# 多级差分 RC 网络：一般阶数推导与计算审查

本节将原二阶结论推广到 N 级，并区分代数证明、精确算术核查和电路仿真。研究对象为固定顺序的正值串联 R／对地 C 梯形网络；参考支路固定，理想电压源驱动，初始条件为零。两支路每次接入相同、已知的负载，比较包含绝对增益的完整复传递函数。

## 1. 一般阶数的两个多项式

令 r_j=R_j/R_*、q_j=C_j/C_*、x=sR_*C_*。单级链矩阵为

\[
M_j(x)=\begin{bmatrix}1+r_jq_jx&r_j\\q_jx&1\end{bmatrix}.
\]

乘积 M_1…M_N 的第一行为 (A_N,B_N)。从 A_0=1、B_0=0 出发，逐级递推：

\[
B_j=r_jA_{j-1}+B_{j-1},\qquad A_j=A_{j-1}+xq_jB_j.
\]

正值元件保证 deg A_N=N、deg B_N=N−1、A_N(0)=1。每一级矩阵的行列式为1，整个乘积亦为1，A_N 与 B_N 没有非平凡公共因子。开路传递函数、输入源置零后的输出阻抗及电阻端接后的传递函数分别为

\[
H_0=\frac1{A_N},\qquad \frac{Z_0}{R_*}=\frac{B_N}{A_N},\qquad
H_g=\frac1{A_N+gB_N},\quad g=R_*/R_L.
\]

二阶的 A_2=1+ax+bx²、B_2=c+dx 是该表示的特例。

## 2. 任意阶的元件恢复与正实现判据

已知实系数多项式 A_j、B_j，使用最高次系数 lc(·) 从输出端恢复：

\[
q_j=\frac{\operatorname{lc}(A_j)}{\operatorname{lc}(B_j)},\quad
A_{j-1}=A_j-xq_jB_j,
\]
\[
r_j=\frac{\operatorname{lc}(B_j)}{\operatorname{lc}(A_{j-1})},\quad
B_{j-1}=B_j-r_jA_{j-1}.
\]

正实现的充要判据为：A_N(0)=1；每步次数按上述网络阶数下降；每个恢复的 r_j、q_j 严格为正；最后 A_0=1、B_0=0。必要性由正向递推直接给出；充分性由恢复结果逐级反向代回给出。恢复步骤逐个唯一，因而在该固定梯形拓扑内，(A_N,B_N) 唯一确定全部元件。

逆映射在正元件点附近由非零分母的有限有理运算组成，且严格正值、非零最高次系数在足够小邻域内保持成立。前向映射和逆映射光滑互逆，因此 (A_1,…,A_N,B_0,…,B_{N−1}) 是2N个有效局部坐标。

## 3. 端接约束如何消除自由度

| 固定参考支路的匹配要求 | 独立约束 | 正实现域内的局部自由度 |
|---|---|---|
| 开路完整传递函数相同 | 固定 A 的 N 个非恒定系数 | N |
| 一个指定 g>0 下完整传递函数相同 | 固定 A+gB 的 N+1 个系数 | N−1 |
| 两个不同已知电阻端接下完整传递函数均相同 | 确定 A 与 B | 0，元件逐一相同 |

单个正电阻负载时，常数项1+gB_0固定 B_0，其余 N 项为 A_k+gB_k（最高次为 A_N），约束秩为 N+1。N=1 时一个正电阻负载已具有零自由度。

对于两个不同端接，记 U_i=1/H_{g_i}：

\[
B=\frac{U_2-U_1}{g_2-g_1},\qquad
A=\frac{g_2U_1-g_1U_2}{g_2-g_1}.
\]

因此两支路在两种端接下均相同就具有相同 A、B，逐级恢复后对应元件相同。两个端接指两组完整传递函数；若只比较归一化幅度或两个离散频点，以上条件不成立。

## 4. 更一般的已知有理负载

若无量纲负载导纳为 g(x)=P(x)/Q(x)，P、Q 为非零互素实多项式，且 QA+PB 不恒为零，则

\[
H_g=\frac{Q}{QA+PB}.
\]

两支路匹配当且仅当 QΔA+PΔB=0。由互素性可写成

\[
\Delta A=P S,\qquad\Delta B=-Q S.
\]

令 m=min(N−deg P,N−1−deg Q)。次数限制要求 deg S≤m；A(0)=1 又要求 P(0)S(0)=0。因此局部匹配自由度为

\[
d_g=\max\{0,m+1-\epsilon\},\qquad
\epsilon=\begin{cases}1,&P(0)\ne0,\\0,&P(0)=0.\end{cases}
\]

零负载导纳即开路另列，维数为 N。上述公式来自系数空间的线性核与严格正实现域相交，不需要以有限阶展开替代一般证明。

| 负载 | 无量纲导纳形式 | 局部自由度 |
|---|---|---|
| 电阻 | g_0>0 | N−1 |
| 纯电容 | αx，α>0 | N |
| 纯电感 | β/x，β>0 | max(N−2,0) |
| 串联 RC | αx/(1+γx)，α、γ>0 | N−1 |
| 并联 RC | g_0+αx，g_0、α>0 | N−1 |

两个不同的已知有理导纳也可确定 A、B：分别写出 ΔA+g_iΔB=0，相减后由 g_1−g_2 不恒为零得到 ΔB=0，再得到 ΔA=0。该结论保留完整函数和负载已知的条件。

## 5. 换载泄漏和工程边界

设 D_i(g)=A_i+gB_i，Δ表示P支路减N支路，则共模输入向差模输出的增益为

\[
G_{D\leftarrow C}=-\frac{\Delta A+g\Delta B}{D_P(g)D_N(g)}.
\]

若在 g_0>0 下匹配，则 ΔA=−g_0ΔB、ΔB(0)=0，换载后

\[
G_{D\leftarrow C}(g)=-\frac{(g-g_0)\Delta B}{D_P(g)D_N(g)}.
\]

负载变化与剩余输出阻抗自由度共同决定泄漏；零频仍抵消，非零频可失配。输出跨接电容对任意阶独立线性支路仍给出共同负载因子，故不会单独改变差模增益与共模转差模增益之比。

理论唯一性与测量稳定性分别检验。两端接恢复包含1/(g_2−g_1)，而 δ(1/H)≈−δH/H²；负载过近、深阻带测量会放大误差。未知源电阻与第一级电阻只作为总和可辨识；零电容造成降阶；跨支路源耦合和不对称负载需要完整网络模型。
