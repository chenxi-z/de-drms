## 核心命题（原文）

1. **AAF 与抽取被塞进 ADC 的输入采样网络（本文核心动作）**（p.536，PDF p.2）："First, since Decimation causes noise folding, an anti-aliasing filter is required. This FIR filter is implemented using a switched capacitor structure."（抽取导致噪声折叠，AAF 用开关电容结构实现——即抗混叠在电荷域、于 ADC 输入端完成）
2. **常规做法需要隔离缓冲器，且其建立时间要求苛刻（H5 域关键段）**（p.536，PDF p.2）："A conventional solution, as shown in Fig. 1, would require an isolation buffer between the FIR filter and the ADC input sampling stage, to avoid charge sharing between the two switched capacitor blocks. This buffer would also provide the required AGC functionality. However, this amplifying stage would have very demanding settling time requirements to reduce the error at the sampling instant in the ADC input stage. Also, it would increase area and power consumption."（两个开关电容块直接级联会**电荷分享**；常规解法插隔离缓冲器，但缓冲器在采样瞬间的建立误差要求非常苛刻——本文的解法是把 FIR+抽取+增益全合并进单一采样结构，从而不需要该缓冲器）
3. **合并方案**（p.536，PDF p.2）："The FIR filtering, decimation by two and gain control functions are all implemented in the sampling network at the input of the ADC, as shown in Fig. 3. Combining these functions in a single sampling structure optimizes area, power and complexity."（单一采样结构同时完成 FIR 滤波、二抽取、两档增益）
4. **FIR 的使命 = 抑制 Fs/2 附近噪声**（p.536，PDF p.2）："The key role of the FIR filter is to provide enough noise suppression around Fs/2. The signal at the input of the ADC is band limited by preceding circuits to 75MHz. The ADC works at half that frequency. A third order charge domain FIR filter was implemented to attenuate the input signal noise around 37.5 MHz."（输入被前级限带到 75 MHz，ADC 以一半频率 37.5 MHz 工作，三阶电荷域 FIR 压折叠带）
5. **失配会劣化共模噪声抑制（P1 域唯一定性线索）**（p.537，PDF p.3）："Layout considerations are also very critical, since any component mismatches could result in degradation of common mode noise rejection and cancellation."（元件失配会劣化共模噪声抑制与对消——**只有这一句定性断言，无任何解析条件/公式**）
6. **开关电荷注入与钟馈只是「尺寸优化掉」**（p.537，PDF p.3）："In order to minimize sampling error due to the charge injection and clock feed-through from the switches, transistor sizes are optimized for speed and area."（电荷注入/钟馈误差靠晶体管尺寸优化压小，未给定量模型）
7. **多比特放宽第一积分器运放要求**（p.535，PDF p.1）："This multi-bit architecture relaxes the first integrator's amplifier requirements, thanks to reduced signal changes at the amplifier's output when compared to a single bit sigma-delta ADC. Also, the required full signal swing at this node is reduced, resulting in relaxed settling time and slew rate specs."（多比特 DAC 使运放输出摆幅变小 → 建立/压摆规格放宽）

## 关键数值（原文）

- 工艺/电源：1.5 V、130 nm 数字 CMOS（p.535）；实测 "1.6mW per channel, with a 1.58 V power supply"，面积 "0.2 mm2 per ADC"（p.538，PDF p.4）
- 架构：离散时间二阶 5 电平 ΣΔ，采样 37.5 MHz；IFA 工作于 75 Msps；输出 3-bit @ 37.5 Msps（p.535–536）
- FIR 系数与抑制量："coefficients C0, C1, C2, and C3 are 1, 3, 3, and 1 respectively, which can be easily implemented as capacitor ratios"（p.536）；"Matlab simulations indicate that more than 80 dB attenuation can be achieved at folding frequency band edge (36.5 MHz)"（p.536，**仿真值**）
- 增益控制："a two-step (0 dB and 14 dB) gain control function, using switched capacitor circuits"（p.537，PDF p.3）；两种增益模式下 "the capacitance seen at the input port is kept constant for both gain modes"（对前级负载恒定，p.537）
- DR/SNDR：ADC DR 要求 "minimum of 60dB"（p.535）；实测 "The measured peak SNDR is 60 dB for an input 4 dB from full scale with a 1 MHz bandwidth"（p.538，PDF p.4）
- 时序：六相时钟 P1–P6 实现 FIR+抽取，"integration occurs in P1, P3, and P5 phases only … Since there is no integration for P2, P4, or P6 phases, a decimation by 2 operation is performed. To increase the time available for integrator settling, integrating control signal's I1, I2 and I3 duty cycle is extended"（p.537，PDF p.3）
- 噪声权重判断："quantization noise is a dominant noise contributor for this application, making kT/C noise less of an issue"（p.537）；"noise from the amplifier is not very critical due to the high in-band quantization noise. Therefore slew rate, GBW and output dynamic range became the most critical design parameters"（p.537）
- DAC 线性化：5 电平 SC DAC 用 ILA（Individual Level Averaging）算法（p.538，PDF p.4）

## 对 P1/P2/P3 的对照

- **P1（失配消去条件，G_DC≡0）——相关性：低（只有一句定性旁证）**：全文唯一涉及「失配→共模」的语句是 p.537 的 "any component mismatches could result in degradation of common mode noise rejection and cancellation"——**方向与 P1 一致（失配破坏共模对消）但没有给任何元件级条件或公式**，属工程经验断言。FIR 系数 1/3/3/1 用电容比实现（p.536），失配只影响滤波系数，未讨论对共模路径的影响。killRisk：无（不构成反例也不构成竞争性框架）。
- **P2（Kelvin 结构地板 ≈56 dB）——相关性：无**：片上接收机链路（LNA→TA→IFA→ADC），无两线/四线传感结构讨论。
- **P3（平坦度约束的 AAF 衰减上界）——相关性：中低（同域不同问）**：它给出的是「内置 AAF」路线的一个数据点——三阶电荷域 FIR 在折叠带边（36.5 MHz）仿真 >80 dB（p.536）。这是**带边单点抑制指标**，不是「通带平坦度 ↔ 阻带衰减」的解析权衡框架；但它证明了「AAF 衰减指标可以由系统仿真定阶（"The FIR order was determined by system level simulations", p.536）」的工程惯例——可作为 P3 所批评的「无解析框架、靠仿真定阶」现状证据（C 级）。killRisk：无。
- **方法学（D1–D10）——相关性：低**：无选型方法学内容；倒有一处 H5/D9 邻接材料——「两级 SC 网络间电荷分享 → 常规解 = 隔离缓冲器 → 缓冲器建立误差苛刻 → 解法 = 功能合并免缓冲」（p.536）这条链，是「开关电容负载的驱动/建立」问题在同一芯片内的经典表述，但无数值（缓冲器建立精度未给数）。

## 没读到的

- FIR >80 dB 抑制是 Matlab 仿真值（p.536），**实测频谱（Fig.10 FFT）只对应 500 kHz 单音 @ 37.5 MHz 采样，未单独实测 FIR 折叠抑制**。
- 隔离缓冲器方案被否后，「电荷分享」的定量误差（若不加缓冲会差多少 dB）未给——本文以合并结构绕开而非量化。
- 失配→共模抑制劣化（p.537）无公式、无灵敏度数值；"common mode noise rejection and cancellation" 具体指 SC CMFB 与全差分通路哪一环，文中未展开。
- OCR 丢失：式(1) 差分方程符号混乱（已按上下文核回为 y(n)=C0·x(n)+C1·x(n−1)+C2·x(n−2)+C3·x(n−3)）；Fig.4/6/7/8/9 为图，正文无法核其内部标注；参考文献 [1]（F. Muhammad 离散时间蓝牙接收机 ISSCC 2004）与 [2]（Gomez/Haroun EA 调制器）原文未读。
