## 核心命题（原文）

1. **论文主题：用可行解空间的拓扑性质生成 Pareto 前沿，做模拟电路尺寸多目标优化**（p.47，摘要）：
   > "We present a novel heuristic for optimizing analog circuit performances. It deals with generating the Pareto front using the topological properties of the feasible solution space. This heuristic allows us generating optimal values of circuit parameters in reduced computation time and memory consumption."（摘要；即不靠 GA/SA 等通用元启发式，而是扫掠可行解空间拓扑直接取非支配点。）

2. **模拟电路优化天然是多目标、解是一整条 Pareto 前沿而非单点**（p.47）：
   > "These problems are thus seldom single-objective ones. They are in fact several contradictory criteria (or objectives) that must be satisfied simultaneously. … the solution of MCOP is not a single one but a set of solutions known as Pareto front (or boarder) when it is plotted in the objectives' hyper-space [2]. Any solution of this set is optimal in the sense that no improvement can be made on a component of the objective vector without degradation of at least another of its components."
   （这是「性能空间存在硬权衡、不能标量化折算」的一般性论据，但只针对尺寸综合，不涉及物理匹配界。）

3. **加权聚合（a priori 标量法）只在可行解空间凸时有效，且扫不全 Pareto 前沿**（p.49–50）：
   > "However, the aggregation (weighting) method is valid only when the feasible solution space is convex. Other ways convergence to the 'best' solution is not insured, i.e. not all the Pareto front can be covered by varying these weighting coefficients, as depicted in Fig. 3."（p.49）
   > "It is clear, as it is shown in Fig. 3, that varying the weighting coefficients (x1, x2) cannot allow sweeping the entire Pareto front. Besides, since there is not a formal rule that allows choosing these coefficients, we show in Fig. 3(c) how much, in some cases, obtained solutions are sensitive to a small variation of these weightings."（p.50）

4. **方法核心：用 Ideal/Nadir 点把可行解空间（FSS）约简为 RFSS，再按各目标逐一扫掠得 k 条初步边界，取交集后做支配运算**（p.51–52）：
   > "the tradeoff surface, i.e. the Pareto front, can simply be generated by sweeping the feasible solution space, (according to objective fi for example) and by taking up, for each fi, the first met point (i.e. the minimum of fj)."（p.51）
   > "Also, and in order to restrict this FSS, we noticed that the front of Pareto is boarded by the minimum values of each function fi; fj: The search will be restricted to the set of values belonging to the intersection of the whole FSS and the rectangle ((fi, fj), (fi*, fj*)). These coordinates are those of the Ideal and the Nadir points."（p.52）

5. **两个应用都是电流模式电路（开关电流存储单元、第二代电流传输器 CCII+），不是滤波器**（p.56、p.58）：
   > "In the following two main applications are presented: optimizing performances of two current mode circuits (Switched Current Class AB Grounded Gate Memory Cells and Second Generation Controlled Current Conveyors)."（p.56）
   > "The proposed heuristic was applied to optimize both parasitic input X-port resistance (RX) and high current cutoff frequency (fc)."（p.58，CCII+ 应用）
   （目标对分别是 rtr–SNR 与 RX–fc，均为晶体管级尺寸–性能权衡；全文无任何滤波器传递函数/衰减/平坦度目标。）

6. **结论自评：随机 a posteriori 方法、生成全部非支配解、可嵌入自动设计流**（p.61）：
   > "It is a stochastic a posteriori approach that generates all the set of non-dominated optimal solutions (the Pareto boarder) in reduced computation time. It uses Nadir and Ideal points to reduce the feasible solution space. Sweeping approaches are adopted to generate preliminary boarders leading to the optimal Pareto front."

## 关键数值（原文）

- 换算电流单元（Application 1）：1500 点 DVS → RFSS 1465 点 → 初步前沿 453 点 → 最优前沿 25 点，程序生成最优前沿约 5 s（p.57–58）：
  > "The heuristic was applied using a 1500-point DVS for each variable"（p.57）；"the optimal Pareto boarder comprises only 25 points. … the C?? program generates this optimal front in *5 s."（p.57–58；*为原文的约等号转义）
- 点 A 尺寸：rtr = 270 ps、SNR = 68.4 dB、可采样至 80 MHz（p.58）：
  > "Due to its low rtr (270 ps), the cell, sized using point A scaling, can be sampled up to 80 MHz. The SNR equals 68.4 dB."
- 采样率–SNR 上限（同单元）：> "…can not exceed 79 dB when the cell is sampled at 10 MHz. It can achieve 83 dB when it is sampled at 1 MHz"（p.58；时间响应是 fsampling 上限的根源）
- CCII+（Application 2）：10,000 点 DVS → RFSS 1020 点 → 初步前沿 566 点 → 最优前沿 201 点，约 30 s，「只实际探索了 10% 的 FSS」（p.60）：
  > "only 10% of the FSS was effectively explored."（p.60）
- CCII+ Pareto 前沿两端点理论与 Spice 实测（Table 7，p.61）：低端 fc = 1.129 GHz（理论）/1.144 GHz（Spice）、RX = 389 Ω/528 Ω；高端 fc = 2.020/1.791 GHz、RX = 697/911 Ω。
- 工艺/供电（Table 4、6）：AMS 0.35 µm CMOS；CCII+ 为 ±2.5 V、偏置 100 µA。

## 对 P1/P2/P3 的对照

- **P1（失配→G_DC 消去条件、τ 匹配）**：无涉。全文不出现 sensitivity、mismatch、differential path、极点/时间常数匹配等概念；其"contradictory criteria"是尺寸–性能目标冲突，不是两条路径传递函数之差。相关度：无。
- **P2（Kelvin 结构地板 ≈56 dB）**：无涉。无结构/布局/电阻比失配到 CMRR/地板的讨论。相关度：无。
- **P3（平坦度约束的衰减可达上界 / Bode-Fano 匹配界）**：无涉。Pareto 前沿是**数值搜索得到的经验权衡面**，与解析可达界（Bode-Fano 类）无任何关系；文中目标全是电路性能指标，不含滤波器衰减/平坦度指标对。相关度：无。
- **方法学（增量四·门槛化）**：中低。提供的是「性能空间 Pareto 前沿生成」通用方法学（Ideal/Nadir 约简 + 扫掠 + 支配表），若 P 系列论文要把「灵敏度 vs 带宽 vs 增益」做成门槛化/多目标论证，可引其「加权法只在凸空间有效、扫不全前沿」的论据（p.49–50）；但其前沿来自随机采样，不含统计公差/良率维度。
- **killRisk**：**无**。不构成对 P1/P2/P3 任何主张的威胁；反而佐证「模拟电路性能存在不可标量化合并的多目标权衡」这一一般性前提。
