# 精读笔记 · Cirrus Logic 2025《CS530x Input Buffer/Filter Circuits》(AN0556R1, JUL 2025)

> 格式标准（全组沿用）：出处 → 核心命题（原文引用）→ 关键数值（原文）→ 对 P1/P2/P3 的对照 → 没读到的。
> 读法：pdftotext 全文逐节读（18 页全读），引用一律原文加页码；不转述成模糊话。

## 出处

Cirrus Logic Application Note AN0556R1, "CS530x Input Buffer/Filter Circuits", Copyright © 2025 Cirrus Logic / Cirrus Logic International Semiconductor Ltd., JUL 2025。18 页，R1 = Initial Release（p.18）。面向 CS5304P/4S/8P/8S、CS53A04P/8P 与 CS5302P 高性能 ADC 的外置输入缓冲/滤波电路。

## 核心命题（原文）

1. **六种差分缓冲方案列表（§1, Table 1, p.2）**——原文逐条（Description / Op-Amps / Advantages / Disadvantages）：
   - "Differential Input in Inverting Configuration"（2 op-amps per input）：优点 "Maximum dynamic range. Common mode rejection. Supports input higher than 2 VRMS"；缺点 "Inverting input stage."
   - "Differential Input in Non-Inverting Configuration"（2 per input）：优点 "Maximum dynamic range. Common mode rejection."；缺点 "2 VRMS maximum input. Higher noise. Requires buffered ADC_VMID."
   - "Single-Ended to Differential Input with Parallel Op-Amps"（2 per input）：缺点 "1 VRMS maximum input. Requires buffered ADC_VMID."
   - "Single-Ended to Differential Input with Inverter and Parallel Op-Amps"（3 per input）：缺点 "3 op-amps required per input. **Signal-alignment mismatch INnP/N. Noise mismatch between INnP/N.**"
   - "Single-Ended Input with Single Op-Amp"（1 per input）：缺点 "Requires external VMID. **Signal-alignment mismatch INnP/N. Noise mismatch between INnP/N.**"
   - "Single-Ended to Pseudo-Differential Input"（2 per input）：优点 "Reduced noise. Supports input higher than 1 VRMS"；缺点 "Reduced dynamic range."
   （§2 p.9 Table 8 对 CS5302P 重复同一六行，仅末行拼写 "Psuedo"；CS5302P 各图额外并 100 pF。）

2. **无源差分 RC 的 THD+N 劣化 ~10 dB 原话（§3, p.16）**：
   > "Note that the **THD+N performance is degraded by approximately 10 dB** when using the passive buffer/filter."
   前文定性："An active buffer/filter, such as described in Section 1 and Section 2, is recommended for typical applications. The active circuits provide enhanced filter characteristics and noise reduction through signal gain. If maximum ADC performance is not required, a passive buffer/filter can be used to reduce component costs."（p.16）
   Table 15（p.16）对无源方案的 Disadvantages 原文："**THD+N degraded. Requires buffered ADC_VMID.**"；Advantages："Reduced component cost. Simple circuit."
   **注意**：劣化 10 dB 是实测结论式陈述，**没有给机理、没有给失配/共模分析、没有给测试条件**——与 P1 的对照见下。

3. **"镜像配方"证据（逐图）**：所有差分图两侧 RC 完全同值——
   - Fig.1 反相差分（p.3）：两臂各 68 µF + 1.2 kΩ（HPF）；反馈 680 pF + 300 Ω/10 Ω（LPF）；跨两输出 15 nF。Table 2（p.3）："HPF –3 dB cut-off frequency: R = 1.2 kΩ, C = 68 µF → 1.59…1.95 Hz；LPF cut-off frequency: R = 300 Ω, 10 Ω, C = 680 pF, 15 nF → 640 kHz"。
   - Fig.2 同相差分（p.4）：两臂各 1 µF + 100 kΩ（HPF 1.59 Hz）+ 680 pF/15 nF（LPF 640 kHz）。
   - Fig.6 伪差分（p.8）与 Fig.13 无源（p.16）：两臂 68 µF + 1.2 kΩ（或无源 68 µF + 10 kΩ，HPF 0.23 Hz）+ 跨接 15 nF。
   - 元件推荐（§4.1, p.17）："Capacitors should be stable dielectric types, such as C0G (NP0) or electrolytic. Resistors should be low value where possible, to minimize thermal noise. Low-noise op-amps should be used, such as Texas Instruments OPA1612 or OPA1656."——**只讲噪声/介质稳定，不讲容差/匹配**。
   - 运放门槛（Table 17, p.17）：Input noise 5 nV/√Hz；GBW 15 MHz；Slew rate 5 V/µs；THD+N −128 dB。

4. **差分拓扑优点只有定性宣称**："Common mode rejection."（Table 1/8 两行反相/同相差分的 Advantages 栏，p.2/p.9）——**没有任何数字、没有说与元件匹配的关系**。

## 关键数值（原文）

- 全部有源方案 LPF 截止 640 kHz（Fig.1/2/4/5/6 系，R = 300 Ω, 10 Ω, C = 680 pF, 15 nF；§1.3 并联运放方案 R=510 Ω 时 490 kHz，Table 4 p.5）；HPF 截止 1.95 Hz（68 µF/1.2 kΩ）、1.59 Hz（1 µF/100 kΩ）、3.39/4.59 Hz（§1.3）。
- 输入量程配置："the ratio of four (1.2 kΩ / 300 Ω) supports a full-scale input of 8 VRMS, i.e., four times the maximum ADC input level"（p.3 等多处）。
- 无源配置（Fig.13, p.16）：68 µF + 10 kΩ + 跨接 15 nF，2 VRMS 满幅、单位增益、HPF 0.23 Hz；1.65 V 偏置可用 "2 x 20 kΩ resistor string"。
- §4.2（p.17）："If the ADC_VMID current for all the buffer circuits exceeds 10 µA, an external VMID buffer should be used." §4.3（p.17）：不用的 INxP/INxN "should be floating"。

## 对 P1/P2/P3 的对照

- **P1（失配消去条件）**：本文是"镜像配方 + 无失配分析"的**当代（2025）再确认**。全部差分图两侧元件逐值相同，但全文（grep）对 mismatch 的全部用法仅 Table 1/8 三处："Signal-alignment mismatch INnP/N" 与 "Noise mismatch between INnP/N"（p.2/p.9）——这是指**单端转差分时 P/N 两路信号对齐与噪声不一致**的拓扑缺点，**不是元件容差→共模转化分析**，且没有任何定量。"Common mode rejection" 作为优点只给词不给数。**P1 的"厂商配方不回答失配问题"论断在此得到 22 年后同一家厂商的复证。**
- **P2（Kelvin 地板）**：无涉及。
- **P3（AAF 衰减上界）**：无涉及（给的是 ADC 输入抗混叠 LPF 单点设计，无衰减上界讨论）。
- **THD+N 10 dB 劣化的归属问题（重要）**：原文只说无源方案 THD+N 劣化 ~10 dB，**没有说这 10 dB 从哪来**（是无源网络阻抗/失真？是缺增益使噪声占比升？还是 RC 失配致共模？）。我们论文引用时**不得**把它当作"失配致共模转化"的证据——它只是一个无解释的观察值。可用于论证"被动 RC 在高要求场合有实测可闻代价"。

## 没读到的

- 失配→共模转化定量分析：**没有**（预期得到验证；mismatch 字样仅上述拓扑缺点三处，无定量、无 CMRR 公式）。
- 10 dB 劣化的测试条件、机理、随频段的变化：均无。
- CS530x 器件本体的输入结构（"see Section 5 of the device datasheet" 多次外指，p.3/4/5…）——需另找 CS530x 数据手册才能补齐。
- 与 AN048 的显式互引：无（两文各自独立，元件值风格不同：AN48 是 MFB 综合方程，AN0556 是给定值表）。
