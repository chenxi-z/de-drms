## 出处

Asahi Kasei Microdevices (AKM) AK5578EN datasheet, 文档号 015016736-E-03, 2022/02（rev 03；rev 00 = 2015/12/18 First Edition，rev 03 关键变更 = "Figure76 … adjusted the optimal input bias voltage with 10.5k ohm resister."，p.71）。器件："8-Channel Differential 32-bit ΔΣ ADC"；"It achieves 121 dB dynamic range and 112 dB S/(N+D) while maintaining low power consumption performance."（p.1）

## 核心命题（原文）

1. **差分输入结构（§13.3 Analog Inputs, p.68）**：
   > "The Analog input signal is **differentially supplied into the modulator** via the AINn+ and the AINn- pins (n= 1-8). The input voltage is the difference between the ALINn+ and ALINn- pins (n= 1-8). The full scale signal on each pin is nominally **±2.8 V (typ)**. A voltage from AVSS1/2 to AVDD1/2 can be input to the AK5578. The output code format is two's complement. The internal HPF removes DC offset (including DC offset by the ADC itself)."
   同页保护约束："any voltage which exceeds the upper limit of AVDD1/2+0.3 V and lower limit of AVSS1/2−0.3 V and any current beyond 10 mA for the analog input pins should be avoided… Use caution especially when using ±15 V for other analog circuits in the system."

2. **推荐外置电路 = "镜像配方"证据（§13.4, Fig.76, p.69）**——原文定性：
   > "Figure 76 shows **Input Buffer Circuit Example 1 (1st order HPF; fc= 0.70 Hz, 2nd order LPF; fc= 351 kHz, gain= −14.5 dB)**. The analog signal is able to input through XLR or BNC connectors. (short JP1 and JP2 for BNC input, open JP1 and JP2 for XLR input). The input level of this circuit is **14.9 Vpp** (AK5578: ±2.8 Vpp Typ.). When using this circuit, analog characteristics at fs = 48 kHz is **DR = 121 dB, S/(N+D) = 112 dB**."
   > "\* **Film capacitors are recommended for the components shown as 15nF and 1nF** in the figure below."
   Fig.76（目视核对元件值，p.69）：AINn+ / AINn− **两臂逐值镜像**——各经 68 µF 耦合 → NJM5534（Bias 脚接偏置）反相放大，输入 R = **3.3 kΩ**、反馈 **620 Ω ∥ 1 nF\***（即 2nd order LPF 的 MFB 臂），输出经 **10 Ω** 串联 + **100 pF** 对地，进 AK5578 AINn+ / AINn−（各 2.8 Vpp）；两 ADC 脚之间跨 **15 nF\***。前端差分接收级：4.7 kΩ ×2 + NJM5534 + XLR/BNC 跳线 JP1/JP2；偏置分压 **10 kΩ / 10.5 kΩ**（VA=+5 V，10 µF+0.1 µF 滤波）——10.5 kΩ 即 rev 03 的偏置修正值（p.71）。**注意：图是"两臂同值镜像"画法，正文没有任何一句讨论两臂容差/失配。**

3. **S/(N+D) 随偏置变化（性能口径原文，p.69）**——两条：
   > "In case the original circuit example is used featuring **input bias voltage of 2.5V (Typ.), S/(N+D) performance will be degraded ~6dB**."
   > "The **S/(N+D) characteristics of the AK5578 vary depending on DC bias voltage of the input signal**. Set the DC bias voltage in the range from **0.502 × AVDD to 0.522 × AVDD** for optimal characteristics."
   （背景：p.69 前文——Date Code XXXXHXX 起的新品推荐 Fig.76 新偏置；旧偏置 2.5 V Typ 属原版电路例。rev 03 历史记录："In case Date Code: XXXXHXX, Figure 76 is adjusted the optimal input bias voltage with 10.5k ohm resister." p.71。）即 **S/(N+D) 是偏置工作点的函数**，偏离最优点（AVDD=5 V 时 0.502–0.522×5≈2.51–2.61 V，旧 2.5 V 就差 ~6 dB）。

4. **片内 THD 补偿**：**AK5578 无此功能**（全文 grep 无 "THD compensation"；"compensate" 仅出现在 BICK 时序延迟语境 p.35 与增益/失调由内部 HPF 处理）。AKM 的失真口径只有整机 S/(N+D) 实测值（见下）。

## 关键数值（原文，§8 Analog Characteristics, p.9，Ta=25 ℃, AVDD=5.0 V, TVDD=3.3 V, fs=48 kHz, BICK=64fs, 1 kHz, 24-bit, BW 20 Hz–20 kHz）

- S/(N+D)：fs=48 kHz：**−1 dBFS 100 (min) / 112 (typ)**；−20 dBFS 97；−60 dBFS 57。fs=96 kHz：110 / 90 / 50。fs=192 kHz：110 / 90 / 50（单位 dB）。
- Dynamic Range（−60 dBFS A-weighted）：Not-Sum. mode 117 (min)/121 (typ)；8-to-4 124；8-to-2 127；8-to-1 130 dB。S/N（A-weighted）同值。
- Input Voltage（Note 10）：2.7/2.8/2.9 Vpp（"This value is (AINnP)−(AINnN)… Vin = 0.56 × (VREFHm−VREFLm) [Vpp]"）；§7 注 9 另给 "Vin (typ, @ 0dB) = 2.8 × {(VREFH) – (VREFL)} / 5 [V]"（p.8）。
- **Input Resistance：3.0 / 3.6 / 4.2 kΩ**（"These values will be doubled in DSD 64fs mode."）——每脚对差分对内的输入阻抗。
- Interchannel Isolation 110/120 dB；**Interchannel Gain Mismatch 0 (typ) / 0.5 (max) dB**；Power Supply Rejection 60 dB（Note 11：PSRR 施加于 AVDD/TVDD，1 kHz 20 mVpp）。
- 参考（§13.2, p.68）："connect a **20 Ω resistor** between the VREFH1-4 pins and analog 5 V supply, and connect a **0.1 μF ceramic capacitor in parallel with an 100 μF electrolytic capacitor** between the VREFH1-4 pins and the VREFL1-4 pins"；VREFL 接 AVSS。
- 去耦/地（§13.1, p.68）："DVSS and AVSS1/2 must be connected to the same analog ground plane. System analog ground and digital ground should be wired separately and connected together as close as possible to where the supplies are brought onto the printed circuit board."

## 对 P1/P2/P3 的对照

- **P1（失配消去条件）**：本文是"镜像配方"的又一原始件——Fig.76 两臂 3.3 k/620 Ω/1 nF/10 Ω/100 pF 逐值相同、跨接 15 nF，正文只字未提两臂失配。全文对 mismatch 的唯一用法是 **"Interchannel Gain Mismatch 0/0.5 dB"（p.9）——通道间增益失配的规格条目，与"差分两臂失配→共模转化"完全是两回事**；CMRR/共模转化字样零次出现。S/(N+D) 随偏置变化 6 dB 级、随输入阻抗/电平变化的口径全部是**单端工作点**语境，无一涉失配。**P1 反例搜索：未找到任何反例，预期得到验证。**
- **P2（Kelvin 地板）**：无直接内容；但 Input Resistance 3.6 kΩ typ（DSD64 加倍）是"ADC 输入并非无穷阻"的实测注脚。
- **P3（AAF 衰减上界）**：Fig.76 给出 2nd order LPF fc=351 kHz 单点配方（对 fs=48 kHz 采样），未讨论衰减上界或与失配的权衡。
- **引文价值**：p.69 两句偏置敏感性原文（0.502–0.522×AVDD / 2.5 V 差 ~6 dB）是"S/(N+D) 随偏置变化"论断的最好引文；Fig.76 可作"厂商差分输入镜像配方"对照图（与 AN048 Fig.5、AN0556 Fig.1 并列）；p.9 Interchannel Gain Mismatch 行可引为"厂商失配口径只到通道间增益、不到差分臂对称性"的证据。
