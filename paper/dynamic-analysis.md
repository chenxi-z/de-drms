# 动态响应分析：比值测量的动态误差与共模瞬态泄漏（2026-10-28）

> 定位：手稿《Termination-Dependent Cancellation in Multistage Differential RC Networks》的动态篇理论底稿——回应审稿意见（`manuscript/REVIEW-2026-10-28-dynamics.md`）T1/T2 项。符号与前件：`paper/manuscript/sections/02a`（链矩阵 D=A+gB、恢复、维数）、`paper/derivations/dynamic_ratio.py`（sympy 核验）、验证包 `Obsidian p1-文献谱系/verification/2026-10-28-dynamic/`。
> 术语纪律：不造新词。"直流群时延"= DC group delay；"加权平均恒等式"为初等卷积事实，不冠定理名号之外的称谓。

## 0. 模型与假设（M1 层，缓冲前端）

双同步比值测量链：样品通道 v_P(t)=I(t)·R(t)，参考通道 v_N(t)=I(t)·R_s，各自经同一负载 g 的无源 RC 梯形（直流增益归一 G(0)=1，即读出 R̂=R_s·[g_P⊛(IR)]/[g_N⊛I]——K 已按设计直流增益校正）。**假设：跟随器在滤波器之前**（DE-DRMS 实际拓扑），R(t) 只调制源幅度，网络本身 LTI。传感元件在网络内（无缓冲直连）是本模型失效区，手稿 limitation 须声明。

## 1. 匹配支路：加权平均恒等式与滞后界（D1）

**恒等式**（初等，逐点精确）：若 G_P=G_N=G（即运行负载下 D_P=D_N），则

R̂(t) = ∫ g(τ)·I(t−τ)·R(t−τ)dτ / ∫ g(τ)·I(t−τ)dτ —— **读数是 R 的 g,I-加权历史平均**，I(t) 的任意波形波动（含快沿）**精确消去**，对全部 t 成立。

证明：[g⊛(I·R)](t) = R(t)·[g⊛I](t) + [g⊛(I·(R−R(t)))](t)（R(t) 与 τ 无关，线性拆分）。

**界**：|R̂(t)−R(t)| ≤ L_R·Imax·M₁ / |[g⊛I](t)|，其中 L_R=|dR/dt| 上界，M₁=∫τ|g(τ)|dτ（一阶绝对矩；g 可有负瓣，N≥2 时留数符号交替，故用绝对矩）。M₁ 由极点/留数直接可算：M₁ ≤ Σ_k |r_k|/|p_k|²（梯形 D 全实负极点）。
注：不宣称 h≥0（N≥2 冲激响应一般有负瓣）；分母下界随 [g⊛I](t) 逐点取，不做统一常数宣称。

**含义**：匹配通道的动态误差=纯滞后加权平均（单通道滤波动态），无 I 串扰。与主设计文档 fs2 的"滞后 ~15 µs 非增益误差"结论同构，此处给出精确恒等式与可计算界。

## 2. 失配支路一阶：R·İ·Δτ 交叉项（D2）

R̂−R = 滞后项（D1，以 g_P 计）+ **交叉项** E₂ = R(t)·([g_P⊛I]−[g_N⊛I])/[g_N⊛I]。
直流增益归一 ⟹ E₂ 的稳态零阶项为零。对慢 İ 展开：E₂ ≈ R·(İ/I)·Δτ + O(İ̈/I)，其中

**Δτ = τ_P − τ_N，τ = D′(0)/D(0)（运行负载下的直流群时延）**，梯形系数直接表出：τ = (A₁+gB₁)/(1+gB₀)（x 单位，×R\*C\* 化秒）。

数值锚（N=2，P=(1,1,1,1)@g=0.1，C₂ 偏差）：+2%→Δτ=0.33 µs；+5%→0.83 µs；+10%→1.67 µs。以 İ/I=800 s⁻¹（1 kHz 三角 ±20%@100 µA）、R=100 kΩ 计：R·(İ/I)·Δτ = 133 Ω（+10% 失配；验证包 T1b 实测 mean 122 Ω / max 162 Ω，量级吻合）——静态消去被打破后**动态出现的新误差通道**，静态分析完全不捕获。（勘误注：初稿误写 R·İ·Δτ，量纲不符；正确式为相对变化率 R·(İ/I)·Δτ。）

## 3. 焊接定理（D3）：静态消去条件 = 动态比值稳健性条件

**命题**：运行负载 g 下，下列等价：(i) D_P=D_N（系数向量相等——手稿静态消去条件）；(ii) g_P=g_N（冲激响应相等）；(iii) 任意 I(·) 波动在比值读出中精确消去（D1 恒等式成立）。
证明：(i)⟺(ii) 同阶多项式相等；(ii)⟹(iii) D1；(iii)⟹(ii) 取 I 为冲激族即得 g_P=g_N。∎

**含义**：手稿的静态条件族（开路 N 维/单负载 N−1 维/双负载 0 维）同时就是"动态 I-消去"的条件族——静态分类学获得动态语义。一阶失配下动态代价 = R·İ·Δτ + 滞后项（D2），Δτ/ΔM₁ 均由系数差表出。

## 4. 共模瞬态泄漏脉冲（T2/P4）

负载偏移族（g₀ 配平、g 观察）：G_DC(g)=−(g−g₀)ΔB/(D_P·D_N)，ΔB(0)=0 ⟹ G_DC(0)=0 但带宽有限 ⟹ **共模阶跃必产生有限能量差分脉冲**（Gasulla 单级瞬态尾的 N 级推广位）。

手稿 P/T 支路（g₀=0.1 配平）@g=0.2：G_DC(x)=−0.1x/((x²+3.2x+1.4)(x²+2.9x+1.2))（归一），四实极点 −2.689/−2.677/−0.523/−0.521（x 单位）。sympy 闭式 y(t)=L⁻¹[G_DC/s]（双曲函数组合，见推导脚本输出）；峰值 9.2×10⁻³·V_c @ t≈28.2 µs（手稿 P/T 支路 @g=0.2；1 V 阶跃即 9.2 mV 差分脉冲）。
一般工具：峰值 ≤ ‖g_DC‖₁；能量 ‖g_DC‖₂² = Σ_{k,j} r_k r_j/(−(p_k+p_j))（留数闭式）；恢复时间由最慢极点 1/0.52·R\*C\*≈19 µs 支配。

## 6. 新颖性边界（如实）

- 恒等式与绝对矩界：初等卷积事实，本文**不作为首创**，价值在应用于该网络类的读出链并给出系数表出的 Δτ/M₁；
- "滤波后取比≠先取比再滤波"：已知现象（research-focus §11.3 已自警"不能重新包装成新发现"）；
- 本文新处（检索内未见）：①同步双通道+多级 RC 下交叉项的系数表出 R·İ·Δτ 与焊接命题 D3；②负载偏移族 CM 阶跃脉冲的 N 级闭式/能量公式。近缘须划界：Xin 2022（固定时差漂移）、Gervasoni 2017（通道交换）、Gasulla 2000（单级瞬态）、Endres 1992（PLL 域 iff）。
- 未做：采样/LPTV（I4 维持推迟）、噪声谱版（I3a，可后接）、传感在网络内的 LTV 情形。
