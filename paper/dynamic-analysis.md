# 动态比值读出与负载变化后的共模瞬态（2026-10-28）

本底稿对应手稿 `sections/03a-dynamic-ratio-and-transient-leakage.tex`，前件为 `02a` 的链矩阵模型。以下结论针对缓冲后的独立无源 RC 梯形，不外推为实物仪器性能。原动态验证包保留；修正后的三/四级原生验证见 Obsidian `verification/2026-10-28-codex-audit/dynamic-corrections/`。

## 1. 模型、单位与归一化

源电压为 `v_P=I(t)R(t)`、`v_N=I(t)R_s`。缓冲器位于滤波器之前，R 只调制源幅度；串联电阻、对地电容均为正，终端电阻负载固定且电导非负，网络稳定、LTI。卷积包括完整输入前史，或等价的相容初态；所有比值要求参考输出非零。传感元件直接进入滤波网络、任意独立初始电压及采样/LPTV 不属于此模型。

记原始传函 `H_j=1/D_j`，直流增益 `k_j=H_j(0)=1/D_j(0)`，归一化传函 `G_j=H_j/k_j=D_j(0)/D_j`，冲激响应为 g_j。实际输出电压 u_P、u_N 经直流校准后给出

```text
Rhat = R_s (k_N/k_P) u_P/u_N
     = R_s [g_P*(IR)]/[g_N*(IR_s)]
     =     [g_P*(IR)]/[g_N*I].                         (1)
```

末式已经是 Ω；不再额外乘 R_s。若用实际输出完成归一化，应将 u_j 乘 D_j(0)。

## 2. 匹配通道：精确历史平均及界

当 G_P=G_N=G 时，逐点精确有

```text
Rhat(t)−R(t)
 = ∫₀∞ g(u)I(t−u)[R(t−u)−R(t)]du / (g*I)(t).         (2)
```

正电流下这是历史电阻的加权平均。R=R₀ 恒定时，任何分母非零的电流波形均得到 R₀；R 随时间变化时，电流仍影响历史权重。整体电流历史乘同一常数会约掉，任意改变电流波形不会普遍约掉。

明确反例：取完整前史 `I=I₀ exp(αt)`、`R=R₀ exp(βt)`，α、β≥0，则

```text
Rhat(t) = R(t) G(α+β)/G(α).                           (3)
```

改变 α 通常改变读数。单级 `G(s)=1/(1+Ts)`、βT=1 时，α=0 给出 R/2，αT=1 给出 2R/3。三级/四级原生验证在相同 R 历史下同样观察到电流造成的读数变化。

正值对地 RC 梯形的节点状态矩阵 M 的非对角元非负，输入向量 b、输出选择向量 c 非负；`g(t)=cᵀexp(Mt)b≥0`，直流归一化不改变该性质。部分分式留数交替不意味着冲激响应有负瓣。因此一阶绝对矩恰好等于普通一阶矩及直流群时延：

```text
M₁ = ∫₀∞ u|g(u)|du = ∫₀∞ ug(u)du = τ,
τ = T D′_x(0)/D(0)
  = T (A₁+g_load B₁)/(1+g_load B₀),  T=R_*C_*.        (4)
```

若相关前史上 `|Rdot|≤L_R`、`|I|≤Imax`，则

```text
|Rhat−R| ≤ L_R Imax τ / |(g*I)(t)|.                  (5)
```

若完整前史满足 `0<Imin≤I≤Imax`，可进一步取统一界 `L_R(Imax/Imin)τ`。零状态有限启动须使用实际卷积分母；有变号的电流不能使用凸平均解释。留数三角界 `Σ|r_k|/|p_k|²` 仍可作保守上界，但不是此梯形的精确 M₁，且留数必须与归一化口径一致。

## 3. 失配通道：精确分解与一阶式

两通道归一化后不同时，

```text
Rhat−R
 = ∫₀∞ g_P(u)I(t−u)[R(t−u)−R(t)]du / (g_N*I)(t)
   + R(t) [((g_P−g_N)*I)(t)] / (g_N*I)(t).            (6)
```

两项的分母都是参考通道输出；第一项不是未经缩放的“匹配 P 通道滞后项”。在 I、R 相对通道记忆变化缓慢、分母远离零时，

```text
Rhat−R ≃ −τ_P Rdot − R (Idot/I) Δτ,
Δτ=τ_P−τ_N.                                         (7)
```

二阶矩 `μ₂,j=∫u²g_j(u)du` 给出卷积展开余项界

```text
|(g_j*f)−f+τ_j fdot| ≤ (μ₂,j/2) sup_{v≤t}|f″(v)|.   (8)
```

分别对 f=IR 和 f=I 应用后再展开商；商的控制还需要分母下界。快沿使用精确式 (6)，不套用慢变近似。恒定 R、参考通道更慢时 Δτ<0，上升电流对应正误差；下降电流对应负误差。二级单位支路参考末级电容 +10%、g_load=.1 时，Δτ=−1.66667 µs；R=100 kΩ、Idot/I=+800 s⁻¹ 对应 +133.333 Ω。一阶值是局部有符号预测，不是整周期平均绝对误差。

## 4. 匹配判据：恒定电阻下的电流消去

正确的等价关系为：对每个恒定 R₀、所有允许且分母非零的电流历史，校准读数恒等于 R₀，当且仅当

```text
g_P=g_N  ⇔  G_P=G_N  ⇔  D_P/D_P(0)=D_N/D_N(0).      (9)
```

充分性直接由式 (1) 得到；必要性由 `(g_P−g_N)*I=0` 对所有电流探针成立得到，正直流上的任意小扰动已足够。无需使用可能导致比值未定义的孤立理想冲激。

原始 `D_P=D_N` 还要求两个直流增益相同。静态原始传函匹配族的维数只在保留该额外要求时继承；不能将归一化匹配直接当作同一族。例：单级、g_load=.1，P 为 r=1、q=1，N 为 r=2、q=6/11。其原始分母分别为 `1.1+x`、`1.2+(12/11)x`，归一化传函却同为 `11/(10x+11)`。对于变化的 R，即便满足式 (9)，结论仍是带电流权重的式 (2)，不是任意电流免疫。

## 5. 负载变化后的共模阶跃响应

在 g₀ 原始配平，观察负载为 g；取差分方向 P−N，ΔB=B_P−B_N，则

```text
F=G_DC=−(g−g₀)ΔB/(D_P D_N),  ΔB(0)=0.               (10)
```

稳定极点与 F(0)=0 使 F(s)/s 无残留零频极点，阶跃响应衰减且有有限平方积分。F≡0 时响应为零；非零 F 才产生非零脉冲。RC 有理滤波器的高频衰减不表示严格带限。

对互异的存留物理极点 p_k，分别定义

```text
F(s)   = Σ r_k/(s−p_k),
F(s)/s = Σ a_k/(s−p_k),  a_k=r_k/p_k,
y(t)   = V_c Σ a_k exp(p_k t),
∫₀∞ y²dt = V_c² Σ_{k,j} a_k a_j/[−(p_k+p_j)].        (11)
```

冲激响应平方积分用 r_k r_j，是另一量。峰值界为 `sup|y|≤|V_c|‖h_DC‖₁`。若极点用 x=sT 的无量纲 λ_k，则阶跃能量式另乘 T，冲激响应平方积分式另乘 1/T。阶跃平方积分单位为 V²·s，不称焦耳能量；重极点须用相应多项式乘指数项，恢复到有限误差带还须指定容差。

实际 P/T 支路：P 为 r=(1,1)、q=(1,1)，T 为 r=(18/19,20/19)、q=(361/180,1/2)。两者 g₀=.1 配平，g=.2 时

```text
D_P=x²+3.2x+1.4,  D_T=x²+3.3x+1.4,
F=H_P−H_T=+0.1x/(D_P D_T).                           (12)
```

极点为 −2.8、−2.6770329614、−0.5229670386、−0.5。T=10 µs 时，峰值 `0.009197601 V_c`、峰值时间 `28.20333 µs`，最慢渐近时间常数为 20 µs；阶跃平方积分为 `3.17497×10⁻⁹ V_c² s`。这保留原峰值结论，并明确差分方向、极点和响应定义。

## 7. 贡献与范围

卷积恒等式、矩界、群时延展开和留数积分都是标准工具，不作为首创。本文将它们与该终端依赖的多级梯形系数及负载配平族连接：区分变化电阻的历史权重、恒定电阻的归一化匹配判据、失配时的有符号电流变化率项，以及负载改变后的共模阶跃响应。新颖性须与相关读出及RC瞬态文献逐项对照，不作“检索未见即首次”的推断。未覆盖传感元件进入网络后的时变参数、采样/LPTV、噪声及实物非理想。
