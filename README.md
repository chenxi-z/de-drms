# DE-DRMS — 双电极直流电阻测量仪

> **2026-11-04：直流首板 + 扫频预留。** 当前固件已接通测量、参考校准、TF记录和双通信口，并提供主机回归与CSV解码工具；实板性能尚待验收。见[固件使用流程](firmware/DE-DRMS-Code/README.md)和[设计入口](docs/design/README.md)。IOC与原理图/PCB本轮未改，旧性能与旧引脚描述不能当验收依据。

本工作区用于研发一套**双电极直流电阻测量仪**，对两端 MWCNTs 导电网络传感层做**结构损伤分级监测**，
涵盖上位机软件、下位机固件、硬件电路、结构件，以及配套的校准、测试与生产工艺。

测量原理为**恒流激励 + 双通道同步实测**：恒流同时流过传感层与精密电阻 Rsense，
ADC 同步采两者压降，按 `R = (V_sample / V_Rsense) × Rsense` 计算电阻，
参考校准后以 `R=k×V_sample/V_Rsense` 计算。后续损伤等级须由该批试件的 **R/R₀** 标定曲线确定；
当前LED表示运行/记录状态，没有虚构分级阈值（详见 [`docs/design/`](docs/design/README.md)）。

## 当前状态

- 当前器件为 **STM32U575RGT6（1 MB Flash / 786 KB SRAM，无SMPS）** + ADS131A02 双通道同步 ADC，
  USB外设为 **USB_OTG_FS**，记录走 **SDMMC1 4-bit**。TF常电，无I²C/TMP117，PA4保持ADS_CS。
  硬件实装与最新引脚以主文档附录F、`docs/design/pin-assignment.md`和用户EDA为准。
- 固件已实现 ADC 上电/回读/CRC/DMA、有界采集、参考校准和双页Flash保存、FileX记录/滚动/容错、
  USB/USART控制、RTC/电池、按键与安全软关机。默认 **4 kSPS**。实板实测 **64 kSPS 是无损上限**
  （16/32/64 kSPS 均零丢样、零 CRC 错）；**128 kSPS 受 ADC 读取时序限制不可用**，采集入口直接拒绝。
  64 kSPS 连续记录约 68.65 s / 4,393,647 帧已在单张卡上通过；其他卡、1 GiB 实物轮转与掉电恢复仍待验收。
- [机器协议](shared/protocol/de-drms-v1.json)与[人读说明](docs/protocol/de-drms-v1.md)成对维护；
  [CSV解码工具](tools/de_drms_log.py)保留坏帧/丢帧诊断，不将正常关闭误当无损采集。
- 尚须实板验证精度、连续吞吐、晶振裕量、实际卡与掉电恢复、USB枚举/挂起/唤醒。
  **BQ24074当前模式接线不能仅靠EN1满足USB挂起取电要求**。无温度补偿，损伤阈值仍需试件标定。
- EDA由用户维护；上位机GUI、结构与生产工艺仍是后续工作。当前可用串口/USB终端控制和命令行导出CSV。

### 单一事实来源

通信协议存在两份载体，用于避免定义漂移：

- `shared/protocol/` 存放机器可读的权威定义，供固件与上位机直接引用或生成代码；
- `docs/protocol/` 存放面向人的说明文档。

**修改协议时必须成对更新，并在同一次提交中完成。**

## 开发约定

- **分支**：`main` 保持可交付基线；功能与修复使用 `feat/…`、`fix/…` 短生命周期分支。
- **提交信息**：采用 Conventional Commits 风格，例如
  `feat(firmware): 增加 R_ref 自校准流程`。
- **行尾**：仓库内文本统一为 LF，由 `.gitattributes` 固定；Windows 批处理脚本保留 CRLF。
- **缩进**：由 `.editorconfig` 约束，提交前请确认编辑器已启用 EditorConfig 支持。
- **入库范围**：只提交源文件与文档。固件产物（`hex` / `bin` / `elf`）、EDA 输出、
  3D 导出件与编译目录一律不入库；**器件手册、论文、厂商参数表等外部资料一律放 Obsidian 库**
  （`20-硬件工程/`），本仓库不存放；正式发布件如需留档，在对应目录用局部
  `.gitignore` 的 `!` 规则单独放行。
- **入库守卫**：`.githooks/pre-commit` 会拒绝外部资料（pdf/Office/压缩包）与单个 >1 MiB 的文件；
  每个克隆执行一次 `git config core.hooksPath .githooks` 启用。唯一例外：
  `docs/design/diagram/*@2x.png` 示意图预览（给人看的交付件，经确认保留）。
- **空目录**：以 `.gitkeep` 占位；新增目录请沿用同一约定。
- **语言**：文档与注释以中文为主；代码标识符、协议字段与目录名使用英文。
