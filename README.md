# DE-DRMS — 双电极直流表面电阻测试仪

本工作区用于研发一套**双电极直流表面电阻测试仪**，涵盖上位机软件、下位机固件、
硬件电路、结构件，以及配套的校准、测试与生产工艺。

测量原理为**双电极直流法**：由下位机对被测表面施加稳定的直流激励，
采集两电极之间流经表面的电流，按 `R = V / I` 计算表面电阻，
再依据电极几何尺寸换算为表面电阻率。

### 单一事实来源

通信协议存在两份载体，用于避免定义漂移：

- `shared/protocol/` 存放机器可读的权威定义，供固件与上位机直接引用或生成代码；
- `docs/protocol/` 存放面向人的说明文档。

**修改协议时必须成对更新，并在同一次提交中完成。**

## 开发约定

- **分支**：`main` 保持可交付基线；功能与修复使用 `feat/…`、`fix/…` 短生命周期分支。
- **提交信息**：采用 Conventional Commits 风格，例如
  `feat(firmware): 增加 10^6~10^12 Ω 量程自动切换`。
- **行尾**：仓库内文本统一为 LF，由 `.gitattributes` 固定；Windows 批处理脚本保留 CRLF。
- **缩进**：由 `.editorconfig` 约束，提交前请确认编辑器已启用 EditorConfig 支持。
- **入库范围**：只提交源文件与文档。固件产物（`hex` / `bin` / `elf`）、EDA 输出、
  3D 导出件与编译目录一律不入库；正式发布件如需留档，在对应目录用局部
  `.gitignore` 的 `!` 规则单独放行。
- **空目录**：以 `.gitkeep` 占位；新增目录请沿用同一约定。
- **语言**：文档与注释以中文为主；代码标识符、协议字段与目录名使用英文。

## 待确认事项

以下条目需在进入设计阶段前明确：

1. **量程与准确度**：表面电阻测量范围、分辨力与允差（例如是否覆盖 10³ ~ 10¹² Ω）。
2. **激励方式**：直流激励的电压档位与限流方式，是否需要多档自动切换。
3. **电极系统**：电极材料、几何尺寸、电极间距与施加压力要求。
4. **引用标准**：需确认适用标准及其版本（候选：IEC 61340-2-3、
   ANSI/ESD STM11.11、GB/T 1410、ASTM D257 等，适用性待评估）。
5. **下位机选型**：MCU 型号、ADC 方案与工具链（Keil / IAR / GCC）。
6. **上位机技术栈**：语言与框架、目标操作系统、打包与分发方式。
7. **物理链路**：上下位机通信方式（USB CDC / UART / BLE / Wi-Fi）与供电方式。
8. **校准**：标准电阻件规格、校准周期与溯源要求。
9. **项目命名**：`DE-DRMS` 的正式英文展开与产品型号。
