# 设备行为与验收

供项目负责人和需求评审使用。以下是首版目标行为。评审关注仪器在试验现场的表现；已验证的操作步骤以后随固件版本写入用户手册。

| 现场动作 | 期望看到的结果 |
| --- | --- |
| 无卡开机 | 设备自动测量。有有效电阻时可读到电阻值。具备适用的试件基线 R₀ 和区间配置后才显示对应等级。插入卡本身不会建立文件。 |
| 建立试件基线 | 长按测量键请求建立 R₀。质量合格且保存成功后采用新基线，失败保留原值。仪器参考校准是独立维护操作。 |
| 做一次试验 | 在监测就绪且卡可写时，短按测量键开始记录。文件和起始样本边界确认后才显示记录中。再次短按或到预设时长结束记录，完成收尾后继续监测。 |
| 试验中连接或拔掉电脑 | 连接后可查到按键发起的这次记录。拔线后设备继续记录。记录期间读取历史文件或把卡导出为 U 盘会得到忙提示。 |
| 读取历史记录 | 记录收尾完成后，可通过协议读取文件，也可显式导出为只读 U 盘。导出期间持续监测，交还卡后才能再次记录。 |
| 试验中掉卡 | 本次记录报告不完整；采集仍有效时监测继续。重新插卡后需显式启动下一次记录。 |
| 停采或关机 | 短按电源键安全停采并收尾；电池运行时长按请求关机。唤醒后恢复监测，之前的录制动作不会重放。 |

**首板验收时请看一场完整试验。** 无卡开机、插卡、按键开始、中途接电脑查询、拔线、定时结束，再立即开始第二次。核对每次记录独立可辨，同时检查文件能否正常关闭、采样是否丢失。这两项结果需要分别判断。对区间功能还要覆盖无基线、读数过期和区间未配置，三者均不能点亮正常等级。

客户分档阈值和基线稳定容限需试件标定；实际支持的采样、记录和上传组合需首板验证。固件升级属于后续规划。
