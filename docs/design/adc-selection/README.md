# 附录 F ADC 选型记录与备选方案

版本 1.0 · 2026-10-12 · 状态：主方案定稿，备选挂起

> 本文件记录双电极电阻测量仪的 ADC 选型全过程、被否决方案及原因、以及挂起的备选方案。
> 主方案见 [信号链文档 附录 E.4](../2026-10-10-universal-signal-chain.md)。

## 2 选型决策链（按时间顺序）

```
ADS1220(太慢) → ADS124S08(多通道复用/4kSPS) → AD7175-2(排除) 
  → ADS127L11(单通道高速, 比例式Rsense当基准) 
      ✗ 否决：基准输入电流 ±2µA(缓冲开)/190µA/V(缓冲关)，对150kΩ源阻抗致命(SBAS946C核实)
  → 换思路：双通道实测，各用固定基准
      → AD7124-4(多通道复用) → ADS131M02(双通道同步, 但用户会加跟随器)
      → ADS131A02(加跟随器后阻抗差异抹平, 综合更优)
  ✓ 定稿 ADS131A02
```

## 3 主方案：ADS131A02（定稿）

| 参数 | 数值 | 手册 |
| --- | --- | --- |
| 通道 | 2 通道**同步采样** | SBAS590E |
| 位数 | 24 bit ΣΔ | — |
| 速率 | 最高 128 kSPS | — |
| 模拟供电 | 3.0–5.5 V（灵活，含负电荷泵模式） | — |
| 数字供电 | 1.65–3.6 V，**3.3 V 直连** | — |
| 基准 | 内部 **2.442 V**（6 ppm/℃ typ）或外部（勘误 2026-10-12：原文"1.2 V"有误，手册无 1.2 V 选项） | — |
| 输入阻抗 | 差分 130 kΩ（fMOD=4.096 MHz） | EC 表 |
| SNR | 115.2 dB | — |
| 封装 | TQFP-32（7×7 mm） | — |
| 价格 | ~$4（TI 筛选表） | — |

**选定理由**：
- 同步采样 → V/I 严格同时，恒流波动在除法中抵消；
- 用户既定每通道加跟随器 → 130 kΩ 输入阻抗的加载问题被跟随器隔离，不再是短板；
- 模拟供电宽（3.0–5.5 V）→ 将来要抬激励电压测更高 R₀ 时有余量；
- 内部基准 6 ppm/℃ + 支持外部基准 → 比 ADS131M02 内部基准更稳；
- 数字 3.3 V 直连 → 不用电平转换（对比 ADS127L14 的 1.8 V 数字）；
- SNR 115.2 dB、128 kSPS → 对 1% 准静态应用富余，余量即可靠性。

## 4 备选方案（挂起）

### 备选一：ADS131M02（挂起）

| 参数 | 数值 |
| --- | --- |
| 通道 | 2 通道同步采样 |
| 速率 | 64 kSPS |
| 模拟供电 | 2.7–3.6 V（窄） |
| 数字供电 | 1.65–3.6 V，3.3 V 直连 |
| 基准 | 内部 1.2 V |
| 输入阻抗 | 330 kΩ（增益 1–4）/ **≥1 MΩ（增益 8–128，预充电缓冲）** |
| 封装 | WQFN-20（3×3 mm）/ TSSOP-20 |
| 价格 | **~$1.66（最便宜）** |

**挂起理由/启用条件**：
- 优势：高输入阻抗（增益≥8 时 ≥1 MΩ，**可不用跟随器直连高阻源**）、最便宜、封装小、用户**用过**；
- 劣势：模拟供电窄（2.7–3.6 V）、速率低、内部基准不如 A02 稳；
- **启用条件**：若后续决定**省掉跟随器**（M02 高阻直连的加载误差仅 0.01–0.015%，远小于 1% 指标），或成本/功耗/便携成为首要约束，切换到本方案。

### 备选二：ADS127L14（评估后未选，记录原因）

四通道同步、512 kSPS、2.85–5.5 V 模拟。性能强但：**数字供电仅 1.65–1.95 V（需电平转换）、无内部基准（需外置基准芯片）、价格 ~$14（A02 的 3.5 倍）、VQFN-56 大封装**。4 通道与高速对本应用过剩，故未选。

### 备选三：AD7124-4（评估后未选，记录原因）

四通道**复用**（非同步），基准缓冲电流 nA 级适合比例式。但复用型 V/I 不同时采样，且用户已定双通道同步实测路线，故未选。

## 5 被否决方案记录

| 方案 | 否决原因 | 手册依据 |
| --- | --- | --- |
| **ADS127L11 比例式**（Rsense 当基准） | 基准输入电流 ±2 µA（缓冲开）/190 µA/V（缓冲关），对 150 kΩ 源阻抗产生 0.3 V–228 µA 误差，致命 | SBAS946C EC 表 |
| **分压激励**（VCC+分压替代恒流源） | 电流随 R_sample 变 50%、自热不一致、电源噪声直接灌入、断裂时 0/0 不定需额外检测电路 | 设计评审 |
| ADS1262/63 | 模拟供电最低 4.75 V，3.3 V 不能工作 | SBAS661C |
| AD7792/93/94 | 无基准缓冲，基准电流 400 nA/V → 150 kΩ 上 6% 误差 | 手册 |
| ADS1235 | 基准电流 500 nA + 需 5 V 供电 | SBAS824 |

## 6 关键教训（存档防重踩）

1. **比例式测量（Rsense 当基准）对 ADC 的基准输入电流极其敏感**。传统低速 ΣΔ（AD7124、ADS124S08，基准电流 nA 级）可用；高速 ΣΔ（ADS127L11/L14，基准电流 µA 级）不可用。**选比例式前必须先核基准输入电流。**
2. **多通道 ADC 分两种**：复用型（一个内核轮测，如 AD7124-4）vs 同步采样型（多内核同时转，如 ADS131M02/A02/L14）。要 V/I 同步必须选后者。
3. **输入阻抗是否重要取决于前端是否有跟随器**。有跟随器则 ADC 输入阻抗被隔离，不再是约束；无跟随器直连高阻源时，输入阻抗必须 ≫ 源阻抗。
4. **TI ADS 产品线里"双通道同步采样"只有 ADS131M02 和 ADS131A02**（依据 TI 官网参数筛选表，34 颗 24bit ΣΔ 全核实）。ADS127 系列无双通道（L11/L21 单通道、L14/L18 四/八通道）。
