### A.3 模拟前端与自校准

- 3×OPA388 跟随器（T/M/B 三线），**第 4 颗不做**：AIN1N 经 RC 直连 Rsense 底端 Kelvin 地——真实非对称接线，后成为 CMRR 结构地板的来源（A.6）。
- T 顶端 R_top 10 kΩ / R_b 150 kΩ 偏置；BAV199 低漏保护；R32/R33 Kelvin 焊盘（四线不贴/二线 0 Ω）。
- 自校准三层：0.1% R_sense 打底 + 0.01% R_ref（PTFR0805Q100KN9）+ 零点模式；单颗 TMUX1134 切换；k 校准中 R_sense 约掉、绝对精度锚定 R_ref。
- 证据：附录 E.2/E.3、`模拟前端与自校准.svg`。

### A.4 ADC 选型（否决链）

ADS131A02 定稿（2 ch 同步、24 bit、128 kSPS、内基准 2.442 V、3.3 V 直连、sinc³、fMOD 4.096 MHz）；否决 ADS127L11（比例式致命，见 A.1）、ADS1262（需 4.75 V）、AD779x（无基准缓冲）、ADS1235（500 nA + 5 V）。采样策略：冲击全程 128 kSPS 采满、按需数字降采样；768 kB/s → TF 记录（SDMMC 4-bit）。证据：附录 E.4、`adc-selection` 历史。

### A.6 验证方法学（论文的"方法"核心）

1. **十维门槛框架** D1–D10 + C9（衰减/通带/建立/噪声增量/容差 σ/CMRR/kickback/群延迟/peaking），门槛全程不降、FAIL 如实保留。
2. **三层验证**：L1 理想 RC（解析/线性 MC）→ L2 真实宏模型 LTspice（TI OPAx388.LIB + 恒流源 + 3 跟随器 + Kelvin 非对称接线 + ADC 等效负载与采样开关）→ L3 离线 sinc³ 系统层（比值链、折叠风险）；纪律：**理想 RC 结果不得冒充 LTspice 结果**。
3. **T00 回归锚定**：每轮复跑基线对锚定值（六项全中，偏差 <0.03 dB）。
4. **容差双配对口径**：未配对量产（R±1%C±5% MC n=1000 + ≥30 LTspice 角点）vs 配对（逐级各自配 / **整线同 m**）；发现二阶 R1·C2 交叉乘积项 → 逐级配对只 51 dB，整线同 m 恢复 90.5 dB。
5. **CMRR 双口径**：RC 自身（配对可控）vs 整链 Kelvin 结构地板 56.08–56.31 dB（拓扑决定、配对不可修复）。
6. **kickback**：3.5 pF 差分采样开关、4.096 MHz 双相 50%、Ron 扫 1/100/1000 Ω（声明假设）。
7. **混叠有界风险**：4.096/16.384 MHz ±{1k,8k,16k} 注入；16.384M 族瞬态实测为交流预测 1.65–8.5×；sinc³ 合成仅 −61~−64 dB。
8. **真实占地 vs 本体面积**：EasyEDA 工程副本实画六方案布局（184 焊盘读回验证），发现二阶全 0402 真实占地反小于一阶含 0805（32.62 vs 39.05 mm²/通道，−16.5%）。
9. **物理极限定量**：D4≤0.5 dB 把 fc 钉死 50–70 kHz → 4.096M/fc≈1.8 dec → 无源二阶理想极限 ~76 dB < 80；D1/D3 与 D4 在无源一/二阶内互斥（参数微调无解，需三阶/有源/数字合成口径）。

### 由现状提炼的科学问题（写 Intro/讨论用）

- **SQ1（可达性极限）**：通带平坦度约束下，面向离散开关电容 ΣΔ 的 N 阶无源 RC 抗混叠网络，衰减上界的解析形式是什么？（本文已给 N=1,2 的实测印证：两阶理想 ~76 dB < 80 dB @ 4.096M/fc≈1.8 dec）
- **SQ2（配对不变量）**：多级差分 RC 梯形的共模抑制由什么配对不变量决定？（发现：级间独立配对不保持 R1·C2 交叉乘积 → 逐级配 51 dB vs 整线同 m 90.5 dB）
  **2026-10-26 校准**：单级失配公式已有（TI SBAA230 app note），差分网络共模响应已有定性分析（Hornero Ocaña 2021, AEU）——SQ2 的新颖性收窄为多级配对不变量 + Kelvin 结构地板 + 可达性边界，写作时 SBAA230/Hornero 为最近前作正面引用；go/no-go = 精读此二者及其引文链。
- **SQ3（结构地板）**：双通道比值系统中，负端 Kelvin 无源直连接道的 CMRR 是否存在与配对无关的拓扑上界？（实测 ~56 dB）
- **SQ4（比较度量学）**：衰减/平坦/CMRR/噪声/建立/kickback/真实 PCB 占地互相冲突时，候选滤波器如何被公平裁决？（门槛框架 + 三层验证 + EDA 实画占地 Pareto）
- **SQ5（残余风险定界）**：模拟段不达标而依赖 sinc³ 数字滤波时，fMOD/MCLK 邻域折叠风险如何定界？（16.384M 族瞬态为交流预测 1.65–8.5× 的有界评估方法）
