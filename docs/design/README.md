**数据流**：1S 锂电 → 双 LDO → OPA333 恒流源（8 µA）→ 样品 / Rsense → 跟随器 →
ADS131A02（双通道同步）→ STM32U575RGT6（SPI）→ USB → 上位机。

## 4 关键设计决策与理由（含被否方案）

| 决策 | 结论与理由 |
| --- | --- |
| 恒流 vs 电桥 | **恒流**。被测对象是两端电阻条，物理上无法自然成桥 |
| 单通道 vs 双通道 | **双通道同步实测**。V/I 严格同时，恒流波动在除法中抵消 |
| 比例式（Rsense 当 REF） | **否决**。ADS127L11 基准输入电流 ±2 µA（缓冲开）/190 µA/V（缓冲关），对 150 kΩ 源阻抗致命 |
| 分压激励（VCC + 分压替代恒流源） | **否决**。电流随 R 变 50%、自热不一致、电源噪声直灌、断裂时输出不定 |
| ADC 选型 | ADS1220 → ADS124S08 → AD7175-2 → ADS127L11 → AD7124-4 → **ADS131A02**（详见选型记录） |
| MCU 选型 | G431 → U535 → U545 → **U575RGT6**（RAM 与大内存需求，详见选型记录） |
| pin2pin U5↔G4 | **不存在**。U5 的 pin21 = VCAP（须接 4.7 µF，禁止外供电），G4 同脚 = VDDA，硬冲突 |
