## 1. 设计目标（一句话）

在 128 kSPS 输出码率下，把直流 + 单相正弦叠加信号（正弦分量 ≤16 kHz）完整、平坦、低噪地送达 ADS131A02 采样电容，同时对 fMOD=4.096 MHz 及以上的混叠源提供远超物理底的衰减。

## 2. 信号规格（输入条件）

| 项 | 值 | 来源 |
|---|---|---|
| 信号类型 | 直流电平 + 单相正弦叠加（不换向） | 用户 2026-10-18 确认 |
| 直流测量对象 | 设计量程 10–120 kΩ（≤0.005%）；1% 可用范围 ~73 Ω–600 kΩ（下限 = K2 漏电恒定 −0.73 Ω 偏置；上限 = 比值机制把恒流合规墙 215 kΩ 推到 ADC 满量程处，600 kΩ 时电流自动跌落、比值抵消，E.3.4 fs4/fs6 实测） | 附录 E.3.4 |
| 正弦分量频率上限 | **16 kHz**（每周期 8 点 @128 kSPS，实用下限） | 用户 2026-10-18 确认 |

## 3. 频率规划（三层分工）

| 层 | 频段 | 责任人 | 手段 |
|---|---|---|---|
| 通带 | DC ~ 16 kHz | 模拟阶梯让路 | fc = 50~80 kHz（给 16 kHz 留 3~5 倍余量） |
| 过渡带 | 16 kHz ~ 64 kHz | 模拟 + 数字共同 | 模拟平缓滚降 + sinc³ 数字滤波器 |
| 数字阻带 | 64 kHz ~ fMOD | **sinc³ 数字滤波器**（OSR=32） | fMOD 谐波处深陷波 |
| **模拟主战场** | **fMOD = 4.096 MHz 及以上** | **模拟阶梯**（唯一防线） | 采样混叠无法被数字纠正 |

**关键澄清**：抗混叠锚点是 fMOD，不是 64 kHz。64 kHz 只是奈奎斯特折叠边界；64 kHz~fMOD 之间的带由数字滤波器负责，模拟阶梯只需守住 fMOD 及其谐波。

## 4. 架构定稿（不再变更的结构性决策）

```
每线： 跟随器(OPA388)输出 ── R_iso ── 无源RC阶梯(2~4级) ── ADC引脚
每通道(差分对)：两线末级之间跨接 C_diff（兼电荷桶）；每线末级对地 C_cm
通道数：2（CH1 = AIN1P/AIN1N，CH2 = AIN2P/AIN2N），共 4 线，全配同一标准单元
```

已定稿决策（前轮已论证，不再重开）：

1. **四线统一全配**：AIN1N（Rsense 底端低阻参考）也配全阶梯。比值测量精度来自两线对称，失配转 CMRR/增益误差。
2. **跟随器只当缓冲，不进反馈环路**：OPA388 GBW=10 MHz，在 fMOD 主战场环路增益 ~8 dB，Sallen-Key 阻带翘曲，判死。跟随器贡献 = ①把源阻抗从 ≤150 kΩ 压到近零（阶梯电阻可取几百欧）；②阶梯首级电阻兼任其容性负载隔离电阻（一件顶两职）。
3. **末级 C_diff 三职合一**：差分衰减主电容 + ADC 采样电荷桶（容值 ≥ 采样电容 20~50 倍）+ 通道噪声带宽设定。
4. **无源 RC 阶梯**是 fMOD 频段唯一可靠滤波手段（该频率处性能只由 R/C 本身决定）。

## 5. 多维评分标准（核心，用于方案打分排序）

每个候选方案按以下 **10 个评分槽位** 评分（D6 拆为 D6a/D6b 两个子维度，D6b 仅报告不进 min），归一化到 [0,1]，**取最小值**作为总分（短板制——任何一维不及格则整体不及格）。维度权重通过阈值设定体现。**评分主口径 = 真实 OPA388 模型**（第 1 轮复核发现 0Ω 理想源口径在 fMOD 处偏差 16–22 dB，不可用）。

### 5.1a 维度说明（为什么要有 D7–D10）

- **D7 容差敏感度**：扫频测量最怕 fc 漂移——1% R 容差会让不同频率点的增益不一致，直接变成扫频幅值误差。标称值好看没用，要看离散。
- **D8 CMRR @通带**：电阻测量是比值测量，精度依赖两线对称性。两线阶梯失配会把共模电压（T 点约 2 V）转成假差分信号——0.1% 失配 → 2 mV 假信号，对 80 mV 样品信号 = 2.5% 误差。**2026-10-19 修订（R5 第 2 轮求解阶段发现）**：同向 1% 失配下任何拓扑 CMRR 只有 48–49 dB（物理上限），但**两线按 R·C 乘积异向配对**（R 偏大的线配 C 偏小的）可把失配转化为时间常数匹配，1% 单体下达 110–112 dB。考核条件据此改为配对后失配；BOM 须加配对工序要求（实测每对 R、C 值后按乘积配对贴片，或采购配对网络）。
- **D9 Kickback**：ΣΔ ADC 采样电容以 fMOD 速率吞吐电荷，末级网络若回稳不充分，直接变成非线性误差。原先是验证项，提级为正式维度（实际板子最常见翻车点之一）。
- **D10 群延迟**：扫频测相位（复阻抗谱），群延迟不平坦 = 相位失真 = 阻抗角误差。正式维度（用户 2026-10-18 确认）。

### 5.1b D6 拆分的物理依据（2026-10-19，R5 第 2 轮实测）

原 D6（总积分噪声 ≤1 LSB）**物理不可达**：跟随器噪声 9.9 nV/√Hz（OPA388 定稿器件）× D4 要求的 16 kHz 通带决定 ENBW ≥14.3 kHz ⇒ 总噪声 ≥4.3 LSB（理想砖墙极限，实际更高）。1 LSB 阈值相当于要求噪声带宽 ≤864 Hz，与 D4 冲突 16.5 倍。据此拆分：

- **D6a 考核本段可控的部分**：无源阶梯自身的约翰逊噪声增量（跟随器之外新增多少）。阶梯总电阻 ≤5 kΩ（C2）时约翰逊噪声 ~9 nV/√Hz 级但经低通后贡献小，10% 增量是合理要求。
- **D6b 报告总噪声供参考**：4.3 LSB ≈ 1.25 µVrms，对最小信号 80 mV（10 kΩ 样品）是 0.0016%，对测量精度无实质影响；但须报告确认无异常放大（如有源谐振——R5 第 2 轮曾实测到 283 kHz 处 +30.7 dB peaking 把噪声放大 6 倍的案例，见硬约束 C9）。

> ⚠️ **核实后的口径提醒（不阻塞复测）**
>
> sinc³ 在通带内有**固有跌落**：8 kHz **−0.17 dB**、**16 kHz −0.67 dB**（−0.05 dB 点仅 4.37 kHz），
> 属**数字域**衰减，模拟阶梯既无法补偿也不应补偿。
> D4 按 §5.1 定义为「AC 仿真」——即 V1 的**模拟段**（跟随器→阶梯→ADC 引脚）**相对 DC** 的偏差，**本身已不含 sinc³**，口径正确。
> **执行者须守住这条边界**：不得把 D4 扩展成"整链/含数字滤波"的平坦度（那样 16 kHz 处 −0.67 dB 会超阈值 13 倍）；
> 同理，实测端到端频响与 D4 的比对须先反算掉 sinc³ 的固有响应。
> 本条不影响 D1–D3/D5–D10，也不影响 fMOD 与 sinc³ −3 dB 的冲突判据（两项均未超 20%）。

## 6. 候选方案框架（三档，fc 统一在新口径下重评）

| 方案 | 阶数 | 结构 | 预期器件/通道 | 定位 |
|---|---|---|---|---|
| A | 二级 | 2×(R+C_gnd) + C_diff | ~10 件 | 器件最少 |
| B | 三级 | 3×(R+C_gnd) + C_diff | ~14 件 | 折中 |
| C | 四级 | 4×(R+C_gnd) + C_diff | ~18 件 | 衰减最大 |

**定档原则**：不预判档位，三案全部求解、全部评分，以 §5 总分排序定档。若 A 及格（**D1–D10 全过线**）则优先选 A（器件少）；A 不及格再看 B，依此类推。

**注意**：上一战役的 FIN1/V11/V10a 参数是按旧 fc（直流导向，~20-50 kHz）优化的，**本规格下三案全部需要用优化引擎在新 fc 约束（50~80 kHz）+ 新评分口径（加入 D4 平坦度、D6 噪声）下重新求解**，不得直接沿用旧参数。

## 7. 验证方法（LTspice 复测清单）

每个候选方案必须通过以下全部仿真，脚本化、可复现、可分发。**每个评分维度至少有一项仿真覆盖**（对照表右侧）：

| # | 仿真 | 类型 | 目的 | 覆盖维度 |
|---|---|---|---|---|
| V1 | 标称 AC 差分 | .ac | 差分衰减 @fMOD/MCLK、通带平坦度、群延迟 | D1 / D3 / D4 / D10 |
| V2 | 标称 AC 共模 | .ac | 共模衰减 @fMOD | D2 |
| V3 | 失配角 AC 共模 | .ac（两线阶梯 1% 失配） | CMRR @通带 | D8 |
| V4 | 最坏角瞬态建立 | .tran（R/C 容差角 + 600 kΩ 高源阻抗工况） | 建立时间 | D5 |
| V5 | 蒙特卡洛 AC 30 次 | .ac（R/C 容差随机） | 通带增益离散 σ_ΔG | D7 |
| V6 | 蒙特卡洛瞬态 30 次 | .tran（R/C 容差随机） | 建立时间统计稳健性 | D5 补充 |
| V7 | 噪声 | .noise + 积分 0.1 Hz~fMOD/2 | 积分噪声 | D6 |

**维度-仿真覆盖矩阵自检**：D1→V1，D2→V2，D3→V1，D4→V1，D5→V4+V6，D6→V7，D7→V5，D8→V3，D9→V8，D10→V1。十维全覆盖，无遗漏。

**ADC 采样开关模型（V8）构建规范**：采样电容 C_s 与开关电阻 R_sw 取自手册（M2/M6）；开关以 fMOD 频率、手册给定的采样占空比通断；判稳窗口 = fMOD 半周期（@4.096 MHz = 122 ns）；判据 = 回稳到稳态值 0.01% 带内。若手册未给 R_sw/时序，用 LTspice 默认开关（Ron=1 Ω）+ C_s 建模，并在报告中明示假设。

**模型要求**：V9 必须使用 TI 官方 OPA388 SPICE 模型（非理想压控源），以捕捉 GBW=10 MHz 在通带/阻带交界处的二阶效应。
