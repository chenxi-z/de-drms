# 抗混叠与采集驱动子系统设计规格（跟随器输出 → ADC 输入）

- **文档状态**：待用户审阅（DRAFT v1）
- **日期**：2026-10-18
- **作用域**：信号链四个测量点出口之后、含跟随器、至 ADS131A02 引脚入口的完整子系统
- **上游约束**：`docs/design/2026-10-10-universal-signal-chain.md` 附录 E（E.2 前端、E.4 ADC）、`docs/design/pin-assignment.md`
- **冲突仲裁**：本规格与附录 E 冲突时，以附录 E 为准并提请用户修订本规格

---

## 1. 设计目标（一句话）

在 128 kSPS 输出码率下，把直流 + 单相正弦叠加信号（正弦分量 ≤16 kHz）完整、平坦、低噪地送达 ADS131A02 采样电容，同时对 fMOD=4.096 MHz 及以上的混叠源提供远超物理底的衰减。

## 2. 信号规格（输入条件）

| 项 | 值 | 来源 |
|---|---|---|
| 信号类型 | 直流电平 + 单相正弦叠加（不换向） | 用户 2026-10-18 确认 |
| 直流测量对象 | 设计量程 10–120 kΩ（≤0.005%）；1% 可用范围 ~73 Ω–600 kΩ（下限 = K2 漏电恒定 −0.73 Ω 偏置；上限 = 比值机制把恒流合规墙 215 kΩ 推到 ADC 满量程处，600 kΩ 时电流自动跌落、比值抵消，E.3.4 fs4/fs6 实测） | 附录 E.3.4 |
| 正弦分量频率上限 | **16 kHz**（每周期 8 点 @128 kSPS，实用下限） | 用户 2026-10-18 确认 |
| 精密扫频工作区 | ≤8 kHz（每周期 ≥16 点） | 推导 |
| 激励 | 8 µA 恒流（直流模式）；正弦激励模式为将来扩展，本段不感知激励极性 | 附录 E |
| 满量程 | ±2.442 V（ADS131A02 内部基准） | 附录 E.4 |

### 2.1 每周期点数判据（128 kSPS 下）

| 频率 | 每周期点数 | 判定 |
|---|---|---|
| 2 kHz | 64 | 波形级还原 |
| 8 kHz | 16 | 精密扫频（幅值 <1% 误差） |
| **16 kHz** | **8** | **实用下限（幅值 <5% 误差）——设计上限** |
| 32 kHz | 4 | 不可用（幅值误差 ~30%） |
| 64 kHz | 2 | 香农极限，工程不可用 |

## 3. 频率规划（三层分工）

| 层 | 频段 | 责任人 | 手段 |
|---|---|---|---|
| 通带 | DC ~ 16 kHz | 模拟阶梯让路 | fc = 50~80 kHz（给 16 kHz 留 3~5 倍余量） |
| 过渡带 | 16 kHz ~ 64 kHz | 模拟 + 数字共同 | 模拟平缓滚降 + sinc³ 数字滤波器 |
| 数字阻带 | 64 kHz ~ fMOD | **sinc³ 数字滤波器**（OSR=32） | fMOD 谐波处深陷波 |
| **模拟主战场** | **fMOD = 4.096 MHz 及以上** | **模拟阶梯**（唯一防线） | 采样混叠无法被数字纠正 |

**关键澄清**：抗混叠锚点是 fMOD，不是 64 kHz。64 kHz 只是奈奎斯特折叠边界；64 kHz~fMOD 之间的带由数字滤波器负责，模拟阶梯只需守住 fMOD 及其谐波。

## 4. 架构定稿（不再变更的结构性决策）

```
每线： 跟随器(OPA388)输出 ── R_iso ── 无源RC阶梯(2~4级) ── ADC引脚
每通道(差分对)：两线末级之间跨接 C_diff（兼电荷桶）；每线末级对地 C_cm
通道数：2（CH1 = AIN1P/AIN1N，CH2 = AIN2P/AIN2N），共 4 线，全配同一标准单元
```

已定稿决策（前轮已论证，不再重开）：

1. **四线统一全配**：AIN1N（Rsense 底端低阻参考）也配全阶梯。比值测量精度来自两线对称，失配转 CMRR/增益误差。
2. **跟随器只当缓冲，不进反馈环路**：OPA388 GBW=10 MHz，在 fMOD 主战场环路增益 ~8 dB，Sallen-Key 阻带翘曲，判死。跟随器贡献 = ①把源阻抗从 ≤150 kΩ 压到近零（阶梯电阻可取几百欧）；②阶梯首级电阻兼任其容性负载隔离电阻（一件顶两职）。
3. **末级 C_diff 三职合一**：差分衰减主电容 + ADC 采样电荷桶（容值 ≥ 采样电容 20~50 倍）+ 通道噪声带宽设定。
4. **无源 RC 阶梯**是 fMOD 频段唯一可靠滤波手段（该频率处性能只由 R/C 本身决定）。

## 5. 多维评分标准（核心，用于方案打分排序）

每个候选方案按以下 **10 维度** 评分，归一化到 [0,1]，**取最小值**作为总分（短板制——任何一维不及格则整体不及格）。维度权重通过阈值设定体现。

### 5.1 评分维度表

| # | 维度 | 符号 | 测量/计算方法 | 满分阈值（得 1.0） | 及格线（越线淘汰） | 归一化方式 |
|---|---|---|---|---|---|---|
| D1 | **DM 衰减 @fMOD** | A_dm | AC 仿真，差分激励，4.096 MHz 处增益 | ≥120 dB | <80 dB | `min(A_dm/120, 1)` |
| D2 | **CM 衰减 @fMOD** | A_cm | AC 仿真，共模激励，4.096 MHz 处增益 | ≥100 dB | <60 dB | `min(A_cm/100, 1)` |
| D3 | **DM 衰减 @MCLK** | A_mclk | AC 仿真，16.384 MHz 处增益（晶振泄漏路径） | ≥150 dB | <100 dB | `min(A_mclk/150, 1)` |
| D4 | **通带平坦度 @16 kHz** | ΔG | AC 仿真，16 kHz 处增益相对 DC 的偏差绝对值（dB） | ≤0.05 dB | >0.5 dB | ΔG≤0.05 得 1.0；0.05<ΔG≤0.5 线性插值 `1 − (ΔG−0.05)/0.45` |
| D5 | **建立时间（最坏角）** | t_s | 瞬态仿真，0.01% 建立带，1%R + C 容差最坏角；**测试须覆盖高源阻抗工况（样品 600 kΩ 端）** | ≤500 µs | >900 µs | `min(500/t_s, 1)` |
| D6 | **积分噪声 @ADC 引脚** | V_n | AC 噪声仿真，积分 0.1 Hz~fMOD/2，对比 LSB | ≤0.3 LSB | >1 LSB | `min(0.3/V_n[LSB], 1)` |
| D7 | **容差敏感度 @通带** | σ_ΔG | 蒙特卡洛 AC 30 次（R 1% + C 容差随机），16 kHz 处增益偏差的标准差 | ≤0.01 dB | >0.05 dB | σ≤0.01 得 1.0；0.01<σ≤0.05 线性插值 `1 − (σ−0.01)/0.04` |
| D8 | **CMRR @通带** | CMRR_pb | AC 仿真，共模注入测差分输出，10 Hz~16 kHz 最差值（两线阶梯 1% 失配角） | ≥100 dB | <80 dB | `min(CMRR_pb/100, 1)` |
| D9 | **Kickback 回稳** | t_kb | 瞬态 + ADC 采样开关模型，fMOD 半周期（122 ns）内回稳到 0.01% 带内 | 完全回稳 | 半周期内未回稳淘汰 | 二值：回稳 1.0 / 未回稳 0 |
| D10 | **群延迟平坦度 @通带** | Δτ | AC 仿真群延迟，0.1~16 kHz 变化量 | ≤1 µs | >5 µs | Δτ≤1 得 1.0；1<Δτ≤5 线性插值 `1 − (Δτ−1)/4` |

**总分 = min(D1..D10)**。所有 AC 仿真在标称值下进行；D5/D7/D8 在容差角下进行。

**单位约定**：LSB = 2 × 2.442 V / 2²⁴ ≈ **291 nV**（双极性满量程跨度计算）；dB 均为 20log₁₀(电压比)。

**标准测试条件**（V1–V7 共用，执行者不得改动）：

| 项 | 规定值 | 说明 |
|---|---|---|
| 共模激励 | AC 幅度 1 V，直流偏置 2.0 V | 直流偏置取 T 点实际共模电平（E.3：T ≈2.97 V、M ≈2–3 V，取 2.0 V 代表通带内最不利工况）；D2/D8 统一用此 |
| 差分激励 | AC 幅度 1 V（差分），直流偏置同上 | D1/D3/D4 |
| 源阻抗（V1–V6 理想源阶段） | 0 Ω（跟随器闭环输出近似） | V7 真实 OPA388 模型阶段自动覆盖非理想源阻抗 |
| 温度 | 标称 25 ℃；另报 −20 ℃ / +85 ℃ 两角的 D4/D7 趋势（C0G ±30 ppm/℃、电阻按选型温漂代入） | 不做全维度温度角，只看通带相关项 |
| 高源阻抗工况（仅 D5） | 样品 600 kΩ 端（1% 可用范围上限） | 建立时间最坏情况 |

> **D10 为正式评分维度**（用户 2026-10-18 确认：扫频就是为了测相位/复阻抗谱）。群延迟不平坦 = 相位失真 = 阻抗角误差，直接吃掉扫频的核心产出。判据参考：Δτ=1 µs @16 kHz 相当于全通带相位离散 ±5.8°，阈值按此锚定。
>
> **相位测量的进一步含义**：既然要测相位，通道间（CH1 vs CH2）的群延迟**匹配**同样关键——相位是 V_sample 与 V_Rsense 两通道的相对值，通道间延迟差直接变成相位误差。此项由四线统一全配（§4 决策 1）+ D7/D8 的失配考核覆盖；复测时须在报告中单列"CH1 vs CH2 群延迟差 @通带"数据供核查。

### 5.1a 维度说明（为什么要有 D7–D10）

- **D7 容差敏感度**：扫频测量最怕 fc 漂移——1% R 容差会让不同频率点的增益不一致，直接变成扫频幅值误差。标称值好看没用，要看离散。
- **D8 CMRR @通带**：电阻测量是比值测量，精度依赖两线对称性。两线阶梯失配会把共模电压（T 点约 2 V）转成假差分信号——0.1% 失配 → 2 mV 假信号，对 80 mV 样品信号 = 2.5% 误差。这是一阶影响，必须考核。
- **D9 Kickback**：ΣΔ ADC 采样电容以 fMOD 速率吞吐电荷，末级网络若回稳不充分，直接变成非线性误差。原先是验证项，提级为正式维度（实际板子最常见翻车点之一）。
- **D10 群延迟**：扫频若测相位（复阻抗谱），群延迟不平坦 = 相位失真。**若只测幅值（|Z| 谱），本条降级为参考项不参与评分**——待用户确认。

## 6. 候选方案框架（三档，fc 统一在新口径下重评）

| 方案 | 阶数 | 结构 | 预期器件/通道 | 定位 |
|---|---|---|---|---|
| A | 二级 | 2×(R+C_gnd) + C_diff | ~10 件 | 器件最少 |
| B | 三级 | 3×(R+C_gnd) + C_diff | ~14 件 | 折中 |
| C | 四级 | 4×(R+C_gnd) + C_diff | ~18 件 | 衰减最大 |

**定档原则**：不预判档位，三案全部求解、全部评分，以 §5 总分排序定档。若 A 及格（**D1–D10 全过线**）则优先选 A（器件少）；A 不及格再看 B，依此类推。

**注意**：上一战役的 FIN1/V11/V10a 参数是按旧 fc（直流导向，~20-50 kHz）优化的，**本规格下三案全部需要用优化引擎在新 fc 约束（50~80 kHz）+ 新评分口径（加入 D4 平坦度、D6 噪声）下重新求解**，不得直接沿用旧参数。

## 7. 验证方法（LTspice 复测清单）

每个候选方案必须通过以下全部仿真，脚本化、可复现、可分发。**每个评分维度至少有一项仿真覆盖**（对照表右侧）：

| # | 仿真 | 类型 | 目的 | 覆盖维度 |
|---|---|---|---|---|
| V1 | 标称 AC 差分 | .ac | 差分衰减 @fMOD/MCLK、通带平坦度、群延迟 | D1 / D3 / D4 / D10 |
| V2 | 标称 AC 共模 | .ac | 共模衰减 @fMOD | D2 |
| V3 | 失配角 AC 共模 | .ac（两线阶梯 1% 失配） | CMRR @通带 | D8 |
| V4 | 最坏角瞬态建立 | .tran（R/C 容差角 + 600 kΩ 高源阻抗工况） | 建立时间 | D5 |
| V5 | 蒙特卡洛 AC 30 次 | .ac（R/C 容差随机） | 通带增益离散 σ_ΔG | D7 |
| V6 | 蒙特卡洛瞬态 30 次 | .tran（R/C 容差随机） | 建立时间统计稳健性 | D5 补充 |
| V7 | 噪声 | .noise + 积分 0.1 Hz~fMOD/2 | 积分噪声 | D6 |
| V8 | Kickback 回稳 | .tran + ADC 采样开关模型（参数来自 M2/M6） | fMOD 半周期内回稳判定 | D9 |
| V9 | 真实 OPA388 模型 | 替换理想源后重跑 V1/V2/V4/V7 | 跟随器非理想性影响（GBW、输出阻抗随频率） | 全部交叉验证 |

**维度-仿真覆盖矩阵自检**：D1→V1，D2→V2，D3→V1，D4→V1，D5→V4+V6，D6→V7，D7→V5，D8→V3，D9→V8，D10→V1。十维全覆盖，无遗漏。

**ADC 采样开关模型（V8）构建规范**：采样电容 C_s 与开关电阻 R_sw 取自手册（M2/M6）；开关以 fMOD 频率、手册给定的采样占空比通断；判稳窗口 = fMOD 半周期（@4.096 MHz = 122 ns）；判据 = 回稳到稳态值 0.01% 带内。若手册未给 R_sw/时序，用 LTspice 默认开关（Ron=1 Ω）+ C_s 建模，并在报告中明示假设。

**模型要求**：V9 必须使用 TI 官方 OPA388 SPICE 模型（非理想压控源），以捕捉 GBW=10 MHz 在通带/阻带交界处的二阶效应。
