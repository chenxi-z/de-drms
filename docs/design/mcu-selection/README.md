## 1 选型需求

| 需求 | 说明 |
| --- | --- |
| USB | USB FS（设备）以上，用于上位机通信与数据上传 |
| **大 RAM** | 支持"大内存计算"（用户提出），需显著大于 G4 的 32 KB |
| 低功耗 | 手持便携、锂电供电；用户明确"倾向低功耗设计，做一次尝试" |
| SPI / I²C | SPI↔ADS131A02（ADC）、I²C↔TMP117（温度） |
| 定时器 | 触发 ADC 转换、控制模拟开关/校准切换 |
| 存储 | 校准系数持久化（Flash EEPROM 仿真即可） |
| 封装 | 手持设备，优先 7×7 或 10×10 mm |
| 不需要 | G4 那类内置运放/比较器/12 bit ADC（模拟前端为外置专用高精度方案） |

### 2.1 关键发现

1. **SRAM 分水岭明显**：G431 仅 32 KB；U535/U545 为 160–274 KB；**U575 为 786 KB**。
   用户要求"大内存"，G431 直接出局。
2. **U5 系列普遍缺货**：查询时 U535 库存 21、U545 各变体库存 0，
   **只有 U575RGT6 库存 64**（相对可用）；后定版改为 **RET6Q**（SMPS 版，同封装 pin-to-pin 兼容）。
3. **U5 同时满足"低功耗尝试"与"大内存"**，把用户先后提出的两个目标统一了。
4. **RET6Q 相比 RGT6 低功耗更优**（SMPS 版 Shutdown 0.16 µA vs LDO 版 0.64 µA），本设计用外部双 LDO 供电、内部 SMPS 未启用，但 SMPS 版在其它应用场景可进一步省电。

## 3 决策：STM32U575RET6Q

**理由**：

- **786 KB SRAM** 满足大内存需求，是 G431 的 24 倍；
- **U5 旗舰低功耗**（VDD 3.3 V、25 ℃ 典型：Shutdown 0.16 µA，Standby 0.21 µA，Stop 3 1.9 µA（8 KB SRAM2）/ 4.3 µA（全 SRAM），
  DS13737 表 64/67/69；SMPS 版数据），契合低功耗目标；
- **USB OTG FS**（设备/主机/OTG）满足通信，比纯设备模式灵活；
- **1 MB Flash** 容纳固件 + 校准系数 + 数据缓存；
- **LQFP-64（10×10 mm）** 引脚充裕、好焊；
- **与 RGT6 pin-to-pin 兼容**（同封装同引脚，仅内部电源架构不同：RET6Q 带 SMPS，RGT6 不带），本设计用外部双 LDO 供电，两种型号均可使用同一 PCB；
- 模拟前端为外置专用方案，**G4 的内置模拟外设对本设计是冗余**，选 G4 不为这些买单。

**放弃理由**：

- **STM32G431CBU6**：RAM 仅 32 KB，不满足大内存（但其生态最成熟、库存最足，可作降级备选）；
- **STM32U535**：RAM 较小、价格最高、库存少；
- **STM32U545**：RAM 274 KB 居中、价格合理，但**查询时库存为 0**（若能买到，是性价比备选）。

## 4 pin-to-pin 兼容性（重要结论）

**STM32U5 与 STM32G4 之间没有官方 pin-to-pin 兼容的型号对。**
经逐引脚比对官方数据手册（**STM32U535: DS14217** / **STM32U545: DS14216** /
**STM32G431: DS12589** / **STM32G474: DS12288** / **STM32G491: DS13122**；
五个编号均经 ST 官方 PDF 页脚逐一核对）：

> 注：上列 5 份是本次逐引脚比对所依据的手册。
> **本设计定版型号 STM32U575xx 的手册号是 `DS13737`（Rev 10），与 U535 的 `DS14217` 不同，勿混淆**；
> U575 未参与上述 U5↔G4 的逐引脚比对。

- ST 未发布 U5↔G4 迁移应用笔记（AN5371 是 L5→U5、AN5766 是 U5 系列内、AN5094 是 F3→G4）；
- 最接近的是 **UFQFPN48 下 U535 ↔ G431**，但存在致命冲突：
  **pin21 在 U5 上是 VCAP（内核 LDO 输出，须接 4.7 µF 到地，禁止外供电），
  在 G4 上是 VDDA（须接模拟电源）**——直接互换会损坏 U5 或使 G4 模拟部分断电；
- 另有 pin20（PB2 vs VREF+）、pin5/6（PH0/PH1 vs PF0/PF1 振荡器）、BOOT0 脚位差异；
- LQFP48/LQFP64 下电源引脚整体错位，更无法互换。

**结论：不存在"PCB 一次设计、U5/G4 互换"的方案，本设计按 U575RET6Q 单一定版。**
若未来需要降级到 G4，必须重新设计 PCB。
