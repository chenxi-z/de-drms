## 2. 介质与 C2/C3/C4/C5 合规

| 约束 | 要求 | B 案冻结现状 | 判定 |
|---|---|---|---|
| **C2** 每线串联电阻总和 | ≤5 kΩ | **25.93 Ω** | ✅ 余量 193× |
| **C3** 单电容最大值 | ≤100 nF | **68 nF** | ✅ 余量 1.47× |
| **C3 附则** >47 nF 的 SRF | > fMOD（4.096 MHz） | 68 nF：SRF（ESL 1.2 nH）**15.8 MHz > 4.096 MHz** | ✅ 见 §3 |
| **C4** 介质 | 必须 C0G/NP0（或薄膜） | 68 / 68 / 27 / 12 nF 全 C0G | ✅ 可满足（68 nF 是 C0G 常见上限档，0603/0805 有货） |
| **C5** 电阻精度 | 1 % 起步，关键位 0.1 %；**两线 R·C 乘积配对** | R 全 0.1 % 薄膜；配对工序见 §5 | ✅（工序为前置条件） |
| **C9** 首级 R / C1 | R 不得小、C1 不得大 | **R1 ≥ 6.19 Ω、C1 ≤ 68 nF** | ⚠️ 见 §4.3 |

### 2.1 68 nF C0G 的可购性

- 68 nF 是 C0G 的**常见档**，0603（50 V）/ 0805（50/100 V）/ 1206 均有量产。
- **建议 0603**：ESL 0.5–0.9 nH，SRF 19.3–27.3 MHz，对 fMOD 有 4.7–6.7 倍余量。
- **不接受 X7R/X5R**：直流偏压与压电效应（C4 明令）；且容值随电压掉 30–50 % 会直接击穿 D7/D8。
- **容差**：C0G 常见 ±5 %。实测（`r5_r4_c9_sensitivity.json`）**C+5 % 本身不恶化 C9**
  （Rs=60 kΩ：5.813 dB vs 标称 5.817 dB，略降）；**真正的不利方向是 R 偏小**——
  R−0.1 %/C+5 % 时 5.820 dB、R−1 %/C+5 % 时 **5.883 dB**。故 **C 建议 ±5 % 实测筛选**（不必买 ±2 %），
  **R 必须 0.1 %**。
- **C1 的偏离方向**（`r5_r4_B_c1_direction.json`，R1=6.19 固定）：

  | C1 | C9 最坏峰 | D4 | D1 |
  |---|---|---|---|
  | 62 nF（−8.8 %） | **5.688 dB** | 0.1813 dB | 83.85 dB |
  | **68 nF（冻结）** | 5.817 dB | 0.1849 dB | 84.64 dB |
  | 75 nF（+10 %） | **5.939 dB** | 0.1892 dB | 85.49 dB |

  → **C1 变小同时改善 C9 与 D4，但牺牲 D1**（62 nF 时 D1 = 83.85 dB，距 80 dB 及格线只剩 3.85 dB）；
  **C1 变大则 C9 与 D4 两项都恶化**。
  工艺卡应写「**C1 ∈ [62, 68] nF，不得 >68 nF**」，而不是"标称 68 nF ±5 %"。
  **C1 与 R1 的联合容差角（C1 取下限 + R1 取上限）本轮未测**，若采购到这类组合需补测 D1。

## 3. >47 nF 电容的 SRF 核查（C3 强制项）

### 3.1 逐容值：容抗与临界 ESL

|---|---|---|---|---|

| **27 nF**（B·C3） | 1.439 Ω | 0.360 Ω | 55.9 nH | 3.49 nH |
| **12 nF**（B·Cd） | 3.238 Ω | 0.810 Ω | 125.8 nH | 7.86 nH |

### 3.2 SRF 随封装 ESL 的实测范围（0603 0.5–0.9 nH / 0805 ≈0.9 / 1206 ≈1.2 nH）

| C | ESL 0.5 nH | ESL 1.0 nH | ESL 1.5 nH | ESL 2.0 nH |
|---|---|---|---|---|
| **68 nF** | 27.3 MHz | **19.3 MHz** | 15.8 MHz | 13.6 MHz |
| 27 nF | 43.3 MHz | 30.6 MHz | 25.0 MHz | 21.7 MHz |
| 12 nF | 65.0 MHz | 45.9 MHz | 37.5 MHz | 32.5 MHz |

### 3.3 判定

| 项 | B 案 | 判定 |
|---|---|---|
| 含 >47 nF 的容值 | **68 nF × 2（每线，C1/C2）** | — |
| 0603（0.9 nH）下的 SRF | **19.3 MHz** | ✅ **> fMOD 4.7×**，也 > MCLK 1.18× |
| 0805（1.2 nH）下的 SRF | 15.8 MHz | ✅ > fMOD 3.9×（略低于 MCLK，但 C3 只要求 > fMOD） |
| 1206（≈1.2–1.5 nH）下的 SRF | 17.6–13.0 MHz | ✅ > fMOD 3.2–4.3×，仍满足 C3；**不推荐**（靠近 MCLK） |
| **推荐封装** | **0603**（或 0805） | **接地回路 <3 mm + 多过孔**（§3.4） |

### 3.4 共同要求

1. **PCB 走线电感必须计入**：0402 的 0.4 nH 器件 ESL 容易被 2–3 mm 走线（≈1 nH/mm）翻倍。
   **C1（68 nF）的接地回路应短于 3 mm**，并用多个过孔。
2. **不许用 2×33 nF 并联替代 68 nF**：并联降 ESL 但改变 SRF 以上的容性行为，
   且**会改变 D8 的配对基线**（每线变 2 个电容，配对对象翻倍）——**需重新仿真，本表未验证**。
3. **样机阶段实测 SRF / ESR**（网络分析仪或阻抗分析仪），把实测值回填仿真。
4. **ESR 优先级高于 ESL**：§4.2 显示 ESR 0.02→0.10 Ω 会让 D3 掉 15.4 dB，
   而 ESL 增大在同范围内反而**抬高** D1/D3（不是稳健增益，见 §4.2 第 2 条）。

## 4. ESL / ESR 敏感性（**本轮按冻结参数重跑**）

### 4.1 方法与口径

- 网表：`r5_work/r4_B/r5_B_r4_besl_{ESL}_{ESR}.net`，**真实 OPA388 模型**（`lib/OPAx388.LIB`），
  **L 只串在每个电容支路**（`Ra_i → 节点 → La_i → Ca_i → 0`），与第 3 轮 BOM 网表同构；
  C_diff 两侧各 1×ESL（即跨接件共 2×ESL），ESR 用 LTspice `C ... Rser=`。
- 数据：`r5_bom_esl_esr_r4.json`（机器可读）。
- 命令：`LTspice.exe -b -ascii <net>`，`.ac dec 400 0.1 200Meg`。

### 4.2 实测结果（B 案冻结参数）

| ESL | ESR | **D1 @fMOD** | **D3 @MCLK** | D4 @16 kHz |
|---|---|---|---|---|
| 0（理想） | 0 | **84.647** | **132.568** | 0.18489 |
| 0.5 nH | 0 | 85.109 | 141.588 | 0.18489 |
| **1.0 nH** | 0 | **85.581** | **157.454** | 0.18489 |
| 1.5 nH | 0 | 86.064 | **180.694** | 0.18489 |
| 2.0 nH | 0 | 86.557 | 153.606 | 0.18489 |
| 1.0 nH | **0.02 Ω** | 85.642 | 155.394 | 0.18508 |
| 1.0 nH | **0.10 Ω** | 85.643 | **140.014** | 0.18583 |
| 2.0 nH | 0.10 Ω | 86.591 | 141.846 | 0.18583 |

### 4.3 结论（B 案专属）

1. **ESL 对 D1 是单调轻微改善**（84.65 → 86.56 dB @2 nH）：fMOD 远低于所有 SRF，
   +jωL 只是略微增加串联阻抗。
2. **D3 在 ESL ≈ 1.5 nH 附近有窄带峰**（180.7 dB），**这不是稳健增益**：
   0.5 nH 时 141.6 dB、2.0 nH 时 153.6 dB。**量产不能把"落在峰上"当设计依据**；
   **但最差点 132.57 dB（ESL=0）仍远高于 100 dB 及格线**，所以 ESL 对 B 不构成风险。
3. **ESR 是一阶敏感项，但 B 的余量足够**：ESL 固定 1 nH，ESR 0.02 → 0.10 Ω 使
   **D3 155.4 → 140.0 dB（−15.4 dB）**；配合最坏 ESL=0 的本底 132.57 dB，
   **本轮 8 个组合里最低的 D3 = 132.568 dB（ESL = 0、ESR = 0 的理想基准，即最差情况）**，限 100 dB，余量 32.6 dB。**D1 几乎不动（+0.15 dB）**。
4. **D4 对 ESL/ESR 几乎不敏感**（0.18489 → 0.18583 dB，变化 0.0009 dB）——因为 ESL/ESR
   的影响集中在 fMOD 附近，而 D4 在 16 kHz。
5. **C9（首级谐振）与 ESL 的耦合**：本表 ESL 只串在电容支路，**首级 68 nF + 6.19 Ω 的
   跟随器峰对 ESL 不敏感**（谐振频率 279 kHz ≪ SRF 19 MHz）——C9 的余量问题
   来自 **R/C 的容差，不是 ESL**（§4.3 末表）。

**BOM 要求**：
- **Ra1/Rb1 精度必须 0.1 %（薄膜，E96 6.19 Ω）**——用 1 % 料会把 C9 余量从 0.18 dB 压到 0.12 dB；

## 5. **R·C 配对工序要求（D8 的达标前提）**

> 本章是规格 v4 §5.1a / §5.2 C5 的**落地工序**。D8 的达标前提不是"买高精度料"，
> 而是"**每对电阻电容实测后按乘积异向配对贴片**"。

### 5.1 为什么必须是"配对"而不是"高精度"（B 案实测）

第 4 轮实测（`r5_results_r4_B.json` 的 `D8_detail`，真实 OPA388，LTspice）：

| m（单体失配） | **同向失配**（无配对） | **R·C 异向配对** | 配对收益 |
|---|---|---|---|
| 0.1 % | — | **136.884 dB** | — |
| 0.5 % | — | **108.755 dB** | — |
| **1 %** | **48.338 dB** | **95.515 dB** | **+47.18 dB** |

- **同向 1 % 失配的物理上限是 48–49 dB**（与规格 §5.1a 记载一致），**远低于 80 dB 及格线**。
- **只要把 R 偏大的线与 C 偏小的线配成一对（乘积配对），1 % 单体料也能到 95.5 dB**。
- 这不是"买 0.01 % 电阻"能替代的：0.01 % 同向失配也只有约 88 dB（−20 dB/decade 外推），
  而**配对后 0.1 % 单体就能到 136.9 dB**。

### 5.2 工序定义（可照抄进工艺文件；B 案专用数字）

**术语**：一个"标准单元" = 一条线上的 **3 个 R + 3 个 C_gnd**（B 案是三级）；
`C_diff`（12 nF）跨接两线，**不参与逐线配对**（见 §5.6）。

```
步骤 1  入库实测
        每批 R、C 逐件用 4½ 位以上 LCR 表实测，记录到配对表：
            R_meas（Ω）、C_meas（F）、测量温度、仪表编号
        测量条件：1 kHz（C）、DC 四线（R < 100 Ω 必须四线）

步骤 2  计算乘积
        对每个标准单元 i、每一级 k：
            p_ik = R_meas,ik × C_meas,ik        （k = 1,2,3）

步骤 3  异向配对（核心）
        把 4 套标准单元（CH1P / CH1N / CH2P / CH2N）两两配对：
            选 (i, j) 使 max_k |p_ik − p_jk| / p_ik 最小
            —— 即 R 偏大的配 C 偏小的
        配对目标（1 % 单体料）：
            逐级 |Δ(RC)/RC| ≤ 1×10⁻⁴（0.01 %）   → 实测 CMRR ≈ 95.5 dB
            逐级 |Δ(RC)/RC| ≤ 2.5×10⁻⁵（0.0025 %）→ 实测 CMRR ≈ 108.8 dB
            逐级 |Δ(RC)/RC| ≤ 1×10⁻⁶（0.0001 %）  → 实测 CMRR ≈ 136.9 dB

步骤 4  贴片
        按配对结果贴装，**同一对必须贴在同一通道的两条腿上**
        （CH1: Ra1–Ra3 / Rb1–Rb3；CH2: 另两套）。配对表随板归档，与 SN 绑定。

步骤 5  复检
        贴装后测两线对地电容与串联电阻（治具），复核三级 RC 乘积仍在容差内；
        整机做一次共模注入测试（DC 2 V ± 1 V，10 Hz–16 kHz），
        实测 CMRR 应 ≥ 90 dB（留 5 dB 余量对 95.5 dB 仿真值）。
```

### 5.3 配对精度的量化要求（B 案实测锚点）

| 单体失配 m | 配对后**残余 RC 乘积失配** | 实测 CMRR（B） | 相邻档斜率 |
|---|---|---|---|
| 1 % | **0.0100 %** | **95.515 dB** | — |
| 0.5 % | 0.0025 % | 108.755 dB | +22.0 dB/decade |
| 0.1 % | 0.0001 % | 136.884 dB | +20.1 dB/decade |

（字面配对 `R×(1+m)` 配 `C×(1−m)` 的残余乘积误差是 **m²**：1 %→0.01 %、0.5 %→0.0025 %、0.1 %→0.0001 %。）

**反解**（锚定实测的 0.01 % → 95.515 dB，按 **20 dB/decade**）：

| 目标 CMRR | **需要的 RC 乘积匹配** | 等效单体失配 m |
|---|---|---|
| 80 dB（及格线） | ≤ **0.060 %** | 2.44 % |
| 90 dB | ≤ 0.019 % | 1.38 % |
| **95.5 dB（1 % 单体 + 配对实测）** | **0.010 %** | **1.00 %** |
| 100 dB（满分线） | ≤ 0.0060 % | 0.77 % |
| 110 dB | ≤ 0.00060 % | 0.24 % |
| 136.9 dB（0.1 % 单体 + 配对实测） | 0.0001 % | 0.10 % |

**关键推论**：

1. **1 % 单体料 + 配对（残余 0.01 %）落在 95.5 dB**，与实测吻合 —— 这是"1 % 料就能过线"的定量依据。
2. 想要 **100 dB 满分**，只需**单体失配 ≤0.77 %**（残余 0.006 %）——**不必买 0.1 % 电阻**，
   1 % 料筛到 0.8 % 以内即可（E24 厚膜实测分布通常 ±1 %，筛选合格率约 60–70 %）。
3. **B 案实际用的是 0.1 % 薄膜 R**（为了 C9 的余量，见 §4.4）——这使配对更容易：
   0.1 % 单体料配对后可到 **136.9 dB**（远超 100 dB 满分线），**D8 因此不是 B 的短板**。
4. **想要 110 dB 以上必须严格倒数配对**（C/(1+m)）或 0.1 % 单体档 + 配对。

### 5.4 若采用严格倒数配对（B 案第 3 轮实测：110.43 dB）

规格 v4 §5.1a 引用的 "110–112 dB" 对应 `C/(1+m)`（严格倒数）而非 `C×(1−m)`。
第 3 轮 B 案（旧参数）1 % 严格倒数 = **110.43 dB**（vs 字面 95.65 dB）。**本轮未对冻结参数重测该口径**
（`r5_results_r4_B.json` 的 D8 只做字面配对三档 + 同向 1 %）。

**实现方式**：C 不能"按标称值筛"，只能**用可调/并联微调**：
- 方案 A：每个 C_gnd 位并联一个 0–2 pF 微调电容（C0G 或薄膜），贴片后调到目标值；
- 方案 B：**采购 0.1 % 单体 C**（C0G 的 0.1 % 档极贵且交期长），再按 §5.2 配对。

**成本对比**：方案 A 的微调工时 vs 方案 B 的采购成本，**需用户裁决**。

### 5.6 C_diff 的处理（易错点）

**C_diff 是跨接两线的共享件，不能"每线各贴一个"**。
B 案冻结网表（`r5_work/r4_B/r5_B_r4_v1.net`）里：**`Cd pa3 na3 1.2e-08`（单个，跨接）**。
即**配对只作用于每条腿上的 R 与 C_gnd**。
**如果误把 C_diff 也按"两条腿各一份"配对，会把共享件拆成两个串联电容，容值减半、D8 基线改变**。
