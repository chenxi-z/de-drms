> **没有方案达到 min = 1.0**。

### 0.1 为什么"min ≥ 1.0"在本规格下对 B 案不可达（不只是 D4 的问题）

B 案的十维按分数升序排列：

| 排序 | 维度 | 分数 | 达标所需 | 现实测 | 距离 |
|---|---|---|---|---|---|
| 1 | **D4** | **0.7003** | ≤0.05 dB | 0.1849 dB | 差 0.135 dB |
| 2 | **D1** | **0.7054** | ≥120 dB | 84.64 dB | 差 35.36 dB |
| 3 | D2 | 0.7917 | ≥100 dB | 79.17 dB | 差 20.83 dB |
| 4 | D3 | 0.8838 | ≥150 dB | 132.56 dB | 差 17.44 dB |
| 5 | D8 | 0.9551 | ≥100 dB | 95.51 dB | 差 4.49 dB |
| 6–10 | D5/D6a/D7/D9/D10 | 1.0000 | — | — | 0 |

→ **即使把 D4 的满分线放宽到 0.20 dB（B 的 D4 直接拿 1.0），min 也只会升到 0.7054
（D1 成为新短板）**，仍然远不到 1.0。

要让 B 达到 min = 1.0，必须**同时**满足 D1 ≥120 dB、D2 ≥100 dB、D3 ≥150 dB、D4 ≤0.05 dB
（D8 ≥100 dB 可以通过更紧的配对实现：0.5 % 单体配对已达 108.8 dB）。
**而 D1/D2/D3 与 D4 是同一个 fc 的两端**：D1 再增 35 dB（120−84.64）对三阶滚降
（≈60 dB/decade）要求 fc 再降 ×10^(35/60) ≈ 3.8 倍 → fc ≈ 21 kHz，
此时 D4 = 10·log10(1+(16/21)²) ≈ **2.0 dB**（越 0.5 dB 及格线 4 倍）。
→ **三阶无源 RC 拓扑在 D1/D2/D3 与 D4 之间存在硬冲突，min = 1.0 不可达。**

**结论必须说清两点**：
1. **D4 是 B 案当前的第一短板**（0.7003），但它只是"第一个卡点"；
2. **即使放宽 D4，min 也只到 0.7054（D1）**。要在 min 短板制下给出 1.0，规格层须同时处理
   **D1/D2/D3 的满分阈值**（现为 120/100/150 dB，对三阶+80 kHz fc 结构性偏高），
   或改判为"**及格线制 + 关键项加权**"（十维全过即定档，与用户 2026-10-18 的"短板即淘汰"意图一致）。

## 2. C9 peaking 前后对比

### 2.1 节点口径（第 3 轮已定，本轮沿用）

C9 的物理机理是「OPA388 闭环输出阻抗中频**负实部** × 首级阶梯电容」，谐振发生在
**被驱动节点（跟随器输出）**；ADC 引脚处被末级 RC 压平（引脚 DM 峰值 ≈ 0.0000 dB）。
**本报告按跟随器节点考核**，并同时给出引脚值。

### 2.2 修复前后（同工况：Rs = 0，AC DM，真实 OPA388）

| 参数 | 首级 R1 | 首级 C1 | 跟随器节点峰 | 引脚 DM 峰 | C9 判定 |
|---|---|---|---|---|---|
| 第 3 轮冻结（`r5_corr_r4.json` 的 `rs=0`） | **2.74 Ω** | 68 nF | **+10.660 dB** @289.7 kHz | 0.00 dB | **超限 4.66 dB** |
| **本轮冻结** | **6.19 Ω** | 68 nF | **+4.768 dB** @278.6 kHz | −0.0000 dB | **通过（余量 1.23 dB）** |
| 对照：R1 = 7.5 Ω（C1 56 nF，保 R1C1） | 7.5 Ω | 56.0 nF | 4.405 dB | — | 通过，但 D4 0.2142 dB、D1 83.16 dB → min 掉到 0.635（**不建议**） |

- **降幅**：10.660 → 4.768 dB（**−5.89 dB**），首级极点从 854 kHz（旧 1/(2πR1C1)）
  移到 378 kHz（`r5_d5_discrim_r4_B.json:poles`）。
- 机理：Q ≈ \|Re(Z_o,cl)\| / R_series。R1 从 2.74 → 6.19 Ω 把 Q 压到 1 以下。
- **修复的副作用**（`r5_report_r4_c9fix.md` §4 已记录；该文件是上一轮"B 案 C9 修复 + D5 极限环机理研判"报告的存档，本轮报告占用 `r5_report_r4.md` 这个路径）：D1 86.49 → 84.64（−1.85）、D2 83.40 → 79.17（−4.23）、
  D4 0.1876 → 0.1849（略好）、D6b 13.91 → 12.04 LSB（改善）、D10 0.0959 → 0.0904（改善）。
  **无任何维度跌破及格线。**

**读法**

1. **B 的 C9 最坏点不在 Rs = 0，而在 Rs ≈ 60 kΩ**（5.817 dB）。原因是输入侧 Rs∥C_in 极点
   改变了到达跟随器输入的边沿形状，使首级谐振被更强地激发。
   **只看 Rs = 0 会漏掉这个点**（0 Ω 只有 4.768 dB，比最坏点低 1.05 dB）。
2. **容差方向对 C9 不利的是 R−1 %**（R 变小 → Q 升高）：R−1 %/C+5 % 时 Rs=60 kΩ 达 **5.883 dB**，
   余量仅 **0.117 dB**。按 BOM 的 **0.1 % 电阻**实际最坏值是 **5.820 dB @60 kΩ（余量 0.180 dB）**
   （`r5_r4_c9_sensitivity.json` 的 `R-0.1%_C+5%`）。**这是 B 案最紧的一项硬约束**，
   比 D5 的 30 µs（对 900 µs 及格线余量 30×）紧得多。
3. **C 案**：最坏 24.6 dB @150 kΩ，**超限 18.6 dB**；即使 Rs = 0 也有 11.19 dB（超限 5.19 dB）。
   C 案的 C9 在任何源阻抗下都不达标。

| **正对照（判据敏感性）** | 旧参数 R1=2.74，Rs=100 kΩ，**三套独立数值设置** | 498 930 / 523 925 / 499 323 µV（FFT 峰 205 / — / 240 kHz）→ **三设置全报失稳** | 判据不是只在某一积分法下才报警 |

**判定：**
> **是（a）真实的失稳机理，但只在 TI 宏模型的大信号非线性区被激发；不是（b）数值伪影。**
>
> 机理：OPA388 宏模型的单位增益跟随器闭环输出阻抗在 **100 kHz–1 MHz 为负实部**
> （−0.9 Ω@100 k、−2.78 Ω@275 k，`r5_zout_opa388_ti.json`），与首级 C_gnd 构成负阻谐振；
> R1 = 2.74 Ω 时 Q > 1（跟随器峰 10.66 dB），2 V 快沿把输出级推进钳位/限幅区后形成自持极限环。
> **R1 ≥ 6.19 Ω 时 Q < 1（峰 4.77 dB），极限环消失**——这与 C9 是同一根杠杆。
>
> **对真实硅片：** 未做硅验证。但 Re(Z_o,cl) < 0 是单位增益反馈在 A_OL→1 处相位裕度不足的
> 物理表现，**不依赖"硅片可能不会振"来做设计**（保持 R1 ≥ 6.19 Ω 即可）。

## 6. 定档建议

### 6.1 判定（明确回答）

> **B 案没有达到 min ≥ 1.0，按该条不可"全维过线定档"。**
>
> - **十维及格线：全过**（D1–D10 无一越线）；**C9 / C2 / C3 / C4 硬约束：全过**；
>   **D5 全量程：16/16 建立**；**D8 配对 1 %：95.51 dB（≥80）**。
> - **总分 min = 0.700284**，短板 **D4 = 0.1849 dB**（满分线 0.05 dB，距满分 0.1349 dB）。
> - **D4 的 0.05 dB 与 D1 的 80 dB 及格线在三阶拓扑下不可同时满足**（LTspice 实测，真实 OPA388）：
>   把全局 R 缩到 kR = 0.80 时 **D4 降到 0.1196 dB 但 D1 只剩 80.74 dB**（距及格线 0.74 dB）；
>   再缩到 kR = 0.75 → D1 = 79.63 dB（**越线**）；kR = 0.65 → D4 才 0.0797 dB，而 D1 = 77.19 dB。
>   单极点估算下 D4 ≤0.05 dB 需 fc ≥ 148.7 kHz，此时 B 的 D1 按前沿外推只有 ~73 dB。
>   → **这是规格阈值问题，不是方案缺陷**，与 §5.1b 已裁决的"D6 的 1 LSB 不可达"同构。

### 6.2 建议

| # | 建议 | 理由 |
|---|---|---|
| **1** | **B 案（6.19 / 6.04 / 13.7 Ω × 68 / 68 / 27 nF + 12 nF）作为定档基线冻结** | 十维全过、C9 与 D5 全量程成立、13 件/通道、全 E96/E12。它是本轮唯一"硬约束全过"的方案。 |
| **2** | **把 D4 的处理方式提交规格裁决**（三项择一）：(a) 满分线由 0.05 dB 放宽到 **0.20 dB**（B=0.1849 → 满分）；(b) 拆成 D4a（及格/硬指标 ≤0.5 dB）+ D4b（报告值，不进 min，同 D6a/D6b 先例）；(c) 保持 0.05 dB 但明确"该项仅对 fc ≥149 kHz 的方案可满分"，即承认三阶在 50–80 kHz 窗口内的 D4 得分上限 ≈0.70（fc=80 kHz 时） | 现 min 完全由 D4 定义，而 D4 的满分线与 D1 的满分线在三阶/四阶无源 RC 下互斥。**不裁决，任何方案都定不了档。** |
