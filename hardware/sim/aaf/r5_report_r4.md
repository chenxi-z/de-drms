## 1. C9 修复：从 6.8 Ω 到 6.19 Ω 的平衡点

### 1.1 为什么不能只改 R1=6.8 Ω

第 3 轮实测（`r5_d5_coverage_gap_r3.json`）显示 R1=6.8 Ω 可把跟随器峰压到 4.43 dB，
但它只改了 R、没重解 C，fc 从 79.9 → 58.2 kHz，**D4 平坦度恶化到 0.322 dB**（距 0.5 dB 及格线只剩 0.18 dB）。
本轮用引擎（真实 OPA388 源模型）复算，与第 3 轮实测完全一致：

| R1 | fc | 跟随器峰 | D4 | D1 |
|---|---|---|---|---|
| 2.74 Ω | 79.9 kHz | 10.65 dB | 0.1877 dB | 86.15 dB |
| 4.30 Ω | 70.1 kHz | 7.00 dB | 0.2329 dB | 86.33 dB |
| 5.10 Ω | 65.8 kHz | 5.92 dB | 0.2591 dB | 86.43 dB |
| **6.80 Ω** | **58.2 kHz** | **4.41 dB** | **0.3216 dB** | 86.64 dB |
| 12.0 Ω | 42.8 kHz | 2.40 dB | 0.5657 dB | 87.29 dB |

→ 只改 R 是**单向恶化 D4**。必须同时把 C 减小，把 fc 拉回设计窗口。

### 1.2 联合搜索的结果

在 R1 ∈ E96 [5.62, 7.5] × C ∈ E12{10–100 nF} 内做全组合（C1≥C2≥C3 单调阶梯），
约束 fc∈[50,80] kHz + C9≤6 dB + 十维全过线 + 600 kΩ 高阻 D4≤0.5 dB，
按 min 排序取前三名做 LTspice 实测：

| 候选 | R1/R2/R3 | C1/C2/C3 | fc | 引擎峰 | LT 峰 | D4 | D4@600k | D1 | D2 | min |
|---|---|---|---|---|---|---|---|---|---|---|
| **P1 ★** | 6.19/6.04/13.7 | 68/68/27 nF | 79.9 k | 4.75 | **4.77** | 0.1849 | 0.4925 | **84.30** | 78.83 | **0.7001** |
| P2 | 6.65/6.04/13.7 | 82/56/27 nF | 79.5 k | 4.68 | 4.69 | 0.1864 | 0.4940 | 84.34 | 78.87 | 0.6968 |
| P3 | 6.98/6.04/13.7 | 68/68/22 nF | 79.2 k | 4.21 | 4.22 | 0.1874 | 0.4950 | 83.51 | 77.18 | 0.6946 |

**P1 冻结**（min 最高，且与 P2/P3 相比 D1/D2 余量最好）。

> **为什么 P1 的 R1=6.19 Ω 而不是 6.8 Ω**：6.19 Ω 是 E96 档位，其跟随器峰 4.77 dB 已满足 C9（≤6 dB）
> 并留 1.23 dB 余量；同时它比 6.8 Ω 少牺牲 D1/D2，且 D4 更优。这是"peaking 与 D1/D2/D4"之间的平衡点。

## 3. 极限环机理研判（问题 3）

详见 `r5_d5_mech_r4.md`。摘要：

### 3.1 判定：(a) 真实不稳定机理，需要大信号激发；**不是** (b) 数值伪影

**排除数值伪影**：
- `method=gear reltol=1e-5` → 498 930 µV；`method=trap reltol=1e-4` → 498 807 µV（差 **0.02%**）。
  两种积分方法给出同一幅度，**不是积分伪影**。
- maxstep 20 ns vs 40 ns 结果一致。
- 更紧设置（reltol 1e-7 / maxstep 2n）在 TI 宏模型上超时，不能作为反证——但也不构成支持伪影的证据。

**坐实机理**：

| 证据 | 数据 | 结论 |
|---|---|---|
| **E5 理想跟随器** | 全部 Rs 稳定（29.4 µs） | 无源阶梯本身不失稳 |
| **E4 输入电容置 1 fF** | Rs=100k 极限环消失 | Rs∥C_in 输入极点参与 |
| **E2 仅改 R1=6.8 Ω** | 0–600 kΩ 全稳定 | **首级 R 与 C1 的负阻谐振是主因** |
| **F1 纯 DC 输入** | 尾段 0.003 µV（完全安静） | 平衡点本身稳定 → 不是自激，是**边沿激发的极限环** |
| **单腿振幅** | `V(fpa)` 9.6 mV vs `V(fna)` **986.6 mV** | 对称激励下只有一腿振荡 → **必是大信号非线性**（线性对称网络不会） |
| 幅度/边沿依赖 | 0.05–0.2 V 稳定、1.0 V 失稳；10 µs 沿稳定、10 ns–1 µs 失稳 | 阈值型非线性 |

### 3.2 物理图像

OPA388（TI 宏模型）单位增益跟随器闭环输出阻抗在 **100 kHz–1 MHz 的 Re(Z_o,cl) 为负**
（−0.9 Ω @100 kHz、−2.78 Ω @275 kHz、−2.0 Ω @400 kHz；`r5_zout_opa388_ti.json` 实测 700 点）。
该负阻与首级 C_gnd,1=68 nF 构成并联谐振，Q ≈ |Re(Z_o,cl)| / R_series：

- R1 = 2.74 Ω → Q > 1，跟随器节点 **+10.66 dB** @290 kHz
- R1 = 6.19 Ω → Q < 1，跟随器节点 **+4.75 dB** @279 kHz

小信号下两者都稳定（Nyquist 不环绕 −1）；但 2 V 快沿会把宏模型的输出级推入钳位/限幅区，
负阻增强并出现正负摆幅不对称（单腿振荡），形成自持极限环。
**这与 C9 完全同源**——C9 就是为这条机理设的硬约束。

### 3.3 仿真规避建议

1. **首选：R1 ≥ 6.2 Ω**（已冻结）——极限环消失，不需要任何求解器技巧。
2. **不要用"换积分方法"来消除极限环**：trap 与 gear 给出同一结论，它是真实存在的。
3. **判别真伪的正确做法**（本轮已验证有效）：
   - 自治性：输入纯 DC 看是否自振；
   - 输入电容置零对照（本地副本 `OPAx388_noCin.LIB`，不动 `lib/`）；
   - 理想跟随器对照；
   - 两腿分开看（对称激励下单腿振 = 大信号非线性）。
4. **实用设置**：`.save V(pa3) V(na3) V(fpa) V(fna)`（4 向量）+ `maxstep=20n`，
   400 µs 仿真约 1–2 s、`.raw` 1–3 MB。`.save` 全向量 + 1 ns 步长会写出数百 MB 并挂死。

## 6. 剩余缺口与建议

1. **D4 的 0.05 dB 满分线仍不可达**（本轮 0.1849 dB，与第 3 轮结论一致）：
   要达 0.05 dB 需 fc ≥149 kHz，与 fc∈[50,80] kHz 的设计窗口冲突。
   这是规格层面问题（第 3 轮 §7.2 已上报），**不因本轮改动而改变**。
2. **D6b 总噪声 12.0 LSB**（砖墙极限 4.30 的 2.8 倍）——由跟随器 9.9 nV/√Hz 决定，无优化空间。
   D6a（本段可控项）0.68 % 远优于 10 %。
3. **600 kΩ 高阻端的 D4 = 0.4925 dB（引擎）/ 0.4924 dB（LTspice）**，距 0.5 dB 及格线只剩 **0.0075 dB**。
   这是第 3 轮就存在的贴线项，本轮没有恶化也没有解决。**建议在规格里明确 D4 的源阻抗口径**
   （纯 AC 仿真口径 = 0 Ω；实机 600 kΩ 端另有 OPA388 输入极点 −0.31 dB）。
4. **硅片验证**：极限环是宏模型行为，未做硅验证。但 Re(Z_o,cl)<0 是物理机理（单位增益反馈在
   A_OL→1 处的相位裕度不足），**建议按会发生来设计**（即保持 R1 ≥6.2 Ω）。
