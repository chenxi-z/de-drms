## 0. 一句话结论

**三案全部不及格**（无一套满足「D1–D10 全过线」）。按 min 短板制排序：**B (0.3195) > A (0.3100) > C (0.3076)**，但三者差距仅 0.012（≈3.9%），且短板全部是同一项 **D6 积分噪声**——该项各案几乎相同（0.94–0.98 LSB），并未真正区分方案。真正区分三案的是 **D1（DM @fMOD）与 D8（CMRR @通带）**，而这两项**三案全部越线**。

> **裁决**：按 §6「若 A 及格则优先选 A」的规则，**A 不及格 → 依次看 B → B 也不及格 → C 也不及格**，故**本轮回合没有任何方案可定档**。
> 若必须在三案中指定一个「继续迭代的基线」，**保留 §5.1 原样口径时按 min 总分取 B**；但该领先完全来自 D6 的 0.009 分差（噪声差 8.4 nV），**不具备统计与工程意义**。**剔除 D6 后排序变为 B > C > A**（§4.2.1）——在真正区分拓扑能力的 D1/D8 上 C 更优。**因此"基线取谁"取决于 D6 口径的裁决（§5 #1、#2），本报告不替用户预设。**

### 1.4 口径说明与数据审计（必读）

**(a) B 案 D5 口径不一致。** `r5_results_B.json` 的 `dims.D5 = 34.68 µs` 取自 **V9c（0 Ω + 真实 OPA388）**，但同一文件的 `D5_candidates_us.V4b_600k_ideal_unbootstrapped_us_UPPER_BOUND = 51.18 µs` 更大。规格 §5.1 明写 D5「**测试须覆盖高源阻抗工况（样品 600 kΩ 端）**」，`parse_r5.py` 的既定规则是取 `max(D5_candidates_us)`；A/C 两案都取了这个最大值（52.12 / 52.13 µs）。按同一规则 B 应记 **51.18 µs**。**两值均远优 500 µs，归一化分同为 1.0，不影响总分**。报告表里保留 JSON 原值 34.68 并加注，避免与 `r5_results_B.json` 对不上。

**(b) C 案 `r5_results_C.json` 自带的 `scores` 与 §5.1 公式不符（严重）。** 文件内 `scores` 给 D1=0.0、D8=0.0、D2=0.2827、D3=0.5168、D6=0.0354，而按 `dims` 与 §5.1 公式应为 D1=0.6550、D8=0.4652、D2=0.7131、D3=0.8389、D6=0.3076。**本报告一律以 `dims` + §5.1 公式重算**，不使用该文件的 `scores`/`min_score`（其 `min_score=0.0` 系该错误直接产物）。A、B 两案的 `scores` 经同法复核**一致**。（`score_r5.py` 的 `audit_scores()` 会打印这处不一致。）

**(c) 原始 `.raw` 反算复核。** 从 V1/V2/V3 的 `.raw` 重算 D1/D2/D3/D4/D8/D10：A、C **逐位一致（|Δ|<1e-6）**；B 因 JSON 只存 3 位小数，最大 |Δ| = 1.2e-3 dB（D8），属舍入。

**(d) D6 的建模口径（影响「短板」的性质判断）。** V7 网表里 `Rin = 130 kΩ` 是 **ADS131A02 的差分输入阻抗**（`r5_datasheet_facts.md` §4 M3；`gen_netlists_r5.py:65`），被当作纯电阻参与噪声。实测其自身贡献仅 **0.0136 nV/√Hz**，而该电阻的约翰逊噪声按 4kTR 应为 **46.4 nV/√Hz**——这是因为 LTspice 将 `Rin` 跨接在两个理想电压源驱动的节点之间，其热噪声被源「钳死」，**只有网络等效阻抗分到的那部分才输出**。这个建模对「前级无源网络 + 理想源」是自洽的，但**它把 ADC 输入阻抗的热噪声整个丢掉了**。若按 ADC 自身 130 kΩ 计入，仅这一项积分到 2.048 MHz 就是 **66 µVrms ≈ 227 LSB**，会使 D6 直接爆表。
→ **结论：D6 的「0.31 分」只反映无源阶梯自身的噪声，不是 ADC 引脚处的真实总噪声。**这条口径必须由规格 Owner 明确（见 §5 待决 #1），在此之前 D6 不宜作为定档依据——而它恰好是三案的共同短板，**这正是三案分数几乎拉不开的原因**。

## 2. CH1 vs CH2 群延迟差专项（§5.1a 点名）

### 2.1 方法说明（与既有结果的口径差异）

§5.1a 要求「通道间（CH1 vs CH2）的群延迟**匹配**」。三案既有的 `r5_results` 只给了 `CH_tau_diff_us`（V1 里 p 线减 n 线），那是**同一通道内两条腿**的延迟差，**不是 CH1 与 CH2**。
本报告的 CH1/CH2 数据是**本次新跑的、真的四线仿真**：按 §4「四线统一全配」，把同一标准单元摆两份（CH1 = AIN1P/AIN1N，CH2 = AIN2P/AIN2N），各自独立激励与负载，比较两通道**差分输出**的群延迟。网表由 `score_r5.py:gen_ch_net()` 生成、LTspice 24.1 `-b -ascii` 实跑，`.raw` 存 `r5_work/ch/ch_{A,B,C}_{nominal,mismatch1pct}.raw`。

### 2.2 实测数据

| 案 | 通道 | τ @16 kHz（标称） | Δτ(CH1−CH2) 标称 | 带内最大 \|Δτ\| | 1% 通道失配 Δτ | 带内最大 \|Δτ\| |
|---|---|---|---|---|---|---|
| **A** | CH1 / CH2 | 3.123702 / 3.123702 µs | **0.0000 ns** | 0.0002 ns | **−54.15 ns** | 66.72 ns |
| **B** | CH1 / CH2 | 2.810105 / 2.810105 µs | **0.0000 ns** | 0.0003 ns | **−50.74 ns** | 59.06 ns |
| **C** | CH1 / CH2 | 3.258826 / 3.258826 µs | **0.0000 ns** | 0.0000 ns | **−49.45 ns** | 59.18 ns |

> 标称项为 0 是**结构对称的必然结果**（两通道元件逐位相同），不是"测得好"。
> **有信息量的是 1% 失配列**：三条线均 **≈ −50 ns 量级**，即 **Δτ ≈ 0.05 µs**。
> 按 §5.1 D10 的锚定关系（1 µs @16 kHz ↔ 相位离散 5.8°），**0.05 µs ↔ ≈0.29°**。相对 D10 的 1 µs 阈值，通道失配项占 5%，**不构成威胁**。
> 三案在此项上**几乎无差别**（49.5–54.2 ns，差 9%），因为失配延迟由单级 R·C 时间常数量级决定，与阶数关系弱。

### 2.3 与 D8 的互证（重要）

CH 群延迟差随失配**线性缩放**，而 **D8（CMRR）随失配也对数线性缩放**——两者是同一失配源的两种表现。本次实测的 CMRR 失配标定（见 §3.3）显示：

| 通道失配 | A | B | C |
|---|---|---|---|
| 1% | 43.89 dB | 44.85 dB | 46.52 dB |
| 0.3% | 54.37 dB | 55.33 dB | 57.00 dB |
| 0.1% | 63.92 dB | 64.88 dB | 66.55 dB |
| 0.01% | 83.92 dB | 84.88 dB | 86.55 dB |

**每降一个数量级失配，CMRR 改善 20 dB**（本次对 4 个失配点最小二乘拟合，三案斜率均为 **−20.01 dB/decade**，与电压比关系自洽）。据此反解：**要满足 D8 的 80 dB 及格线，四线阶梯匹配需优于 A ≤0.0157% / B ≤0.0175% / C ≤0.0212%**（即 ≈0.02% 量级）。
→ **这是比"选哪个方案"更要紧的结论**：D8 不是靠加阶数能解决的，**必须靠元件匹配/配对采购解决**（见 `r5_bom_check.md` §4）。

## 4. 按总分排序与推荐结论

### 4.1 排序（min 短板制）

| 名次 | 案 | 阶数 | 件数/通道 | **总分 = min** | 短板维 | 越线维 | 全维及格 |
|---|---|---|---|---|---|---|---|
| **1** | **B** | 3 | 13 | **0.31955** | D6 | D1, D8 | ✗ |
| 2 | A | 2 | 9 | 0.31004 | D6 | D1, D2, D3, D8 | ✗ |
| 3 | C | 4 | 17 | 0.30762 | D6 | D1, D8 | ✗ |

### 4.2 为什么这个排序不可信（必须先说清）

1. **排序由 D6 决定，而 D6 三案几乎相同**（0.939 / 0.968 / 0.975 LSB，相差 ≤3.8%）。B 领先 A 仅 0.009 分——**折算成噪声只差 8.4 nV（0.029 LSB）**，远小于任何实测不确定度。
2. **D6 本身的口径未定**（§1.4(d)）：若把 ADC 输入阻抗的热噪声计入，三案 D6 都会跌到 ≈0.001 量级，排序会重排但**结论仍是全不及格**。
3. **真正区分三案的维度（D1 随阶数单调改善：59.2 → 66.7 → 78.6 dB）没有决定排序**，因为它在三案都越线、且归一化后不是最小值。
4. **C 案的 `r5_results_C.json` 自带分数算错**（§1.4(b)）；若误用该文件的 `min_score=0.0`，C 会被排到最后且看似"零分"，与实测严重不符。

#### 4.2.1 排序对 D6 的敏感性（实测）

把 D6 从 min 中剔除后重算（`score_r5.py` 的 `rows` 可复现）：

| 口径 | 第 1 | 第 2 | 第 3 | 短板维 |
|---|---|---|---|---|
| **原样（§5.1 十维）** | **B 0.3195** | A 0.3100 | C 0.3076 | 全是 D6 |
| **剔除 D6** | **B 0.4485** | **C 0.3606** | **A 0.3214** | D8 / D4 / D4 |
| **剔除 D6 + D4** | **C 0.4652** | B 0.4485 | A 0.4389 | 全是 D8 |

→ **排序对 D6 的处置敏感**：剔除 D6 后 **C 从第 3 升到第 2**（B 仍第 1）；再剔除 D4 后 **C 升到第 1**。
→ **B 的"第一"只在保留 D6 时成立**；在"真正区分拓扑能力"的维度（D1/D8）上，**C 更优**（D1 78.6 vs 66.7，D8 46.5 vs 44.9）。这与 §4.3「C 是唯一接近 D1 及格线」的观察一致。
→ **min 短板制在"共同短板"占主导时失去分辨力**。这是评分体系的**结构性发现**，建议 §5.1 在下一轮引入「短板维加权」或对共同短板做敏感性分析（见 §5 待决 #2）。

### 4.3 按分数说话的推荐
**没有任何方案达到 §6 的定档条件（D1–D10 全过线）**，因此**本轮不选型**。若必须给出一个「继续迭代的基线」，两种口径给出的答案不同：

**（口径甲）保留 §5.1 十维原样 → 基线取 B（总分 0.3195 最高）**
- B 在 D3 = 102.5 dB（唯一过线）、D7 = 0.0067 dB（σ 最小）、D10 = 0.142 µs（最平坦）、D2 = 66.5 dB、件数 13（比 C 少 4 件）上都优于或等于 A/C。
- **但 B 的 D1（66.7 dB vs 及格 80 dB）与 D8（44.9 dB vs 及格 80 dB）均不及格**，D1 差 13.3 dB、D8 差 35.1 dB。

**（口径乙）D6 若因口径未定而不参与排序 → 见 §4.2.1，D1/D8 是唯一有意义的分野**
- **C 的 D1 = 78.6 dB 只差 1.4 dB**，是三案中唯一"下一轮微调有可能过 D1"的结构；D8 = 46.5 dB 也是三案最高。
- 代价：17 件/通道（B 为 13），D6 = 0.975 LSB（三案最差，但差距仅 3.8%）。

**共同结论（两口径都成立）**：
- **A 最不可取**：D1/D2/D3/D8 **四项越线**（唯一一案的 D2 也越线，差 0.94 dB；D3 差 16.75 dB），且 D4 归一化分 0.321 还低于 B/C。
- **D8 是压倒性短板**：三案 43.9–46.5 dB，距及格线 33.5–36.1 dB，**不是靠换方案能解决的**（见 §2.3、§4.4）。

#### 4.3.1 逐维胜者（按归一化分，不含并列的满分维）

| 维度 | A | B | C | 胜者 |
|---|---|---|---|---|
| D1 | 0.4933 | 0.5556 | **0.6550** | **C** |
| D2 | 0.5906 | 0.6654 | **0.7131** | **C** |
| D3 | 0.5550 | 0.6831 | **0.8389** | **C** |
| D4 | 0.3214 | **0.5213** | 0.3606 | **B** |
| D6 | 0.3100 | **0.3195** | 0.3076 | **B**（差 3.8%，见 §4.2） |
| D7 | 0.9902 | **1.0000** | **1.0000** | B / C 并列 |
| D8 | 0.4389 | 0.4485 | **0.4652** | **C** |
| D5/D9/D10 | 1.0000 | 1.0000 | 1.0000 | 三案并列满分 |

**读法**：**C 在 4 个传导维度（D1/D2/D3/D8）上全胜**，B 只在 D4（通带平坦度）与 D6（噪声，差距无意义）上领先。这与"阶数越高、阻带越深"的物理预期一致；B 赢 D4 是因为它的三级结构在 16 kHz 附近滚降反而更缓（0.265 dB vs C 的 0.338 dB）。**若把 D6 的争议排除，C 是更优的结构。**

### 4.4 下一轮必须先解决的两件事（按优先级）

1. **D8 的 35 dB 缺口靠元件匹配，不靠拓扑**（§2.3）：80 dB 需 R/C 匹配 ≤0.016–0.021%。→ 见 `r5_bom_check.md` §5 的配对采购方案；或在 §4 架构内引入**共模检测/伺服**（超出当前定稿范围，需用户批准）。
2. **D6 口径先定，再谈选型**（§1.4(d)）：ADC 输入阻抗热噪声是否计入，直接决定 D6 是 0.31 还是 0.001。
