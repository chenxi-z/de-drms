| B | 46.04 µs | **77.30 µs** | 43.0–52.9 µs（0 Ω 角） | **77.30 µs** | 三种数值设置差 <0.05 %（`gear 20n` / `gear 2n` / `trap 1e-4`） |
| C | 不建立（0 Ω 角 41 mV pp 极限环） | **89.87 µs** | 18.5–19.5 µs（V6，非最坏角） | **89.87 µs** | 三种设置 89.872 / 89.849 / 89.872 µs（离散 0.025 %） |

**判读**：
1. **A 案的 D5 不是"未测"，是"测了且不建立"**。`r5_results_r3_A.json:52` 与 `D5_invalid_reason` 明确记录：
   真实模型瞬态为**等幅极限环**（与激励幅度无关），0.01 % 带永不满足 → 按 §5.1「半周期内未回稳淘汰」的同类逻辑记 **0 分**。
   A 案给出的 `D5_candidates_us.V4_0ohm_ideal_corner = 21.08 µs` 是 **0 Ω 理想源**口径，不能替代真实模型。
2. **C 案的 0 Ω 角同样不稳定**（本轮复算：尾段 41.1 mV pp，193 kHz），但其 600 kΩ 角**稳定**，
   而 §5.1 规定的 D5 工况恰是 **600 kΩ 端**，故 C 的 D5 取 89.87 µs 有效。
   这一点必须在图注/规格里写清：**C 的 D5 分数依赖"只测 600 kΩ"这一采样选择**（见 §5）。
3. **B 案 D5 是本轮最干净的一项**：0 Ω 与 600 kΩ 两端都稳定、三种数值设置一致、机理核查
   （首级 C 从 71.4 nF 降到 7.14 nF 后 46.0 → 22.8 µs）证明 46 µs 主要来自跟随器驱动大容性负载的恢复，
   而不是无源阶梯本身。

### 2.2 D6a / D6b 数据（拆分后的两半）

| 案 | D6a 线性口径 | D6a 正交口径 | D6a 评价 | D6b 总噪声 | 相对砖墙 4.30 LSB |
|---|---|---|---|---|---|
| A | **0.170 %** | 5.83 % | 满分（≤10 %） | **15.76 LSB** = 4.59 µVrms | 3.66× |
| B | **0.327 %** | 8.09 % | 满分 | **13.91 LSB** = 4.05 µVrms | 3.23× |
| C | **0.594 %** | **10.92 %** | 满分（线性口径） | **13.74 LSB** = 4.00 µVrms | 3.19× |

**口径提示（重要）**：§5.1 的 D6a 定义写"总积分噪声 vs 跟随器自身噪声的增量比例"，未指定线性还是正交。
- **线性口径** `(Vtot−Vfol)/Vfol`：三案 0.17–0.59 %，全部远低于 10 % —— 但线性相减会把"跟随器主导"
  的部分抵掉，**对无源网络的真实贡献不敏感**。
- **正交口径** `√(Vtot²−Vfol²)/Vfol`：A 5.83 %、B 8.09 %、**C 10.92 %** —— **C 用正交口径会越过 10 % 满分线**
  （归一化分 10/10.92 = 0.916），但仍远在 30 % 淘汰线内。
- 本报告按**线性口径**评分（与三案 JSON 一致），并把正交口径并列披露。**若规格方裁定用正交口径，
  C 的总分不变（短板仍是 D4 = 0.7102），但 C 的 D6a 会从 1.0 掉到 0.916** —— 仍不是短板。

**D6b 说明**：三案都在 **13.7–15.8 LSB**，是砖墙极限 4.30 LSB 的 3.2–3.7 倍。这与 §5.1b 的推导一致
（跟随器 9.9 nV/√Hz × 16 kHz 通带的 ENBW ≥14.3 kHz ⇒ 理论下限 4.3 LSB；实际电路噪声带宽更宽）。
**D6b 不进 min，但它说明"总噪声"这一项在现拓扑下没有优化空间**——想改善必须换运放或压窄带宽，
而后者与 D4/D10 冲突。

## 3. D8 配对收益曲线（本轮主证据）

### 3.1 三档失配 × 配对/同向（全部 LTspice 真实 OPA388 实测）

**配对** = B 线 `R×(1+m)`、`C_gnd×(1−m)`（R·C 乘积回到 ≈1）。
**C_diff 是跨接两线的共享件，不参与逐线配对**——核对三案配对网表：
`r5_work/r3/r5_A_r3_v9p_m0.01_pair.net` 的 `Cd pa2 na2 1.8e-08`、
`r5_work/r3_B/r5_B_v9b_p1_r3.net` 的 `Cd pa3 na3 1.2e-08`、
`r5_work/r3_C/r5_C_r3_v3p010.net` 的 `Cd pa4 na4 8.2e-09`（三处均与标称档同值）。
**同向** = B 线 `R×(1+m)`、`C_gnd×(1+m)`（无配对，最坏情形）。

| 0.1 % | C | **135.47 dB** | 68.55 dB | **+66.93 dB** |

### 3.2 读法与结论

1. **配对收益随失配减小而增大**（1 % → 0.1 %：+46~47 → +65~67 dB）。
   这符合"配对把失配转成时间常数匹配"的机理：m 越小，配对后残余的二阶失配越小。
2. **1 % 单体 + 配对后三案都在 94.7–96.7 dB**，全部**高于 80 dB 及格线**，但**都达不到 100 dB 满分**。
   即：**D8 在规格正文（1 %）口径下是"过线但不满分"**，C 案最差（94.66 dB）、A 案最好（96.65 dB）。
   **若按下发的 `dims.D8`（B/C 取 0.1 % 档）评分**，两案 D8 = 1.0000（封顶）；
   **两种口径的总分相同**（都是 D4 短板），见 §1.4 的口径审计行。
3. **同向 1 % 对照只有 48.4–49.2 dB**，与规格 §5.1a 记录的"物理上限 48–49 dB"完全吻合 →
   **配对工序是 D8 从"必淘汰"变成"过线"的唯一途径，不是优化项**。
4. **同向失配的 −20 dB/decade 规律**（本轮数据复核）：
   0.1 %→1 % 十倍失配，CMRR 掉 20.0–20.7 dB，与旧 BOM 表 §5 的 −20.01 dB/decade 拟合一致。
5. **严格倒数口径（C/(1+m)）比字面口径（C×(1−m)）高 13–15 dB**（B 案 1 %：110.43 vs 95.65 dB）。
   规格 v4 §5.1a 引用的"110–112 dB"对应**严格倒数**口径，正文却写 `C×(1−m)` —— 二者不是同一个式子。
   本报告 §1 的评分用下发 `dims.D8`、§3.2 的讨论用正文 1 % 口径；**两种取法对总分都无影响**。
   但如果规格方要拿 110 dB 当设计目标，必须同时改写正文公式并在 BOM 工序里允许"容差按可调/筛选"实现严格倒数配对。

### 4.2 为什么两种口径差这么多

C9 的原文是「**有源谐振：真实 OPA388 模型下全频段增益峰值 ≤6 dB**」，理由写的是
「OPA388 闭环输出阻抗中频负实部可与阶梯电容形成谐振」。**谐振发生在被驱动节点（跟随器输出），
不是 ADC 引脚**——引脚处被末级 RC 低通压平了 10–14 dB。

- **A 案**：两级都是 100 nF 大电容直接挂在 2.4 Ω 输出电阻上 → 跟随器节点 +14.0 dB。
- **B/C 案**：首级电容 68 nF / 33 nF，且首级电阻 2.74 / 1.8 Ω 更大，峰降到 +10.7 / +11.2 dB，
  但仍**高于 6 dB 限值**。

### 4.3 与 §5.1b 记载的 "+30.7 dB @283 kHz" 的核对

规格 §5.1b 引用第 2 轮曾实测到 **283 kHz 处 +30.7 dB**。本轮复算：

| 参数 | 引擎引脚 DM | LTspice 引脚 DM | LTspice 跟随器节点 |
|---|---|---|---|
| **旧 A：R1 = 1.1 Ω**/100 nF + 13 Ω/100 nF | 22.98 dB | **23.92 dB** @277 kHz | **34.93 dB** @277 kHz |
| 本轮 A：R1 = 2.4 Ω（同上其余） | 1.70 dB | **1.73 dB** @279 kHz | **14.01 dB** @281 kHz |

（本轮新跑网表：`r5_work/c9_r3/c9_A_r{1.1,2.4}.net`，命令 `LTspice.exe -b -ascii`）
→ **"+30.7 dB" 应理解为"跟随器节点、R1=1.1 Ω 旧参数"的峰值**（本轮实测 34.93 dB，与 30.7 dB 同量级；
差异来自扫描点数与 R1 精确值）。**在引脚口径下同参数只有 23.9 dB**，与文档记载的 30.7 dB 对不上。
**建议规格方在 C9 条文里明确写"考核节点 = 跟随器输出（或阶梯首级节点）"**，否则两种口径会给出相反结论。

### 4.4 C9 判定（本报告采用）

按 C9 的**物理机理**（谐振在跟随器输出节点），**三案全部不满足 ≤6 dB**：

| 案 | 跟随器节点峰值 | 超限倍数 | 首级 R 提到多少可降到 ≤6 dB（本轮实测） |
|---|---|---|---|
| A | +14.01 dB @ 280.8 kHz | 2.3× | **R1 = 10 Ω → +3.01 dB（通过）**；R1 = 4.3 Ω 时 +7.58 dB（**仍超**） |
| B | +10.66 dB @ 289.7 kHz | 1.8× | **R1 = 6.8 Ω → +4.43 dB（通过）** |
| C | +11.19 dB @ 319.9 kHz | 1.9× | R1 = 3.3 Ω → +7.61 dB（**仍超**）；需更高，**本轮未测** |

（网表 `r5_work/c9_r3/pk_{A_2.4,A_4.3,A_10,B_2.74,B_6.8,C_1.8,C_3.3}.net`，`LTspice.exe -b -ascii`，
`.ac dec 1000 0.1 200Meg`，取 `V(fpa)` 相对 DC 的峰值）

**关键交叉发现**：**C9 与 D5 的稳定性修复是同一根杠杆，但 C9 要求更严**。
- A 案：R1 = 4.3 Ω 就能解 D5（全范围稳定），但 C9 仍 7.58 dB → **要同时满足 C9 需 R1 = 10 Ω**，
  而 R1=10 Ω 时 D4 升到 **0.557 dB（越 0.5 dB 及格线）**（引擎预测，§5.2 表）。
- B 案：R1 = 6.8 Ω 同时满足 C9（4.43 dB）与稳定性；代价需重新求解 D4。
- **这说明"A 案用 R1=4.3 Ω 修复"只解了 D5，不解 C9**，前一节 §5.2 的结论必须按本条修正。

**这是本轮最需要规格方裁决的一条**：
- 若 C9 按**引脚**判 → 三案全过（A +1.73 dB、B/C ≈0 dB），C9 不构成任何障碍；
- 若 C9 按**跟随器节点**判 → 三案全不过，且 B/C 的 D5 在中间阻抗的失稳（§5）正是同一机理的大信号表现。

## 5. D5 覆盖缺口（本轮新增发现，不改变 §1 的评分但必须上报）

§5.1 的 D5 标准工况只规定 **"样品 600 kΩ 端"**，本轮三案都按它取数。但规格 §2 的**设计量程是 10–120 kΩ**，
1 % 可用范围到 600 kΩ。**0 Ω 与 600 kΩ 两个点不足以覆盖 10–220 kΩ**。

本轮补测（`r5_d5_coverage_gap_r3.json`，网表 `r5_work/loz_r3/*.net`，真实 OPA388，
2 V 差分阶跃、10 ns 沿、判据 200 µV）：

| 案 | 73 Ω | 10 kΩ | **50 kΩ** | **100 kΩ** | **220 kΩ** | 600 kΩ |
|---|---|---|---|---|---|---|
| **A（R1=2.4）** | 27.5 mV 振 | 31.3 mV 振 | — | **145.4 mV 振** | — | 132.8 mV 振 |
| **B** | 0 ✓ 52.8 µs | 0 ✓ 66.6 µs | **44.9 mV 振** | **65.6 mV 振** | **77.2 mV 振** | 0 ✓ 74.6 µs |
| **C（R1=1.8）** | 41.1 mV 振 | 48.7 mV 振 | — | **101.4 mV 振** | — | 0 ✓ 82.9 µs |

**（"振" = 尾段峰峰值远超 200 µV，等幅不衰减）**

### 5.1 这个现象的可信度

| 检验 | 结果 |
|---|---|
| 两种独立数值设置（`gear 20n` reltol 1e-5 vs `trap 40n` reltol 1e-4） | B@100 kΩ：65.6 / 65.7 mV；B@220 kΩ：77.2 / 77.1 mV → **两法一致** |
| 幅度依赖（B@100 kΩ） | 0.05/0.1/0.2 V 阶跃 **稳定**；1.0 V **失稳** |
| 边沿依赖（B@100 kΩ） | 10 ns / 1 µs **失稳**；10 µs **稳定** |
| 小信号环路（C 案，1 mV 脉冲） | 扰动在 ~40 µs 内衰减到 1e-10 → **小信号稳定、无 RHP 极点** |

→ **这是宏模型的大信号非线性行为**（OPA388 TI 宏模型在 100–600 kHz 的负实部输出阻抗
−0.12 Ω@100k / −1.25 Ω@320k / −3.57 Ω@1M，见 `r5_results_r3_C.json` 的 `xcheck.D5_stability_note.mechanism`），
与 C9 的 +10~14 dB 峰**同源**。
**不能据此断言真实硅片会失稳**（TI 宏模型的大信号块是行为级近似），但**必须**：
1. 把 D5 的工况点从"0 Ω + 600 kΩ"扩到 **100 kΩ / 220 kΩ**（覆盖设计量程 10–120 kΩ 与 1 % 可用范围）；
2. 在样机阶段用**真实 2 V 阶跃 + 100 kΩ 源**实测，而不是只测两端。

### 5.2 低成本的修复方向（本轮已验证）

| 案 | 改动 | 修复效果 | 代价（引擎预测） |
|---|---|---|---|
| **A** | R1 **2.4 → 4.3 Ω** | D5：73 Ω~600 kΩ **全范围回稳**（38.7–111.3 µs，最坏角也稳） | D1 74.59 → 74.81 dB（+0.22）；D4 0.199 → 0.266 dB |
| **A** | R1 **2.4 → 10 Ω** | **同时满足 C9**（跟随器峰 3.01 dB）与 D5 | **D4 0.199 → 0.557 dB（越 0.5 dB 及格线）**；D1 74.59 → 75.51 |
| **C** | R1 **1.8 → 3.3 Ω** | D5：73 Ω/10 kΩ/600 kΩ 稳定，但 **100 kΩ / 220 kΩ 仍振**；C9 仍 7.61 dB | D1 92.88 → 93.06；D4 0.180 → 0.209 |
| **B** | R1 **2.74 → 6.8 Ω** | **同时满足 C9**（4.43 dB）；D5 的 100–220 kΩ 未复测 | 需重新求解 D4（本轮未跑） |

**关键结论（修正上一版）**：
- **A 案 R1 = 4.3 Ω 只解 D5、不解 C9**（C9 仍 +7.58 dB）。要同时满足 C9 需 **R1 = 10 Ω**，
  但那会把 **D4 推到 0.557 dB（越 0.5 dB 及格线）** → **A 案无解**（D1 也仍只有 75.5 dB）。
- **B 案 R1 = 6.8 Ω 同时满足 C9 与 0 Ω/600 kΩ 稳定性**，是唯一在本轮被验证"两项都过"的配置；
  但 100–220 kΩ 的 D5 与新的 D4 需重测。
- **C 案 R1 = 3.3 Ω 不够**（C9 7.61 dB），R1 要继续加大，代价是 D4 上升——需重新求解。

### 7.2 D4 的 0.05 dB 满分线是否可达？（理论前沿）

D4（16 kHz 相对 DC 的模拟段偏差）与 D1（fMOD 衰减）**由同一个 fc 决定，方向相反**：
压低 fc 改善 D1，却抬高 D4。本轮用引擎（真实 OPA388 源模型）在 **C2（ΣR≤5 kΩ）+ C3（C≤100 nF）**
约束下扫 R×C 缩放，求"满足 D4 ≤ 0.5 dB 及格线时的最大 D1"：

| 案 | 最优缩放 | **D4 及格约束下 max D1** | 对应 D1 分 | **距 120 dB** |
|---|---|---|---|---|
| A（2 级） | R×1.58, C×0.95 | **77.93 dB** | 0.649 | **−42.1 dB** |
| B（3 级） | R×1.26, C×1.37 | **97.47 dB** | 0.812 | **−22.5 dB** |
| C（4 级） | R×0.79, C×2.51 | **115.56 dB** | 0.963 | **−4.4 dB** |

**读法**：
- **A、B 两级/三级拓扑在 D4 及格约束下，D1 最多到 78/97 dB，离 120 dB 差 42/22 dB**——不是调参能补的，
  是**阶数不够**（每级约 −20 dB/decade，少一级就差一个 decade 量级的衰减）。
- **C 案的四级拓扑在 D4 及格约束下可以把 D1 推到 115.6 dB（距满分仅 4.4 dB）**，代价是
  C 全部放大到 ~98 nF（贴 C3 上限）、R 缩到 1.4–17 Ω。**这是唯一有可能逼近 120 dB 的路径**。
- **但 D4 的满分线 0.05 dB 与"fc = 50–80 kHz"这一设计区间本身就不自洽**：
  单极点近似下 16 kHz 相对 DC 的偏差是 `10·log10(1+(16/fc)²)` dB ——
  **fc = 73.7 kHz → 0.200 dB、fc = 104.8 kHz → 0.100 dB、fc = 148.7 kHz → 0.050 dB**。
  三案 fc 都在 78–80 kHz，实测 0.180–0.199 dB，与单极点预测（0.170–0.176 dB，见下表）
  只差 0.01–0.03 dB（剩余部分来自跟随器有限带宽与输出电阻，不是无源阶梯）。

  | 案 | 引擎 fc | 单极点预测 dG@16k | 实测 dG@16k |
  |---|---|---|---|
  | A | 78.6 kHz | 0.176 dB | **0.199 dB** |
  | B | 79.9 kHz | 0.171 dB | **0.188 dB** |
  | C | 79.9 kHz | 0.171 dB | **0.180 dB** |

  **结论：要拿 D4 满分（≤0.05 dB），单极点 fc 需 ≥149 kHz**，是现设计区间（50–80 kHz）的 1.9 倍以上，
  而抬 fc 会**直接压低 D1**（§7.2 的扫描已经显示：R 缩小抬 fc，D1 随之下降）。
  **D4 的 0.05 dB 满分线与 D1 的 120 dB 满分线在两级/四级无源 RC 拓扑下不可同时满足** ——
  这与 §5.1b 记录"D6 的 1 LSB 物理不可达"是同一类问题，**建议按 D6 的先例拆分或放宽**。

### 7.3 定档结论

> **第 3 轮没有方案达 min ≥ 1.0，因此没有方案可定档。**
>
> - **B、C 两案"十维及格线全过"**（无一项越线），按 §6 定档原则的**及格部分**成立，
>   但 §6 的定档要求是"以 §5 总分排序定档"，而两者的总分只有 0.694 / 0.710 —— **尚未达到可交付质量**。
> - **A 案不可定档**：D5 无有效实测（淘汰）+ D1 越线（74.93 < 80 dB）。
> - **剩余缺口**：B 需 D4 从 0.1876 降到 0.05 dB（−0.138 dB，且当前 fc 已在 80 kHz，需要重新求解）；
>   C 需 D4 从 0.1804 降到 0.05 dB（−0.130 dB）。**两案的 D4 缺口量级相同，C 的总分略高来自 D1/D2/D3 的余量。**

| 2 | B（3 级） | 0.6941 | ✅ | D4（0.1876 dB） | **次选**。D5 是三案唯一"0 Ω 与 600 kΩ 双端稳定 + 三设置一致"的方案；**且首级 2.74 → 6.8 Ω 后 C9 可降到 4.43 dB（本轮实测通过）**——是三案中唯一"稳定性 + C9 同时有解"的配置。但 100–220 kΩ 的 D5 未复测，D1 余量只有 6.5 dB。 |
| 3 | A（2 级） | 0.0000 | ❌ | D5 无效 + D1 越线 | **淘汰**。R1=2.4 Ω 在 0 Ω 与 600 kΩ 都不建立（等幅极限环）；R1=4.3 Ω 可解 D5（38.7–111.3 µs）但 C9 仍 7.58 dB，R1=10 Ω 解 C9（3.01 dB）却使 D4 越线（0.557 dB）。D1 仍只有 74.8–75.9 dB（< 80 dB），**结构上不可能过 D1**（§7.2：A 拓扑在 D4 及格约束下 D1 上限 77.9 dB）。 |

### 8.1 推荐 C 的三个前提条件（缺一不可）

1. **D5 工况点必须扩到 100 kΩ / 220 kΩ**（§5）。C 在 100 kΩ/220 kΩ 实测失稳；
   若不修，C 的"十维全过"只是 0 Ω/600 kΩ 两个采样点的结论。
2. **C9 的考核节点必须裁决**（§4）。按跟随器节点判，C 的 11.19 dB 超限 5.2 dB；
   按引脚判则通过。这条不裁决，C 的"通过"没有意义。
   **且 C 的 C9 修复尚未验证**：R1 从 1.8 → 3.3 Ω 只把峰降到 7.61 dB（仍超），需继续加大并重解 D4。
3. **D4 的 0.05 dB 满分线需复核**（§7.2）。三案实测 0.18–0.20 dB，而 fc 已在 80 kHz，
   差距来自跟随器而非无源阶梯；**要达 0.05 dB 需单极点 fc ≥149 kHz**，与 D1 的 120 dB 不可同时满足。

### 8.2 本轮不建议做的事

- **不建议为追 D4 满分而继续压 fc**：D4 的 0.18 dB 里，无源阶梯只占一部分，剩余来自运放；
  压 fc 会让 D1 变差（A 案 R×3 → D1 84.7 dB 但 D4 1.52 dB，直接越线）。
- **不建议把 D8 的 110 dB 当目标**（§3.2 第 5 条）：正文公式下 1 % 配对只有 94.7–96.7 dB，
  110 dB 需要严格倒数配对或 0.1 % 单体档。
- **不建议用 A 案做基线**：D1 在结构上过不了 80 dB 及格线（§7.2）。
