# D5 中间阻抗「等幅极限环」机理研判（R5 第 4 轮）

- **日期**：2026-10-19
- **对象**：B 案（R1=2.74 Ω 原参数）在源阻抗 50–300 kΩ 出现的瞬态等幅极限环
  （第 3 轮发现：`r5_report_r3.md` §5 / `r5_d5_coverage_gap_r3.json`）
- **数据**：`r5_d5_mech_r4.json`（E1–E5）、`r5_d5_mech2_r4.json`（F1–F4）、
  `r5_corr_r4.json`（AC↔瞬态对照）、`r5_p1p2_tran_r4.json`、`r5_pick_r4.json`
- **网表与原始波形**：`r5_work/r4_mech/`（`LTspice.exe -b -ascii`，模型 `lib/OPAx388.LIB`）
- **判据**：2 V 差分阶跃、10 ns 沿、0.01%（200 µV）带、尾段（后 20–25%）峰峰值

---

## 结论（一句话）

**是 (a) 真实的不稳定机理，但只在宏模型的大信号非线性下被激发**——不是 LTspice 数值伪影。
具体：**跟随器闭环输出阻抗 Re(Z_o,cl) 在 100–400 kHz 为负**（TI 宏模型实测表：−0.9 Ω@100k、
−2.78 Ω@275k）与**首级阶梯电容 C1=68 nF** 构成负阻谐振回路；该回路在小信号下稳定（无 RHP 极点，
AC 分析可验证 Nyquist 不环绕 −1），但**大信号阶跃会激发宏模型内部的限幅/钳位块**（CLAW/CL/ESD），
把工作点推到负阻段的强非线性区，形成自持极限环。**把首级 R 从 2.74 Ω 提到 6.19–6.98 Ω 后极限环完全消失**
（0–600 kΩ 全范围 + R+1%/C+5% 最坏角，实测回稳 31.8–40.0 µs）。

---

## 证据链

### 1. 排除数值伪影（问题 (b)）

| 检验 | 命令/设置 | 结果 | 判定 |
|---|---|---|---|
| 积分方法 | `method=gear reltol=1e-5` vs `method=trap reltol=1e-4` | 尾段 **498 930 µV / 498 807 µV**（差 0.02%），振荡频率 120 / 144 kHz | **不是积分方法伪影** |
| 步长上限 | maxstep 20 ns vs 40 ns | 同上，幅度一致 | 不是步长伪影 |
| 收敛性 | `gear reltol=1e-7 maxstep=2n`、`trap 5n` | 4 组设置里 2 组超时（TI 宏模型已知困难），未取得反证 | 未收敛的组不构成反证 |
| 幅度可重复性 | 同一网表重跑 | 逐位相同 | 确定性 |

> 注：更紧的求解器设置会超时（这是 TI 宏模型在 128 kSPS 级时间尺度上的已知收敛困难，
> 第 3 轮 `r5_work/r3_B/d5var/README_not_converged.txt` 也记录过），
> 故**不能**用"更紧设置也复现"来做唯一判据；主判据是下面 2–4 条。

### 2. 无源网络本身不是失稳源

E5：把 OPA388 换成理想 VCVS（`Efa fpa 0 fa 0 1`），Rs = 0 / 100 k / 600 k：
**全部回稳，29.4 µs**。→ 阶梯 + Rs 的无源部分本身无失稳。

### 3. 必要环节一：跟随器的负阻输出 + 首级电容

E2：**仅把 R1 从 2.74 → 6.8 Ω**（其余不变），Rs = 0 / 50k / 100k / 220k / 300k / 600k：
**全部回稳（35.5–41.3 µs）**，极限环彻底消失。

E2b：第 4 轮候选同样全范围回稳——
- **P2 参数（6.65 Ω / 82-56-27 nF）**：`r5_d5_mech_r4.json` 的 `E2b_FIN_*`，
  0/100k/220k/600k Ω：36.1–40.0 µs
- **冻结 P1 参数（6.19 Ω / 68-68-27 nF）**：`r5_final_ltspice_r4.json` 的 `tran_*` / `FINTR_*`，
  **0/10k/30k/50k/100k/150k/220k/400k/600k Ω 九个点：31.8–39.8 µs**；
  最坏角（R+1%/C+5%）@0/100k/600k：37.1 / 39.1 / 38.3 µs

> 首级 R 的作用是**把 C1 与 Z_o,cl 的负阻谐振解耦**：谐振回路要求
> `R1 < |Re(Z_o,cl)| + 无源阻尼`，而 R1 一旦大于该阈值，Q 掉到 1 以下。

### 4. 必要环节二：输入侧 Rs ∥ C_in 的极点

E4：把宏模型的输入电容 `C_C_DIFF` / `C_C_COM0` / `C_C_COM1`（2 pF / 4.5 pF / 4.5 pF）
置 1 fF（本地副本 `r5_work/r4_mech/OPAx388_noCin.LIB`，**不改 `lib/` 原件**），
Rs=100 kΩ 的极限环**消失**（57.7 µs 回稳）。

补充（本轮临时脚本，`r5_mech_limitcycle2.build` 的 Cin=22 pF 对照）：
在 `fa`/`fb` 节点**再加 22 pF** 并联，Rs=100 kΩ 时极限环**又消失**（稳定）。
→ 输入极点不是"越大越坏"：它改变的是阶跃到达跟随器输入时的**边沿斜率/过冲**，
存在一个最不利的时间常数区。这与 F3 的"10 µs 沿稳定、10 ns–1 µs 失稳"一致
——**输入极点通过改变边沿形状决定是否激发**，不是直接决定环路稳定性。

### 5. 大信号非线性的证据（关键）

| 检验 | 结果 | 含义 |
|---|---|---|
| **F1 自治性**：输入纯 DC（无阶跃） | 尾段 **0.003 µV**（完全安静） | 平衡点本身**稳定**；必须有扰动才起振 → 不是自激振荡器 |
| 幅度依赖（第 3 轮） | 0.05/0.1/0.2 V 稳定；**1.0 V 失稳** | 阈值型非线性 |
| 边沿依赖 | 10 ns / 1 µs 失稳；**10 µs 稳定**（本轮 F3 复现：90.6 µs 回稳） | 大信号快沿是激发条件 |
| 平滑 1 µs 指数沿（F3） | **仍失稳（570 mV）** | 不是 10 ns 的理想化边沿伪影 |
| 单腿振幅（本轮新测） | `V(fpa)` 9.6 mV vs `V(fna)` **986.6 mV** | **只有下摆腿振荡**，上摆腿几乎不动 → 与"下摆方向进入宏模型钳位"一致 |
| CLAW/CL 限幅参考降 10×（F4） | 仍失稳（310 mV，频率升到 287 kHz） | 不是 CLAW 块单独造成；多个非线性块共同作用 |

**第 5 行是决定性的**：差分对称激励下只有一条腿振荡，说明失稳不是纯线性网络行为
（线性网络在对称激励下两腿完全对称）。这是宏模型大信号块（`ESD_IN`/`ESD_OUT`/
`CLAW`/`CL` 限幅/`AOL` 钳位）在正负摆幅上不对称造成的。

### 6. 与 C9 同源

C9（规格 §5.2）考核的正是**跟随器节点 peaking ≤6 dB**，理由写的是
"OPA388 闭环输出阻抗中频负实部可与阶梯电容形成谐振"。
本轮数据把这条机理**定量坐实**：

- 原参数 R1=2.74 Ω：跟随器节点 10.66 dB（C9 超限 4.7 dB）→ 100 kΩ 处 499 mV 极限环
- 修复 R1=6.19 Ω：跟随器节点 4.75 dB（C9 过）→ **0–600 kΩ 全范围回稳**

→ **C9 修好了，D5 的中间阻抗缺口自动消掉**。这是同一根杠杆。

## 机理表述（写进设计文档用）

> OPA388（TI SBOS777D Rev D 宏模型）的单位增益跟随器闭环输出阻抗在
> **100 kHz–1 MHz 区间 Re(Z_o,cl) 为负**（−0.9 Ω @100 kHz、−2.78 Ω @275 kHz、
> −2.0 Ω @400 kHz；`r5_zout_opa388_ti.json` 700 点实测表）。
> 该负阻与首级阶梯电容 C_gnd,1 构成并联谐振回路，等效 Q ≈ |Re(Z_o,cl)| / R_series。
> 当 R_series（首级隔离电阻）= 2.74 Ω 时 Q > 1，跟随器节点在 ~290 kHz 出现 +10.7 dB 峰；
> 大信号阶跃把宏模型输出级推入钳位/限幅区，负阻进一步增强，形成**自持极限环**。
> 把 R_series 提到 6.19–6.98 Ω 后 Q < 1，峰值降到 4.2–4.8 dB，极限环消失。
>
> **真实硅片是否会同样失稳？** 未做硅验证。但两条独立理由支持"需要按会发生来设计"：
> ① Re(Z_o,cl)<0 不是宏模型独有的伪影——它是单位增益反馈在 A_OL 接近 1 处
> 相位裕度不足的物理表现（OPA388 数据手册 Fig.6-25 的开环 Z_o 峰 190 Ω @400 kHz
> 与 A_OL 的 −90° 相位共同决定）；② C9 已经把这条写进硬约束。
> 因此**不依赖"硅片可能不会振"来做设计**。

## 仿真规避建议（给后续复测）

按有效性排序：

1. **首选：把首级 R 提到 ≥6.2 Ω**（本轮已冻结 6.19 Ω）。
   极限环消失、C9 同步达标，**不需要任何求解器技巧**。
2. **求解器设置**：保留 `method=gear reltol=1e-5 trtol=7 maxstep=20n`。
   本轮的判别表明 `trap` 与 `gear` 给出同一结论（498.9 vs 498.8 mV），
   换积分方法**不能**用来"消除"极限环——它真实存在。
   更紧的 `reltol=1e-7 / maxstep=2n` 在 TI 宏模型上会超时（>400 s），不建议作为常规复测设置。
3. **判别真伪的推荐做法**（而不是改求解器）：
   - a) **自治性检验**：输入保持 DC，看是否自振。自振 = 真·不稳定平衡点；
     安静 = 边沿激发的非线性极限环（本工况属后者）。
   - b) **输入电容置零对照**：本地副本把 `C_C_DIFF/C_C_COM0/C_C_COM1` 置 1 fF。
     若极限环消失，说明输入极点参与（本工况确认参与）。
   - c) **理想跟随器对照**：`Efa fpa 0 fa 0 1`。若无源部分稳定，失稳必来自运放。
   - d) **两腿分开看**：对称激励下若只有一条腿振，必是大信号非线性（对称线性网络不会）。
4. **`maxstep` 与 `.save` 的实务**：真实模型 + 长窗 + 多向量会写出数百 MB 的 `.raw`。
   本轮用 `.save V(pa3) V(na3) V(fpa) V(fna)`（4 个向量）+ `maxstep=20n`，
   每条 400 µs 仿真约 1–2 s、`.raw` 约 1–3 MB。

## 对规格的建议（不阻塞本轮冻结）

1. **D5 的工况点应扩到中间阻抗**：§5.1 现在只规定 0 Ω 与 600 kΩ。本轮证明这两个点
   **恰好都在稳定区**，而 50–300 kΩ 全在失稳区。建议改为
   `0 / 10k / 100k / 220k / 600k`（覆盖 10–120 kΩ 设计量程与 1% 可用范围）。
2. **C9 的考核节点应写明"跟随器输出"**：按引脚判三案全过、按跟随器判全不过
   （第 3 轮 §4.2）。本轮已按跟随器节点执行。
3. **C9 与 D5 是同一根杠杆**：建议在 §5.2 C9 的理由里补一句
   "C9 不达标的方案在大信号阶跃下会出现 D5 极限环"，把两条约束显式绑定。
