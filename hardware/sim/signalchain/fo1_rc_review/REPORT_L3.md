## 0. 口径声明（先读，任务书 §3.2/§3.3 的强制要求）

1. **本报告是「LTspice 交流族 CSV（模拟前端频响，T01/T02/T03/T10 产物）× ADS131A02
   手册 sinc³ 传递函数」的离线 Python 乘法后处理。不是 LTspice 直接仿真 ADC 数字内核，
   也不含真实开关采样模型。**所有"数字域"列 = 模拟复响应 × 手册闭式 sinc³。
2. sinc³ 实现按 SBAS590E 口径（本仓库核对件
   `hardware/sim/aaf/r5_datasheet_facts.md` §2 / §数字滤波器）：
   fMOD = 4.096 MHz、fDATA = 128 kSPS、OSR = 32（**全局寄存器，两通道同设**）。
   传递函数 H(z) = [(1−z⁻³²)/(32·(1−z⁻¹))]³，对 fMOD 归一，DC = 1。
3. **折叠风险为有界评估，不是"已验证混叠"**：把输入开关采样当作理想 fMOD 冲激采样
   （折叠增益按最坏 0 dB 计），模拟残存幅度取 T01 实测 D1 外加一阶滚降斜率修正
   （该修正本身为理论估算，未逐点仿真）。**孔径衰减未包含**——手册未给有效孔径时间
   （r5_datasheet_facts.md 已登记为无规格项），真实折回幅度只可能低于本界。
4. LSB = 2.442 V / 2²³ = **0.291 µV**；CH1 信号全幅 1.2 V（8 µA×150 kΩ），
   CH0 示例 0.376 V（@47 kΩ 样品）。

## 2. Block A — Hratio(f)=H0/H1 幅相误差与 R 比值误差（csv A_hratio 块）

**归一化定义**（任务书 §3.3）：H0 = CH0 差分输出 / CH0 模拟激励、H1 = CH1 差分输出 /
CH1 模拟激励（各自归一，激励源条件一致），Hratio = H0/H1。两种源条件：
`ideal0ohm`（两通道 0 Ω 差分源）与 `real_src`（CH0 经 23.5 kΩ/边源阻抗＝47 kΩ 样品、
CH1 源 ≈ BSS138 低阻——真实接线口径）。

**关键结论：sinc³ 在比值中精确消去。** ADS131A02 的 OSR 为全局寄存器，两通道数字滤波器
严格相同，H0·S / (H1·S) = H0/H1。CSV 在 ideal0ohm 行用复数乘除做了数值演示
（`sinc_cancel_resid_dB` 列 ≤ 2e-15 dB，即浮点精度）；real_src 行 dig 列 = 模拟值原样
（t01 无该源条件的相位数据，消去是代数事实不依赖数据）。
**例外警告：若固件日后单通道改 OSR/滤波器配置，此消去不再成立，须重做本节。**

R = (Vsample/VRsense)×Rsense 的比值链误差（1 k–16 kHz 最坏，real_src 口径；
`worst(1k-16k)` 行为 |Hratio| 峰峰 dB、|Δφ| 最大值，t03 原口径）：

| 方案 | \|Hratio\| p-p | 折合幅度误差(p-p) | Δφ 最大 | 8 kHz 点 | 16 kHz 点 |
| --- | ---: | ---: | ---: | ---: | ---: |
| FO1_BASE | +0.00050 dB | +57.6 ppm | 0.6506° | −11.5 ppm / −0.327° | −57.6 ppm / −0.654° |
| FO1_A | +0.00040 dB | +46.1 ppm | 0.6517° | −11.5 ppm / −0.327° | −46.1 ppm / −0.655° |
| FO1_B | +0.00040 dB | +46.1 ppm | 0.6522° | −11.5 ppm / −0.327° | −46.1 ppm / −0.656° |
| FO1_C | +0.00040 dB | +46.1 ppm | 0.6517° | −11.5 ppm / −0.327° | −46.1 ppm / −0.655° |

归因（t03 数据）：0.65° 相位失配几乎全部来自 **CH0 源阻抗不对称**（ideal0ohm 口径
Δφ 仅 0.045°，23.5 kΩ/边源把 CH0 相位多拉 ~0.61°）——是"样品在 CH0 线上、Rsense 在
CH1 线上"的物理事实，不是四案 RC 参数的差别；四案之间差异 ≤0.002°。幅度侧四案差异
≤0.0001 dB（11.5 ppm），可忽略。**准静态（DC）比值误差为 0；该误差只在冲击瞬态的
高频成分经 16 kHz 级带宽时出现。**

## 3. Block C — Kelvin 结构性 CM→DM 进入比值链（csv C_cm_leak 块）

CH1（Rsense 差分对，P 线经运放 / N 线无源 RC 到 E 点）对共模激励的差分泄漏是带内信号，
**sinc³ 对它同样不提供抑制（同通道、同滤波器，比值中消去）**。按
ΔR/R = 10^((CM→DM − H1)/20) / 1.2 V 折算（t02 kelvin 行 ÷ t01 H1）：

| 方案 | @1 kHz | @8 kHz | @16 kHz | 每 1 V 共模的 ΔR/R |
| --- | ---: | ---: | ---: | --- |
| FO1_BASE | 84.0 ppm | 666.8 ppm | 1278.8 ppm | 16 kHz 处 0.13% |
| FO1_A | 84.0 ppm | 669.2 ppm | 1310.4 ppm | 0.13% |
| FO1_B | 84.0 ppm | 670.0 ppm | 1326.4 ppm | 0.13% |
| FO1_C | 84.0 ppm | 669.9 ppm | 1326.9 ppm | 0.13% |

**这是比值链最大的带内误差源，比差模 Hratio 误差（≤58 ppm）大一个量级**，且四案几乎
无差别（结构性，由 AIN1N 无第四颗运放的接线决定，与 RC 取值基本无关）。实际共模电压
幅值取决于 PCB/地系统，本表给的是每伏系数，绝对误差待上板标定。

## 4. Block B — 4.096 MHz±{1k, 8k, 16k} 折叠回带内的有界风险（csv B_alias 块）

机理：fMOD±Δ 经理想 fMOD 采样折叠回 Δ Hz（4.095/4.096/4.097 MHz → 1 kHz，
4.088/4.104 MHz → 8 kHz，4.080/4.112 MHz → 16 kHz）。**sinc³ 对折叠后的频率
（1/8/16 kHz）衰减仅 −0.003/−0.17/−0.67 dB ≈ 0 dB——数字域对这些折叠分量基本无保护，
防线只剩模拟 RC。** 残存幅度 = T01 实测 D1（@4.096 MHz）+ 一阶滚降斜率修正（理论，
±16 kHz 处 ±0.03 dB）：

每 **100 mV** 差模注入折回带内的电平（dBc → µV → LSB → 折合 R 误差，CH1 口径 ÷1.2 V）：

| 方案 | CH0 dBc | CH0 µV | CH0 LSB | CH1 dBc | CH1 µV | CH1 LSB | R 误差(ppm/100mV) |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| FO1_BASE | −40.7 | 924 | 3171 | −38.4 | 1201 | 4122 | 1000 |
| FO1_A | −38.7 | 1157 | 3973 | −37.6 | 1323 | 4545 | 1103 |
| FO1_B | −37.6 | 1324 | 4548 | −36.8 | 1441 | 4948 | 1201 |
| FO1_C | −38.7 | 1159 | 3980 | −37.6 | 1324 | 4547 | 1103 |

（表取 ±1 k 两频点平均量级；±8 k/±16 k 各行见 CSV，同一数量级，852–1441 µV。）
注：R 误差按最坏单通道注入（不抵消）计。若同一干扰同频同相同幅同时进两通道，比值中
按两通道残存差（CH1 比 CH0 多 ~2.3 dB）部分抵消，残余约 20%；按最坏界报告。

**交叉核对（非本层输入，仅对拍）**：
1. 与 `csv/t09_ac_residual.csv` 的 28 个同频点实测模拟残差（P 线注入，AC 实测）对拍，
   本层斜率修正外推与 T09 实测**最大偏差 0.034 dB**（脚本 xcheck 实跑，无 >0.15 dB 告警）；
2. 与 `csv/t09_fold_check.csv` 的瞬态实测拟合（LTspice 采样序列 + 离线 sinc³，
   Ron=100 Ω 假设）对拍：FO1_BASE @4.104 MHz 拟合 950.5 µV/100 mV vs 本层 AC 口径
   ~904–921 µV，一致在 3–5% 内。三条独立路径（T09 AC、T09 瞬态拟合、本层）收敛。

**16.384 MHz 族**（= 4×fMOD，恰折叠回直流；任务书 T09 范围、本 ask 指定 4.096 MHz 族
之外）：引 `t09_ac_residual.csv` 实测——四案 16.384 MHz±16 kHz 残存 −59～−63 dBc，
约 68–111 µV/100 mV（230–380 LSB），比 4.096 MHz 族低 ~20 dB，未入本层 CSV。

## 5. Block D — 群延迟复合（csv D_group_delay 块）

模拟段（t10）2.17–2.48 µs + sinc³ 恒定 11.3525 µs（1 k/8 k/16 kHz 三点数值微分完全
一致，通带内线性相位）。**CH0−CH1 失配仍为模拟段值**（sinc³ 两通道相同，差分中消去），
四案 0.11–0.13 µs，D10（≤5 µs）结论不变。

## 6. 未验证项与上板测试建议（NOT VERIFIED，不宣称已验证混叠）

1. **孔径衰减未建模**：手册无有效孔径时间规格（r5_datasheet_facts.md 登记为无规格），
   真实折回幅度可能显著低于本界（4 MHz 级孔径滚降通常可观）——上板实测见分晓；
2. **真实开关/调制器非理想未建模**：Ron（手册无规格，T09 按 100 Ω 假设扫值）、双相
   时序误差、斩波残余——折叠增益按最坏 0 dB 计；
3. **未做瞬态折叠的完整 L3 仿真**（采保波形×sinc³ 全数字链）：t09_fold_check 的瞬态
   拟合是最近似物，但其自身也依赖 Ron 假设与理想开关；
4. **共模绝对量未定**：Block C 只给每伏系数，实际共模电压取决于 PCB 布局与地系统；
5. **OSR 全局同设是消去前提**：固件若单通道改配置须重做 Block A。

**上板测试建议（首板必测）**：
- 信号源经 100 mV 级耦合注入 AIN 引脚附近，频点 4.096 MHz±{1 k, 8 k, 16 k}、
  16.384 MHz±{1 k, 8 k, 16 k}，读 ADC 码字折回分量，与本界（表 §4）比对；
- 两通道同时注入同频同相干扰，量比值抵消残余，验证最坏界保守度；
- 板上共模注入（Rsense 底 E 点对地干扰）量 Kelvin CM→DM，标定 §3 系数；
- 固件锁定 OSR=32 全局配置，验证 Hratio 相位失配 ~0.65°（可用 16 kHz 正弦激励两通道
  同测读相位差对照）。

## 7. 结论摘要

- **Hratio 幅相**：sinc³ 精确消去；四案 1 k–16 k 比值幅度误差 ≤58 ppm、相位失配
  ≤0.66°，且相位失配由 CH0 源阻抗（样品阻值）主导而非 RC 方案——四案在本指标上
  无差别；
- **比值链误差排序（带内）**：Kelvin CM→DM（~1300 ppm/V @16 k）≫ 差模 Hratio
  （≤58 ppm）；
- **fMOD 折叠**：sinc³ 对 fMOD 附近折叠无保护（0 dB），四案残存 −36.8～−40.7 dB，
  每 100 mV 注入折回 852–1441 µV（2925–4949 LSB、折合 R 误差 710–1201 ppm）——
  **有界评估，非已验证混叠**；D1 一阶先天不足（≥80 dB 门槛）使该风险成为一阶方案
  的固有残留，上板注入实测是唯一关闭路径。
