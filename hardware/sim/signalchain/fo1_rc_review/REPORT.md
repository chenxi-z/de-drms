## 1. 结论摘要

**问题**：`100 Ω + 22 nF + 820 pF`（FO1_A）能否替代现有 `47 Ω + 47 nF + 820 pF`（FO1_BASE）？

**回答：可以替代，且是三个候选中唯一值得采纳的——但必须同时明确：四案（含 BASE）在原规格
D1/D2/D3 上全部 FAIL、未配对 D8 全部 FAIL，这是"一阶拓扑先天不足"而非参数选择问题；
换 FO1_A 不改善也不显著恶化这些 FAIL，其价值是 −51% 占地（−32.0 mm²）换 1–4 dB 的
指标代价，且不触碰任何已 PASS 项的门槛。**

分条依据（全部为本目录实测）：

1. **面积**：FO1_A 双通道 AAF 占地 30.4 mm² vs BASE 62.4 mm²（外廓口径，−51%）；
   47nF/1210→22nF/0805 每件 −8.00 mm²（−63.5%），×4 = −32.0 mm²
   （`bom_footprint_check.md` §4.1/§4.2）。
2. **指标代价（FO1_A 相对 BASE，CH0 opa388 口径，`csv/t01_dm_ac.csv`）**：
   D1 38.72 vs 40.68 dB（−1.96）、D3 59.08 vs 62.67 dB（−3.59）、D2 38.11 vs 40.39 dB
   （−2.28）——三项本来就 FAIL（差 40+ dB），该降幅不改变任何判定。
3. **不触碰已 PASS 项**：D4 0.238 ≤0.5（BASE 0.2234）、D5 最坏角 30.5 µs ≪900、
   D6a 线性口径 CH1 3.31% ≤30%、D7 σ 0.0089 dB ≤0.05、D9 通道判据余量 ≥4×、
   D10 0.126 µs ≤5、C9 0.33 dB ≪6（`csv/t01/t04/t05/t06/t08/t10/t07` 各文件）。
4. **代价点（如实）**：kickback 最坏 45.2 µV（BASE 21.6，×2.1）仍 ≪ 半周期回稳判据；
   4.104 MHz 混叠折回 1215.8 µV/100 mV（BASE 934.8，×1.3）同一量级
   （`csv/t08_kickback.csv`、`csv/t09_ac_residual.csv`）；22nF/0805 LCSC 现货仅
   ±1% 档 521 只（样机 4 只/板够用，量产 ±5% 档需锁 DigiKey 渠道），
   47nF/1210 在 LCSC 今日 0 库存（`bom_footprint_check.md` §0/§1.1/§1.4）。
5. **B/C 不值得**（详见 §4）：B（200Ω+10nF）D1/D2/D3 全垫底、正交口径 D6a 36.78% 超
   30% 淘汰线、kickback 95.3 µV、混叠 1507.7 µV，只为相对 A 再省 10.5 mm²；
   C（100Ω+10nF+6.8nF）虽然未配对 D8 最优（40.6 dB）且占地最小，但 D2 31.2 dB
   （比他案差 5–9 dB）、C_D=6.8nF 在 Kelvin N 线踢峰 182 mV（BASE 7.6 mV 的 24 倍）、
   混叠 2678.2 µV/100 mV（BASE 的 2.86 倍、A 的 2.20 倍）三处独立证据反对。
6. **无论选哪案，D1–D3 的 FAIL 意味着 4.096 MHz 附近防线只剩 PCB 布局与上板实测**
   （§5.1）：每 100 mV 差模注入折回带内，CH0 口径 852–1324 µV（2926–4551 LSB）、
   CH1 口径 1107–1441 µV（3804–4951 LSB，折合 R 误差 923–1201 ppm，最坏单通道不抵消）；
   sinc³ 对折叠后频率仅 −0.003~−0.67 dB 无数字域保护（`REPORT_L3.md` §4）。

**附带发现（任务书前提与事实冲突，需用户裁决）**：任务书称"47 nF C0G 只能取得 1210"，
实测 LCSC 有村田 47nF/1206 C0G（GRM31M5C1H473JA01L，C21812）现货 51,375 只，且生产 BOM
自用 68nF/1206 C0G——**若保留 47Ω+47nF 电路、仅把 C_G 封装 1210→1206，零电路改动省
4.54 mm²/件（−36%）**，占地 44.2 mm² 仍大于 FO1_A 的 30.4 mm²
（`bom_footprint_check.md` §4.2/§5 冲突 C-1）。

## 5. 关键问题

### 5.1 4.096 MHz 附近混叠风险（L3 有界评估，非"已验证混叠"）

- **机理实测**：4.096M±{1k,8k,16k} 经理想 fMOD 冲激采样折叠回 {1,8,16} kHz，sinc³
  (OSR=32) 对折叠后频率仅 −0.003/−0.17/−0.67 dB ≈ **无数字域保护**，防线只剩模拟 RC
  （`REPORT_L3.md` §4，`csv/l3_hratio_alias.csv` B_alias 块）。
- **模拟残存（三条独立路径收敛）**：T09 AC 28 频点实测、T09 瞬态采样序列×sinc³ 拟合
  （fit_over_pred_phased 0.9974–0.9994）、L3 斜率修正外推（与 T09 实测最大偏差
  0.034 dB）——每 100 mV 差模注入折回带内（`csv/l3_hratio_alias.csv` B_alias 块，
  4.08–4.112 MHz 七频点×两通道）：**CH0 口径 852–1324 µV（2926–4551 LSB、折合 R 误差
  710–1104 ppm）；CH1 口径（最坏单通道不抵消）1107–1441 µV（3804–4951 LSB、
  923–1201 ppm）**。分方案（CH1，AC 幅度口径）：BASE 1107–1201 最低 < A 1220–1323 ≈
  C 1221–1324 < B 1328–1441 最高；相位修正口径（下条）则 C 最高。
- **真实接线特有（T09 相位翻转发现）**：两侧 S1 反相采样使 Kelvin N 线馈通在采样序列中
  变号——混叠幅度 = |P+N| 而非 AC 的 |P−N|：BASE 950.5 / A 1238 / B 1534 / C 2728.7
  µV/100 mV；相位修正预测与折叠瞬态 LSQ 拟合四案相差 <0.3%。**C 案瞬态折叠实测比
  未相位修正的朴素 AC 预测大 2.36 倍**（`csv/t09_fold_check.csv` fit_over_pred=2.3558；
  BASE/A/B 仅 1.03–1.16），根因 C_D=6.8nF 加剧 Kelvin N 线馈通；16.384M=4×fMOD 族无翻转。
- **上板必测（唯一关闭路径）**：16.384 MHz 晶振/时钟走线远离模拟前端与 Kelvin 线、
  C_D 靠 ADC 引脚、模拟区完整地平面；首板灌 4.104 MHz/16.392 MHz 定幅音实测输出折叠。
  孔径衰减（手册无规格）与真实调制器非理想未建模——真实幅度只可能低于本界。
- fMOD 附近引脚耦合需 **<≈11 µV（FO1_C，折回传输最大）～<≈33 µV（FO1_BASE）** 才能压到
  1 LSB 以下（按 1 LSB=0.291 µV ÷ 相位修正折回传输系数换算，覆盖 4.08–4.112 MHz
  七频点：BASE 30.4–33.1 / A 23.4–25.4 / B 18.9–20.5 / C 10.6–11.5 µV，
  `csv/t09_ac_residual.csv` alias_phased_uv_at100mV 列）。

### 5.2 AIN1N Kelvin 接地非对称（真实接线，非理想化四运放）

- Kelvin 真实接线比对称 CH0 口径再差：D1 40.7→38.4、D3 62.7→52.9（BASE）——AIN1N 无源
  RC 直通是**结构性代价**（`csv/t01_dm_ac.csv` kelvin 行）。
- Kelvin 结构 CMRR_RC 通带最差 56.0–56.3 dB @≈15.9 kHz（四案几乎相同，由拓扑决定、RC
  参数几乎不影响），cmdm_1k≈−79.9 dB 处于 80 dB 临界（`csv/t02_cm_ac.csv`）；
  对称口径的 ≈300 dB 为求解器数值底（器件完全对称），**不能作为 D8 达标证据**——真实
  散布由 T06 给出（§3.1）。
- 比值链最大的带内误差源是 Kelvin CM→DM：16 kHz 处 1279–1327 ppm/V、8 kHz 667–700
  ppm/V，比差模 Hratio 误差大一个量级（`REPORT_L3.md` §3）；绝对量取决于 PCB/地系统，
  待上板标定。
- 对称口径（ideal/opa388 CH0）的 CMRR 未配对散布须 T06 ≥1000 组容差 MC（已做，
  §3.1），本报告不冒充。

### 5.3 16 kHz 双通道幅相误差

- 通带内 H0/H1 幅度差 ≤0.0005 dB、相位差 ≤0.66°（1k–16k，real_src 口径；
  `csv/t03_channel_match.csv`）。**0.65° 失配由样品 47 kΩ 源阻抗×运放输入电容引入
  （CH0 特有，ideal0ohm 仅 0.045°），非 Kelvin 结构（通带内贡献 ≤0.046°）、非四案 RC
  差异（四案互差 ≤0.0001 dB / 0.002°）**。
- sinc³ 在 Hratio=H0/H1 中精确消去（全局 OSR 两通道同设；复数乘除演示残差 <2e-15 dB）；
  **例外警告：固件若单通道改 OSR/滤波配置，此消去不再成立**（`csv/l3_hratio_alias.csv`
  A_hratio 块）。
- 高阻样品（600 kΩ）下 CH0 源阻抗致相位失配会更大，L3 未逐一外推（t04/t10 部分覆盖）。

### 5.4 是否需要匹配/标定（D8 结论）

- **未配对量产（模式 A）四案全 FAIL**：C±5% MC P1=34.0–40.6 dB、LTspice 确定性最坏
  失配角 31.7–38.4 dB（阈 80）；C±1% 仍 FAIL（P1 44.2–50.7）。**原报告"一阶免配对"
  不成立**（`csv/t06_d7_d8_verdict.csv`）。
- **R·C 乘积异向配对（模式 B，spec:78 官方考核条件 R×(1+m) 配 C×(1−m)，1% 单体）四案
  PASS**：MC P1=93.8/93.8/94.3/100.5 dB。工艺成本：每板 2 对差分线 4 组 R·C 乘积需
  LCR 实测配对（1 kHz、0.1% 级仪表）+ SMT 前分档工时；C_D 不在配对范围。
- 验证路径：首板 T 点注共模（2 V DC+AC）实测 CM→DM 泄漏 @10 Hz–16 kHz，或首件 LCR
  复测装后乘积失配（spec:103 已要求 BOM 加配对工序）。
- **D6a 双口径分歧（判罚维持规格字面线性口径，两口径并列未删）**：正交（物理功率叠加）
  口径 √(n1²−n3²)/n3 下 fo1_b CH1=36.78% 超 30% 淘汰线（原因：CH1 单运放底噪 √2 低于
  CH0 叠加、2×200 Ω Johnson 最大）；但其宽带总噪声 2421 nV=8.32 LSB 与他案同量级，
  是相对底噪占比问题而非绝对噪声恶化（`csv/t05_noise.csv` note_3）。

### 5.5 其余如实记录的口径问题

- **C9 锚定不等**：2026-10-23 文档 FO1 C9=+1.4 dB，本轮跟随器输出节点实测 +0.69 dB
  （t00 foll_pk 独立交叉一致）→ +1.4 dB 锚定产生口径不可考证；判定不受影响（四案
  0.17–0.69 dB ≪6 dB，`csv/t07_stability.csv` note_3）。

  低于物理/数值地板 → ownss 判据 19/40 行 FAIL；按物理主判据（残余≤0.01%·通道差分稳态
  ≈1.17 V）四方案×全部 Ron/vcm 组合 PASS（最差 2.266e-5，余量 ≥4.4×）。双判据在 CSV
  并列保留，未删除 FAIL 行（`csv/t08_kickback.csv`）。
- **CH1 静态差分增益误差**（ADC 输入电流经 RKB+RKN 的 DC 模型 + 开关电容并存口径）：
  时钟运行时 dm_ss 读数偏低 BASE −0.18% / A·C −0.38% / B −0.75%；CH0 两线同为跟随器
