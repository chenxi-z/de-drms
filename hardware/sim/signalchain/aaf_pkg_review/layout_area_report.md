## 1. 结论表（每差分通道真实占地 vs §4 本体面积规则）

面积口径 = **铜包围框面积**（焊盘 + 地过孔 + 走线的外接矩形，内部间距天然包含）；
单位 mm²；坐标单位 mil（1 mil = 0.0254 mm），数值自读回图元实测（落盘舍入 0.1 mil）。

| 方案 | 器件/通道 | 每通道 L×H (mm) | **每通道真实占地 (mm²)** | 两通道铜面积和 | 两通道合围（含 40 mil 通道距） | §4 本体面积 | 真实/本体 |
|---|---|---|---|---|---|---|---|
| S0 | 2×R0402 + 2×C0805 + 1×C0402（5 件） | 3.674 × 10.627 | **39.05** | 78.11 | 81.85（3.674×22.276） | 6.5 | 6.01× |
| S1 | 同上（值不同） | 3.674 × 10.630 | **39.06** | 78.12 | 81.85 | 6.5 | 6.01× |
| T1 | 4×R0402 + 4×C0402 + 1×C0402（9 件） | 4.942 × 6.600 | **32.62** | 65.24 | 70.25（4.942×14.216） | 4.5 | 7.25× |
| T2 | 同上（100/120 Ω） | 4.942 × 6.600 | **32.62** | 65.24 | 70.25 | 4.5 | 7.25× |
| T3 | 同上（68/150 Ω） | 4.942 × 6.600 | **32.62** | 65.24 | 70.25 | 4.5 | 7.25× |
| T4 | 同上（82/160 Ω） | 4.942 × 6.600 | **32.62** | 65.24 | 70.25 | 4.5 | 7.25× |

要点：

1. **S0 与 S1 占地等同**（39.05 vs 39.06，差异仅落盘舍入）——印证任务书 §4 预判
   「CG 都选 0805 时占地应作同一封装等级比较」，面积不能作为 S0/S1 的取舍依据。
2. **二阶 9 件全 0402 比一阶 5 件（含 0805）小 6.43 mm²/通道（−16.5%）**。
   主导因素是 C0805 立式落地的 land pattern（焊盘节距 2.0 mm + 焊盘 1.41×1.35 mm）
   把通道高度从 6.60 mm 拉到 10.63 mm；T 系虽然件数多一倍、长度多 1.27 mm，高度优势完胜。
3. 任务书 §4 的警示成立：**本体面积不代表真实占地**（6～7 倍差距），且
   「二阶多四件、真实占地不一定更小」的担心被实测反向否定——二阶反而更小。
4. 两通道合计有两个口径：铜面积和（通道各自包围框相加）与合围（外接矩形，含 40 mil
   通道间铜净距）。上表两者都给；**若 AAF 两通道贴邻布置，占板面积应按合围口径**
   （S 系 81.85 / T 系 70.25 mm²）。

## 2. 副本与「绝不改写原图纸」的保证

### 2.1 为什么是板级副本而不是工程级副本（偏离说明，非静默降级）

- EasyEDA API **没有工程级复制**：`DMT_Project` 只有 create/open/move/getInfo
  （见 `references/classes/DMT_Project.md` 方法表）。
- 建新工程再 `openProject()` 切换，SKILL.md 明文警告「may discard unsaved changes in
  the currently opened project」——原工程正处于活跃编辑状态（见 §2.3），此风险不可接受，
  与「绝不改写原图纸」冲突，故弃用。
- 采用 `DMT_Pcb.copyPcb()` 在**同一工程内**复制 PCB1 → 副本文档 **PCB1_1**
  （uuid `537c2dab302e8997`，自由 PCB，不挂在 Board1 下）。六方案布局全部画在 PCB1_1 上。
- 原图纸零改动证据：绘制完成后切回 PCB1（uuid `7f5db17ea6083de2`）只读点数——
  **AAF_* 网络焊盘数 = 0**，元件/焊盘/走线均为原有内容；本会话对 PCB1 与全部原理图页
  的全部调用均为只读查询（getCurrentProjectInfo / getAll* / openDocument）。

### 2.2 手动制作「真·工程级副本」的步骤（如需）

1. 嘉立创EDA 专业版 → 左侧「工程」面板 → 右键工程「双电极电阻仪」→「另存为工程」
   （或 文件 → 另存为工程），命名如「双电极电阻仪-AAF评测副本」；
2. 打开副本工程，删除不需要的实验文档（如本报告的 PCB1_1 可保留作参照）；
3. 六方案评测块当前就在原工程的 PCB1_1 上，可在副本工程中用
   「文档 → 右键 PCB1_1 → 复制到其它工程」带走，或直接按本报告 §6 的 JSON 坐标复现。

### 2.3 会话期间的原工程状态观察（非本人改动）

- 复制时刻 PCB1 快照：472 焊盘 / 4 过孔 / 149 元件（副本 PCB1_1 保留了该快照）；
- 会话末 PCB1 实测：468 焊盘 / 4 过孔 / 207 走线 / 147 元件。
- 差异（−4 焊盘 / −2 元件）发生于本人仅做只读查询的文档上，判定为**用户侧活跃编辑**，
  与本次评测无关；AAF 件数 0 证实未被本人污染。

## 3. 布局方法（两方案族统一方法学，只差封装与级数）

### 3.1 焊盘几何 = 本工程项目库真实 land pattern

自原工程库 `lib_Footprint.getDocumentSource` 提取（`fp_pads.json`）：

| 封装 | 焊盘节距 (mil) | 单焊盘 (mil) | 用途 |
|---|---|---|---|
| R0402 | 34.08 | 22.27 × 21.26（RECT） | 全部电阻 |
| C0402 | 33.08 | 19.685 × 21.26（RECT） | Cd、T 系 CG |
| C0805 | 78.74 | 55.512 × 53.15（RECT） | S 系 CG |

### 3.2 通道拓扑（每差分通道）

```
        CG_P(立式,向外)          Cd(立式,跨中) —— 仅一只,两行共用
 IN ──[R1]──●──────●────────●── OUT(至 ADC AIN)     ← P 行 (通道中心 −50 mil)
            │stub  │via旁置   │
            ●      ●(GND)    ●                        ← 镜像轴（通道中心线）
            │stub  │via旁置   │
 IN ──[R1]──●──────●────────●── OUT                   ← N 行 (通道中心 +50 mil)
        CG_N(立式,向外)          （二阶：R1 后串 R2，两个节点各落一组 CG+GND via）
```

- **P/N 严格镜像**：N 行全部图元为 P 行绕通道中心线的精确镜像（含 Cd 居中对称）；
- 电阻沿行走线串臂；CG 立式垂直落出，**每只 CG 独立 GND 过孔**（0.3/0.6 mm = 12/24 mil），
  过孔旁置于 CG 远端焊盘侧方 10 mil（不额外增高包围框）；
- 间距规则：CG 内侧焊盘边缘距行中心 ≥25 mil（避开节点焊盘区）、异网络铜缘净距 ≥10 mil、
  信号线宽 8 mil、接地短线 10 mil、**通道间铜净距 40 mil（1.016 mm）**；
- 每通道元件数与位号语义：S 系 = R1_P/R1_N + CG_P/CG_N + Cd（5 件，10 焊盘 + 2 过孔）；
  T 系 = R1/R2×P/N + CG1/CG2×P/N + Cd（9 件，18 焊盘 + 4 过孔）。
  网络名 `AAF_<方案>_CH<n>_<IN|N1|N2>_<P|N>` 与 GND，逐件可追溯。

## 4. 模拟敏感区与高速线（真实板走廊分析，来源：PCB1 只读勘察）

副本 PCB1_1 保留了复制时刻的真实板（149 元件）。关键锚点（mil）：

- **U7 = ADS131A02（TQFP-32）@ (1433, −484)**；左侧 AIN 引脚缘 ≈ x 1335；
- **OPA388 跟随器列：U9 (730, −195)、U11 (730, −365)、U12 (730, −535)**（SOT-23-5）；
- U10 = TMUX1134（TSSOP-20）@ (619, −791)；U13 @ (436, −395)；
- **U6 = STM32U545（LQFP-64）@ (2363, −751)**——SPI1 高速侧在 U7 右侧朝 U6；
- 晶振 X1 (1660, −124)、X4 (2290, −1300)、X2 (2025, −1260) 均不在左走廊。

**AAF 天然走廊 = 跟随器列（x≈730）与 U7 左引脚（x≈1335）之间**，但勘察发现走廊已被
既有前端 RC 群占据：R34–R37（R0603，x=1005，y −199…−550）、C47–C49（C0402，x=824）、
R22–R24（R0402，x≈1300，y −203）。最大连续空窗仅 x∈[860, 990] ≈ 3.3 mm，小于任何评测块宽。
因此：

- 六方案评测块统一置于 **x ≥ 8600 的板外评测区**（与既有铜净距 554.6 mil），
  未触碰真实板内容——占地是布局的内在属性，不因放置位置改变；
- **落位建议**：AAF 以「替换既有前端 RC 群（R34–37/C47–49/R22–24 一带）」的方式进真实板，
  P/N 行走向与 U7 左侧 AIN 引脚列垂直正交，GND 过孔向走廊外侧打；
  SPI/时钟高速线在 U7 右侧与上方，与 AAF 走廊隔整颗 ADC，天然规避；
  评测块按合围口径（3.67×22.3 或 4.94×14.2 mm）规划走廊净空即可。

## 5. NOT VERIFIED / 限制（如实声明）

1. **真·工程级副本未创建**（API 不存在 + openProject 有丢弃原工程未保存改动的风险）→
   用工程内板级副本 PCB1_1 替代；原图纸零改动已由读回证实（§2.1/§2.3）。手动步骤见 §2.2。
2. **评测块未集成进真实板内走廊**：走廊被既有前端 RC 占据（§4），块置于板外评测区。
   每通道/两通道面积不受影响（内在属性），但「替换 R34–37/C47–49 后的真实落位走线」
   属原理图/PCB 施工阶段工作，本次不做。
3. **DRC 未在副本上跑**：评测块在板框外，DRC 只会产出板框外噪声与既有板自身状态，
   不能为本次结论增量；几何/净距/镜像由程序化断言覆盖（§3.3）。
4. **无截图**：EasyEDA API 不提供 PCB 画布导出图；按任务书「截图或坐标证据」的许可，
   以逐件坐标证据替代（§3.4 + 三个 JSON）。用户可在嘉立创EDA 中打开 PCB1_1 直接目视。
5. 电容实物 SRF/ESL/型号库存按任务书 §1/§5(6) 由设计者核实，本次仅按已确认封装画布局。
