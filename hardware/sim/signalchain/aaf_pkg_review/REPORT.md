## ① 结论摘要（六方案排序与推荐）

**判罚底线先说清：六方案无一满足原 D1≥80 dB 与 D3≥100 dB，门槛未放宽，FAIL 如实保留。**
能跨线的门槛指标只有 D2（T2/T3/T4）与 D4–D10/C9（全案或按口径，见 ③）。

**电气能力排序（门槛跨线数 + 抑制量 + D4 余量综合）**：

| 排名 | 方案 | 一句话 |
|---|---|---|
| 1 | **T2**（100+120 Ω/10nF×2/820pF，全 0402） | **最优电气折中**：D2=61.05 dB 跨线；D1=62.33 dB 六案第二、D3=94.74 dB 六案第三（T4=96.40/T3=95.14 更高）；D4 标称 0.4121/A5 角 0.4609 dB 余量可控（85℃ 叠架 0.4183 dB）；PM 96.34°；真实占地 32.62 mm²/通道 |
| 2 | T4（82+160 Ω） | 抑制最强（D1=63.53/D2=62.25/D3=96.40 dB 全列最高）但 **D4 A5 角 0.4735 dB 距 0.5 淘汰线仅 0.027 dB**（任务书 §2 预判的边界案坐实），量产 C0G 实容差劣于 ±5% 即越线 |
| 3 | T3（68+150 Ω） | D2=60.55 dB 勉强跨线（余量最小 0.55 dB）；D4=0.336/0.376 dB 最平；D1 略低于 T2（61.84 vs 62.33）、D3 反高于 T2（95.14 vs 94.74） |
| 4 | T1（100+100 Ω） | **D2=59.47 dB 边缘 FAIL（差 0.53 dB）**；其余指标与 T2 同型 |
| 5 | S0（47 Ω/47nF/820pF，0805 CG） | 一阶内抑制最高（D1=40.68/D3=62.67 dB）但 D2 差 ~20 dB；**47nF/0805 C0G 无目录料号（阻断项是料号不存在而非寄生，见 ⑤-4）** |
| 6 | S1（100 Ω/22nF/820pF，0805 CG） | 六案全列最低（D1=38.72/D2=38.11/D3=59.08 dB） |

**推荐**（Pareto 明细见 ④）：

1. **首选 T2**。理由：D2 唯一同时跨线且余量（1.05 dB）与 D4 余量（0.039 dB 至淘汰线，A5 角口径）平衡最好；全 0402 真实占地 32.62 mm²/通道比 S 系省 6.43 mm²/通道（−16.5%）；任务书 §2 亦标注 T2 为「优先」。**代价两条必须接受**：(a) D6a 正交口径 44.6% 超 30% 淘汰线（判罚口径=线性口径 9.48% PASS，双口径并列如实，见 ③ 注）；(b) D8 配对必须走「整线同 m」四元件选配工序（R1/R2 同偏 + C1/C2 同偏），逐级各自配只到 51.1 dB FAIL（见 ⑤-3）。
2. **T4 仅作抑制边界备选**：需最高 D1/D2/D3 且量产容差受控（±5% C0G 实测筛选）时才取。
3. **S0/S1 出局**：D2 差 ~20 dB（一阶斜率不够）、真实占地反而大 16.5%、S0 另有料号阻断；S0 与 S1 占地等同（39.05 vs 39.06 mm²，落盘舍入差），**面积不能作为 S0/S1 的取舍依据**。
4. **若 D1≥80/D3≥100 是硬规格**：无源 RC 一阶/二阶在 D4≤0.5 dB 通带约束下**物理不可达**（差距量级与重新设计方向见 ④ 第三行）——这是设计决策点，不是参数微调能解决的。

## ⑤ 关键问题

1. **混叠抑制是系统级缺口，不是参数问题**：D1/D3 六案全 FAIL（③a）；瞬态折回（T09，100 mV 注入口径）S 系 3280–4269 LSB、T 系 280–372 LSB——二阶把折回压掉一个数量级但仍非零；**二阶 16.384M±8k/±16k 瞬态实测为交流相位模型预测的 1.65–8.5 倍**（相位模型的 P/N 近对消在真实时钟开关电容电路不成立，已以瞬态实测为界，`csv/t09_fold_check.csv`）；全部 4.096M 族与 ±1k 折回与交流预测一致（0.8–1.3 倍）。实际风险取决于板级高频注入幅度（MCLK 16.384M 谐波、SPI 干扰路径），AAF 选型只影响 4.096 MHz 以上。
2. **Kelvin 非对称（CH1 AIN1N 无源 RC 直连）的三重结构性代价**：D1 Kelvin 口径比 opa388 舱低 1.1–2.3 dB（一阶 S0 −2.28 与 fo1 上一轮「−2.3 dB」定量一致）；D8 Kelvin 结构地板 ~56 dB（③c，配对不可修复；t02 kelvin 行的 62 dB 系 0.5V 口径乐观 6.02 dB，真实地板以 ~56 dB 为准，见 ③b 注）；线缆共模 1 V 经 dut 寄生（200 p/端）在 16 kHz 的 CM→DM 转换 **−5.2~−5.5 dB**（per-1V Vint 口径，六方案 −5.23~−5.46 几乎相同；t 侧源阻抗 10k∥150k≈9.4k 与 s 侧恒流环低阻不对称主导；CM 单端直通输出另为 −12.0 dB 附近）——**该共模泄漏必须靠屏蔽/线缆/系统级对策解决，RC 参数与级数均无法改善**（`csv/t02_cm_full.csv` ch0_cmdm_16k_dB 列）。
3. **配对要求（量产工序）**：D8 免配对全 FAIL；一阶配对 R·C 异向各自配即达 93.7–94.1 dB；**二阶必须「整线同 m」四元件选配**（每线 R1/R2 同偏 + C1/C2 同偏），逐级各自配只到 51.1–54.5 dB（交叉项 R1·C2 失配，`csv/t06_d7_d8_verdict.csv`）——二阶配对工序严格度高于一阶，选 T2 即接受该工序。通道间（CH0↔CH1）不配对（D8 只考核同通道 P/N；通道间配对属 Hratio 采购动作，CH0↔CH1 相位失配 @16k 全案 −0.044~−0.045°（`csv/t10_group_delay.csv` CH0_minus_CH1_bench 行）、幅度失配 p99 0.032–0.047 dB（`csv/t06_mc_summary.csv` A5 档 hr_mag_16000 p99，L1 MC）；t03 的 dphi 为 bench_realsrc 口径 −0.057~−1.60°、随源阻抗 rs 变，非通道间舱失配）。
4. **0805↔1210 等效性结论对 S0 的影响——阻断项是料号而非寄生**（证据 `parasitic_0805_0402.md`）：村田全库（mlcc.csv 25,626 行）与 TDK 目录内 **47nF/0805 无 C0G 料号**（0805/47nF 只有 U2J/SL/X7R；U2J=0±750 ppm/℃，ΔT=30℃ 容值漂 ±2.25%，破坏 D8 配对与 D4/C9 精度，**不构成 C0G 替代**）；唯一 C0G 候选 KEMET 25V 档仅 broker 渠道无现货证据。寄生层面 47nF 三档（0805/1206/1210）在 **4.096 MHz 段电气等效**（SRF 均 ≥4.7×fMOD、ESL 修正 <3%）；16.384 MHz 段 0805 档（SRF≈28–29 MHz 双参照）余量 1.7–1.8×，1210 档无官方 SRF（理论 19–21 MHz 仅 1.2–1.3×，ESL>1.47 nH 即跌破 MCLK）**不得默认等效**。**出路（归设计者裁决）**：1206 档 C0G ±5%/±2% 均有量产料号（GRM31M5C1H473JA01 SRF 24.5 MHz、LCSC 现货，±2% 档 GRM31M5C2A473GA01）；或容值改 68nF/0805/C0G（GRM2195C2A683JE01 SRF 27.3 MHz 量产 B，电气覆盖 MCLK 1.67×）。T1–T4 全 0402 前提（10nF SRF 84.5 MHz、820pF 310 MHz、22nF/0805 43.1 MHz）全部成立（22nF/0805 为 S1 前提，最小余量位仍安全）。
5. **S0/S1 面积与电气取舍**：占地等同（③b），电气 S0 全面优于 S1（D1 +1.96/D3 +3.59 dB），但 S0 有料号阻断（上条）→ **S1 比 S0 更无存在理由**；若坚持一阶路线，S0+1206（放宽封装）是唯一在产 C0G 方案，但占地将进一步大于 39.05 mm²/通道。
6. **T4 边界确认**：任务书 §2「T4 专门用来检测边界」预判成立——A5 最坏角 D4=0.4735 dB 距 0.5 线 0.027 dB，量产 C0G 实容差劣于 ±5% 即越线；T2 0.4609 次之。
7. **THD 双口径**：任务书未给 THD 判决门；.four "Total"（0.002–0.0087%）由 4.096M 开关纹波泄漏（=基波 256/4096 次谐波）主导非模拟失真；真 2–10 次谐波 1e-8–2.3e-6%（0.0002–0.038 LSB，全案 ≪1 LSB，24bit 分辨率下不可测；下限 1e-8% = S0@1k，上限 2.3e-6% = T4@16k）。两口径均落 `csv/thd_summary.csv`，未用任一口径换取结论。
8. **过程修正留痕（终版数据已验证）**：tolcm 阶跃初版误为差分、改纯共模重跑后与上轮锚精确一致；T08 节点1 行键名错已修；T09 折回交流预测交叉表初版键冲突已改 (方案,频点)；run_all.py L1 引擎 Cramer 初版误返回中间节点 v1 已修正并在 CSV 留痕。THD 1kHz 仿真 ASCII raw 1.7–2.0 GB/只（raw/ 合计 7.7 GB 已 gitignore）。
